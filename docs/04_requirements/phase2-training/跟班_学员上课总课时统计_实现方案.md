# 跟班 · 学员上课总课时统计 · 实现方案

> **日期**：2026-08-19  
> **状态**：**P0 已落地**（课时口径 + metrics/`class-hours` + 跟班工作台展示）  
> **入口**：跟班工作台「概览 / 考勤 / 指标」+ 学员考勤明细抽屉  
> **关联**：[跟班模块功能实现方案.md](./跟班模块功能实现方案.md)（O1 KR3 课次考勤已落地）  
> **原则**：不新建表；不改签到写路径；不按打卡起止算课时；班级计划学时与学员已上课时分列，禁止混加  

---

## 0. 结论（先看）

**产品一句话**：按课表每节实际时长折算课时（**45 分钟 = 1 课时**），再按考勤**是否旷课（缺勤）**扣减：未旷课的课次计入「已上课时」；班级同时展示计划总课时与人均/合计已上课时。

| 问题 | 定稿 |
|------|------|
| 能不能做 | **能**。现有 `train_schedule` + `train_attendance` 足够，P0 不建表、不写快照 |
| 1 课时 | **45 分钟** |
| 时长来源 | **课表 `startTime`～`endTime` 优先**；都缺才用该节 `classHours`（已是学时，**不再 ÷45**） |
| 已上课时 | **截止今日及以前**的可折算课次 − 明确缺勤；未开课课次不计入；未登记视为未旷课 |
| 不算什么 | 不用签到/签退时间；仅 `status=0` 缺勤不计该节；**未来课次不计已上** |
| 迟到/早退 | P0 **按整节计**（与现网有效出勤口径一致：status∈{1,2,3}，非旷课） |
| 按日导入 | 有上课/下课时间 → **课次行**落库（匹配/补建 schedule）；仅无时段才按日合并。有课次行时**课次优先于按日** |
| 精度 | 课时 = 分钟/45，**保留 1 位小数**，四舍五入 |
| 与现网「学时合计」 | 那是课表 `classHours` 相加，改名为**计划学时**，避免被当成已上课时 |

现网跟班**没有**学员课时；只有班级课表学时合计、出勤率。本功能补第三条指标。

## 2. 课时口径（锁定）

### 2.1 单节时长（分钟）

对课次 `S`：

1. `startTime`、`endTime` 都能解析为当天时刻，且结束 **晚于** 开始 → `minutes = end - start`  
2. 否则若 `classHours` 能解析为数字 → **直接视为课时**（不再 ÷45），记 `hoursDirect`  
3. 否则该节 **无法折算**，不计入任何人的课时，计入班级 `unconvertibleSessions`

时间串兼容 `HH:mm` / `HH:mm:ss`（课表导入与签到格式都有）。

**禁止**用 `check_in_time` / `check_out_time`：课次签到通常只有签到时刻、没有签退。

### 2.2 单节课时

```
若走时间：sessionHours = round(minutes / 45, 1)
若走 classHours：sessionHours = round(classHours, 1)
```

样例：

| 时间 | 分钟 | 课时 |
|------|------|------|
| 08:00–08:45 | 45 | 1.0 |
| 08:00–11:15 | 195 | 4.3 |
| 08:00–12:00 | 240 | 5.3 |
| 仅填学时 4 | — | 4.0 |

### 2.3 是否旷课

与考勤 `status` 对齐：

| status | 含义 | 该节是否计课时 |
|--------|------|----------------|
| 0 | 缺勤 / 旷课 | **不计** |
| 1 / 2 / 3 | 出勤 / 迟到 / 早退 | **计整节** |
| 无该节记录 | 未点名 | **计**（视为未旷课） |

### 2.4 学员 × 日 如何判定旷课（防重复）

对课表**每一节可折算且日期 ≤ 今天（Asia/Shanghai）**的课次判定是否旷课，再汇总：

| 当天记录形态 | 计课时规则 |
|--------------|------------|
| 课次在未来 | **不计入已上课时**（计划学时仍含全课表） |
| 有课次考勤行 | 该节明确缺勤 → 不计；出勤/迟到/早退或**无该节记录** → 计（**课次行优先于同日按日记录**） |
| 仅有按日记录且缺勤 | 当天全部可折算课次 **不计** |
| 仅有按日记录且有效出勤 | 当天全部可折算课次 **计** |
| 零条考勤 | 已发生可折算课次 **计满**（`hoursStatus=unrecorded`） |

人社「考勤信息列表」导入：一行一课次，按日期+上课/下课时间匹配课表；匹配不到则自动补建课次后写入 `schedule_id`；并清除同日旧的按日（schedule 空）记录，避免按日吞掉课次旷课。

### 2.5 未登记 = 未旷课

花名册学员在本班 **零条考勤**：

- `attendedHours =` 已发生可折算课次合计（未旷课）  
- `hoursStatus = unrecorded`（仅标记「尚未登记考勤」，**不是把未来课次也算满**）  
- **纳入**班级「人均已上课时」分母  

适合现场只登记旷课、其余默认到课；完成率分母仍为**全课表计划学时**，开课中途不会虚高到 100%。

### 2.6 班级汇总

| 指标 | 算法 |
|------|------|
| `plannedHours` | 全课表可折算课次的 `sessionHours` 之和（时间优先，否则 classHours） |
| `plannedHoursFromExcel` | 仅 `sum(classHours)`，给对照，**不作为已上课时** |
| `attendedHoursSum` | 各学员 `attendedHours` 之和 |
| `attendedHoursAvg` | `attendedHoursSum / 花名册学员数` |
| `hoursCompletionAvg` | `plannedHours>0` 的学员：`attendedHours / plannedHours` 再平均 |
| `unconvertibleSessions` | 无时间也无学时的节次数，>0 时界面提示去补课表 |
| `unrecordedStudentCount` | 零条考勤人数（课时仍按未旷课计） |

学员个人 `plannedHours` 与班级课表相同（插班不按入班日截断，P0 简化；P1 可按入班日后课次截）。

## 3. 计算流程

```text
读本班课表 → 每节算出 sessionHours（或标记无法折算）
读本班全部考勤 + 花名册
对每个学员：
  按日期折叠考勤（按日优先于课次）
  遍历全部可折算课次：未旷课则累加 sessionHours
  attendedHours = round(Σ, 1)
班级汇总 §2.6
```

纯函数，建议抽 `FollowClassHourCalculator`（或放进现有 metrics 包），**单测锁口径**，避免前端各算各的。

## 4. 接口

权限：与跟班指标相同 `train:info-class:view`。考勤明细抽屉已要求 `train:attendance:view` 时，课时字段可同接口返回，避免二次鉴权分叉。

### 4.1 班级指标（扩展现有，不新开菜单）

`GET /training/info-classes/{classId}/follow/quality-metrics`

现有出勤率等字段不动，**追加**：

```json
{
  "plannedHours": 86.7,
  "plannedHoursFromExcel": 80.0,
  "attendedHoursSum": 1240.5,
  "attendedHoursAvg": 32.6,
  "hoursCompletionAvg": 78.4,
  "unconvertibleSessions": 2,
  "hoursMinuteUnit": 45,
  "recordedStudentCount": 38,
  "unrecordedStudentCount": 2
}
```

`hoursCompletionAvg` 为百分数、1 位小数；无法计算时 `null`。

### 4.2 学员课时列表（工作台表格用）

`GET /training/info-classes/{classId}/follow/class-hours`

```json
{
  "plannedHours": 86.7,
  "minuteUnit": 45,
  "students": [
    {
      "peopleId": 1001,
      "name": "张三",
      "attendedHours": 72.0,
      "plannedHours": 86.7,
      "completionRate": 83.0,
      "presentSessions": 18,
      "absentSessions": 4,
      "hoursStatus": "ok"
    },
    {
      "peopleId": 1002,
      "name": "李四",
      "attendedHours": 86.7,
      "plannedHours": 86.7,
      "completionRate": 100.0,
      "presentSessions": 22,
      "absentSessions": 0,
      "hoursStatus": "unrecorded"
    }
  ]
}
```

`hoursStatus`：`ok` | `unrecorded`（零条考勤，课时仍按未旷课） | `partial`（出勤/缺勤落在无法折算课次上，仍给出能算的数）。

P0 班级规模按现网考勤 5000 条拉取同级，一次算完即可，不做分页。

### 4.3 学员明细（扩展考勤抽屉，可不新接口）

抽屉继续 `GET /training/attendances?classId&userId`。P0 前端也可调 4.2 取该人一行。

P1 可选：明细每行带 `sessionHours`、`counted`（本行是否计入），需后端按课次 join 课表，避免前端再算一遍。

## 7. 验收

- [ ] 课次签到：08:00–09:30 出勤 → 该节 2.0 课时；缺勤（旷课）→ 0  
- [ ] 迟到/早退与出勤同课时  
- [ ] 按日导入出勤 + 当天两节（45+90 分钟）→ 3.0 课时  
- [ ] 按日缺勤 + 当天有课次出勤行 → **以课次为准**计课时  
- [ ] 考勤 Excel 同日两节仅一节旷课 → 只扣该节（导入为课次行）  
- [ ] 无考勤学员：已发生课次按未旷课计满；**未来课次不计入已上课时**，完成率不会因全课表虚高到 100%  
- [ ] 同天仅一节标旷课、另一节未登记 → 只扣旷课节  
- [ ] 同课次既有出勤又有缺勤行 → **按缺勤计**  
- [ ] 仅有 `classHours=4`、无时间 → 该节 4.0，不再 ÷45  
- [ ] 无时间无学时的节次：班级提示无法折算，不计入计划/已上  
- [ ] 概览「计划学时」与「人均已上课时」数字不同源、可同时看懂  
- [ ] 不改签到、导入、课表保存接口行为

## 9. 风险

| 风险 | 处理 |
|------|------|
| 课表学时本就是「45 分钟课时」，再拿时间 ÷45 会和 Excel 列对不齐 | 计划学时以时间折算为准；Excel `classHours` 只作对照字段 `plannedHoursFromExcel` |
| 按日导入把全天课时给出勤者，半天请假会被算满 | P0 接受；要精确必须改用课次签到 |
| 上午 4 小时墙钟 ≠ 4 课时（240/45=5.3） | 方案即此；若业务要「一小时一课时」需另拍板，与「45 分钟」互斥 |
| 大班一次拉全量考勤 | 与现网 5000 条同源；超限再分页/服务端聚合 |

拍板点只有一个：**墙钟 4 小时算 5.3 课时还是 4 课时**。本文按用户已提「每 45 分钟一个课时」锁定为 **5.3**。
