### 工种专属考核项目说明

本表为电解精炼工（主工种）通用权重。该职业包含以下工种，其"相关知识要求"中部分项目的考核侧重点有所不同：

| 工种 | 侧重 |
|---|---|
| 重冶配液工 | 工作准备 + 生产操作 |
| 重冶净液工 | 生产操作 + 故障判断与处理 |
| 阴阳极制作工 | 生产操作 + 设备管理 |
| 电解槽操作工 | 生产操作 + 故障判断与处理 |
| 电解熔铸工 | 设备管理 + 技术管理与创新 |
