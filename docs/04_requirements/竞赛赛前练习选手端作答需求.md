# 竞赛赛前练习选手端作答需求

## 1. 目标

选手在 APP 的“赛事任务 → 赛前练习”中打开赛事方推送的练习任务，按题目完成练习并自动保存作答；可自动判定的题目在每次作答保存后立即显示对错。任务详情沿用已确认的 `gjjd_appnext/prototypes/competition-pre-practice.html` 刷题原型。

本阶段打通任务接收、题目展示、作答保存、逐题即时判断和参考答案/解析查看；不实现正式考试计时、交卷、任务总分或成绩记录。

## 2. 选手端流程

1. 选手从赛事任务的“赛前练习”列表选择一条推送记录，进入对应练习。
2. 任务头部展示赛事、赛段、题量与当前题号；选手可以上一题、下一题或打开答题卡跳题。
3. 页面从任务题目快照展示题干、题型、选项及音视频资源。过长题干可以折叠/展开；文字作答在独立弹层中输入，题目展开时仍不挤压输入区域。
4. 单选、判断题选择后自动保存并立即显示对错；多选题分为选择与确认两步，选择阶段可反复勾选或取消，点击“确认答案”后才保存并判定，判定完成后锁定选项；填空题离开输入框时保存，所有空填写完整后自动判断；简答等文字题在弹层中点击保存。
5. 客观题、填空和文字主观题均在作答保存后即时判定。填空逐空精确匹配；简答、论述、问答等文字答案按标准答案字符串精确匹配（去除首尾空白、不区分大小写），本阶段不调用 AI 做语义判分。
6. 选手可以按需展开“查看参考答案与解析”。答案和解析单独按需读取，不随题目详情默认返回；本次作答判定响应会为可判定题目返回标准答案。
7. 选手退出后再次在同一设备打开同一条推送记录，恢复之前的作答、逐题判定结果和当前题号。当前题号按 `deliveryId` 保存在选手 APP 本机；它不在设备间同步。

## 3. 数据与业务规则

- 题目展示必须读取生成任务时固化的题目快照，不回查课程题库的当前题目版本，确保推送后的任务内容稳定。
- 作答按“选手 + 本次推送收件项 + 任务题目”隔离。同一已生成任务多次推送后，每次推送的作答互不覆盖；再次推送不会继承其他推送记录的答案。
- 当前题号按本机的 `deliveryId` 单独保存；更换设备或清除 APP 本地数据后，作答和判定仍从服务端恢复，但当前题号从第一题开始。
- 多选题在点击“确认答案”前仅保存为 APP 本机草稿，草稿按 `deliveryId` 隔离并在同一设备重进时恢复；确认后才写入服务端并纳入已答数量，判定完成后锁定选项。
- 服务端通过选手登录身份验证收件项归属；选手不能通过更换收件项或题目 ID 读取其他选手的题目、答案解析或作答。
- 题目详情不包含参考答案、正确选项或解析；参考答案/解析只在选手主动请求反馈接口时返回。
- 题目详情仅对已有作答返回逐题判定结果；无作答时不得下发对错状态，题目详情始终不返回标准答案或解析。单选/判断沿用平台统一判分服务，多选要求正确选项完整且没有错选；填空逐空、其他文字题整体按快照标准答案精确匹配，去除首尾空白且不区分大小写。
- 逐题判定由冻结的题目快照和当前作答实时计算，不写入课程题库，也不累计任务分数；重进任务时由同一快照恢复判定状态。
- 支持单选、多选、填空和文字主观题作答。文字答案最多 500 字，填空最多 20 空；作答内容按 JSON 保存，允许选手反复修改。
- 当前阶段记录作答与已答数量，并显示逐题对错；不累计任务总分，也不提供交卷/完成状态。
- 重复推送保留各自的任务收件记录；任务列表按推送记录展示，入口携带该条记录的 `deliveryId`。

## 4. 接口约定

选手端接口使用赛事选手登录态，并遵循统一响应 `{ code, message, data }`。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/competition/player/tasks` | 分页读取当前选手收到的赛前练习任务 |
| GET | `/competition/player/tasks/{deliveryId}` | 读取本次推送任务详情、题目快照、已有作答及已答数量 |
| GET | `/competition/player/tasks/{deliveryId}/questions/{taskQuestionId}/feedback` | 选手主动查看该题的参考答案与解析 |
| PUT | `/competition/player/tasks/{deliveryId}/questions/{taskQuestionId}/answer` | 新增或覆盖当前推送记录下该题的作答；请求体为 `{ "answer": ... }` |

保存接口返回本题作答状态、判定状态（`correct`、`incorrect`、`pending` 或 `unavailable`）及本次任务的已答题数、总题数；判定完成后随本次保存结果返回标准答案。重新进入任务后，详情恢复对错状态但不返回标准答案，答案与解析仍需选手主动打开反馈查看。服务端拒绝不属于该任务的题目、无效选项和超长答案。

## 5. 页面验收要点

- 从赛事任务列表的赛前练习卡片可以进入任务；不同推送记录能分别进入。
- 单选、判断题作答后即时显示对错；多选题选择阶段不会自动判定，可修改选项，点击“确认答案”后显示对错并锁定选项；完整填写的填空题即时显示对错，答案错误时显示正确答案。
- 主观文字题能保存并恢复作答；标准答案存在时即时显示字符串匹配结果，标准答案缺失时提示暂不可判定。
- 答题卡能区分当前题和已答题，跳题后显示正确题目内容与作答。
- 长题干折叠/展开不遮挡或挤压作答入口；文字输入弹层覆盖题目区域并能保存、关闭。
- 打开反馈后展示答案和解析；未主动打开反馈时，题目展示数据不包含正确答案。
- 重进同一次推送恢复作答；另一条重复推送记录显示独立作答。
- 本阶段没有任务总分、交卷和最终成绩展示入口。
