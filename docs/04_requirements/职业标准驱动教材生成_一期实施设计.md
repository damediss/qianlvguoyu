> 版本：v1.0　日期：2026-08-21

### 2.4 核心流程与算法

**状态机**：`parsed`（工程已建、骨架未建——仅创建失败兜底态）→ `outlined`（骨架+配比完成，可编辑/导出）→ `reviewed`（专家在页面点"评审通过"，一期终态）。

① **解析**（接口 1/2 内）：读 file → `new DocxStandardParser().parse(in)` → `ParsedStandard`。`parseWarnings` 原样落库并在页面展示（学时缺失、权重表缺失时**禁止进入下一步**，返回 400 + warnings）。

② **方向→职业功能映射**（`TextbookDirectionResolver`）：
- 正则抽取等级正文首段"XX 工考核职业功能 N、M、K 项"句式 → `{方向: [序号]}`；铝电解工 10 方向以 v1.0 §2.1 原文为对拍基准；
- 解析不出 → `guessedFunctionNos` 置空 + warning"方向映射未识别，请人工登记"，`function_nos_json` 由创建表单必填传入；
- 单方向工种：directions=["默认"]，全部职业功能生效。

③ **骨架生成**（`TextbookOutlineBuilder`，纯规则）：
- 篇：固定两个 L1（"基本要求"/"工作要求"）；
- 章（基础篇）：2.1 职业道德、2.2 基础知识及 2.x.y 节；章权重取 `theoryWeights.findRow("基本要求-职业道德"/"基本要求-基础知识")`；
- 章（专业篇）：该 level 工作要求中经 ② 过滤后的职业功能（L1），节=工作内容（L2），点=`theoryMaterials`/`skillMaterials` 逐条（dimension=theory/skill）；
- **权重为 null（`—`）的项目不生章**（实测：三级无"工作准备"章、二级无"设备管理"章）；
- source_no 记录标准编号（职业功能 L1 用其序号、工作内容用 L2 编号、点用条目编号）。

④ **篇幅配比**（`TextbookWordAllocator`，纯函数，最大余数法）：
- `total_words = training_hours × words_per_hour`；
- 章字数 = total × weight ÷ 100，最大余数法凑整，**各章之和严格 = total**；
- 节字数 = 章字数 × (该节知识点+技能点条数) ÷ 章总条数，同法凑整；章总条数=0 时各节均分并记 warning；
- 篇字数=子章合计（冗余展示，不约束）。

⑤ **重建保留人工调整**（接口 5/7）：重建时删 `words_manual=0` 节点、保留人工节点；人工节点的字数从总盘子里先扣除，剩余按权重/条数重新分摊（分摊基数相应减少，保证合计仍 = total_words）；章级人工节点只保字数不保结构（其下节重建）。

⑥ **合计校验**（`TextbookOutlineApplicationService`）：接口 4/9 响应携带 `{chapterSum, totalWords, balanced, unbalancedChapters[]}`；前端只做展示，后端在导出前强制复核，不平衡仍允许导出但在导出文件标注（v1.0 §7.4"提示不阻塞"）。

⑦ **导出**（`TextbookOutlineExporter`）：
- Markdown：`# 工种-方向（等级）` → 章 `##`（附权重%/字数）→ 节 `###`（附字数）→ 点 `- [理论]/[技能]`；文末附"配比依据"表（章 | 权重来源 | 是否人工调整）；
- Excel：POI 生成，列=[层级, 编号, 标题, 维度, 权重%, 目标字数, 配比依据]；样式从简（表头加粗+冻结首行）；
- 响应写法照 `StandardParseController.writeFile`（UTF-8 文件名编码）。

### 2.6 防御与异常

- 所有 Mapper 返回 null 检查（AGENTS.md 防御性编程）；
- 解析异常（非 docx/结构不识别）→ 400 + warnings，不写半成品工程（创建接口内解析失败则整体回滚）；
- `function_nos_json` 校验：序号必须在该等级实际存在的职业功能范围内，越界 400；
- 唯一键冲突（同分册重复创建）→ 409 提示"该分册已存在"，不静默覆盖；
- 权限/认证路径 warn 日志（@PreAuthorize 拒绝由全局异常处理器统一返回，审计日志记写操作）。

  - 维度（点级：理论/技能 Tag）；
  - 权重%（章级）；
