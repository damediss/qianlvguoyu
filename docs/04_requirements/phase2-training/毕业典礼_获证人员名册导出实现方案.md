## 一、结论（先看）

| 问题 | 答案 |
|------|------|
| 目标 | 导出与人社样表**同版式、同列**的《职业技能等级认定获证人员名册》xlsx |
| 人员范围 | **导出时二选一**（见 §3.1）：默认 **已获证**；可选 **班级全部人员** |
| 已获证 | **有非空证书编号**（不以「仅有证书记录、证号为空」算获证） |
| 空名单 | 选已获证且无人达标时，**仍导出空表**（不中止、不弹「禁止下载」） |
| 交互 | 点击「导出人员名册」→ 选择「已获证 / 全部」→ 再触发下载 |
| 等级文案 | 统一为 **`三级/高级工`** 形式（级数/称谓） |
| 版式策略 | **模板填充**（方案 A）：样表入库为资源模板，POI 写页眉 + 数据行 + 下移行脚 |
| P0 已做 | 删除旧扁平台账导出；按钮对接新模板导出（当时固定全班） |
| P1 已做 | 范围选择 + `scope` 参数；缺省已获证；空名单空表 |

**一句话：** 同一套人社版式名册；导出前选「已获证（默认）或全班」；已获证=证号非空；无人则空表。

## 二、样表结构（目标格式）

### 2.1 版式

| 区域 | 内容 |
|------|------|
| 第 1 行 | 标题（合并 A1:M1）：**职业技能等级认定获证人员名册** |
| 第 2 行 | **班级名称：{班级标题}**（合并 A2:M2） |
| 第 3–4 行 | 双行表头；「考核成绩」下拆 **理论 / 技能 / 综合 / 工作业绩** |
| 第 5 行起 | 人员数据 |
| 末行 | `填报人：` / `负责人：` / `单位（章）：` |

> **已取消页眉**：不再导出「计划名称 / 填报日期 / 计划编码 / 取证日期」行。

合并区参考样表标题、双行表头竖合、考核成绩、页脚签章合并等。

### 2.2 数据列（13 列）

| 列 | 字段 | 样例 / 规则 |
|----|------|-------------|
| A | 序号 | 从 1 递增（按导出范围内人员） |
| B | 准考证号 | `ticket_no`，无则空 |
| C | 姓名 | 花名册 |
| D | 性别 | 男/女 |
| E | 证件号码 | 身份证 |
| F | 报名机构 | 班级/培训关联企业名（开班企业） |
| G | 职业工种 | 班级工种名 |
| H | 认定等级 | **`三级/高级工`** 等（见 §4） |
| I–L | 理论/技能/综合/工作业绩 | 有值写数字字符串；**空写 `--`** |
| M | 证书编号 | 有非空证号则写出；全班模式下未建证/无证号留空 |

文件名建议：

- 已获证：`职业技能等级认定获证人员名册_{班级名}_已获证_{yyyyMMdd}.xlsx`
- 全部：`职业技能等级认定获证人员名册_{班级名}_全部_{yyyyMMdd}.xlsx`

### 3.1 导出范围（P1 · 2026-08-24 确认）

| 项 | 决议 |
|----|------|
| 交互 | 点击「导出人员名册」→ **选择「已获证」或「全部」** → 再下载文件 |
| 默认选项 | **已获证** |
| 已获证 | `train_certificate` 存在且 `certificate_no` **非空**（trim；空白不算） |
| 全部 | 班级全部学员（`type=student` 且未删除）；含未建证、不合格结业、无成绩；无证号则 M 列空 |
| 空名单 | 范围内 0 人时 **仍导出空表**（标题/班级名称/表头/页脚保留；数据区无有效人员行） |
| UI 形态 | 推荐：按钮下拉菜单两项（「已获证人员名册」「班级全部人员名册」）；或 Popconfirm/Modal 二选一后导出。须保证 **一次选择即可导出**，不要拆成两个常驻按钮占位 |
| 入口覆盖 | 详情页按钮、列表行内「导出人员名册」、工具栏「导出已选名册」均需范围选择（多班时选一次范围，ZIP 内统一） |

> **与 P0 差异**：P0 落地时固定导出全班；P1 改为可选且 **默认已获证**，对外报送与对内核对共用同一模板。

## 七、技术实现要点

### 7.1 模板填充（P0 已用）

1. 模板：`services/platform-api/src/main/resources/templates/职业技能等级认定获证人员名册.xlsx`
2. POI：写第 2 行班级名称；数据行插入并复制样式；页脚下移。
3. 注意：模板 A2 为 `inlineStr` 时，写班级名需 **删单元格再建**，避免只剩「班级名称：」前缀。

### 7.2 API

```
GET /training/info-classes/{classId}/certified-roster/export
    ?scope=certified|all
    &classTitle=可选

GET /training/graduation/certified-roster/export
    ?classIds=...
    &scope=certified|all
```

| 参数 | 规则 |
|------|------|
| `scope` | `certified` = 已获证；`all` = 全部。**缺省 = `certified`** |
| `classTitle` | 可选，优先用于第 2 行与文件名 |
| 过滤时机 | 先查全班学员 + 证书 Map，再按 `scope` 过滤后填表 |
| 空名单 | 过滤后 0 人：仍返回合法 xlsx 空表（不清空表头/页脚） |

权限：与现毕业典礼查看一致。

### 7.3 前端（P1）

| 文件 | 改动 |
|------|------|
| `TrainingGraduationClassDetailPage.tsx` | 「导出人员名册」→ 下拉/选择「已获证（默认）/ 全部」→ `exportCertifiedRoster(classId, title, scope)` |
| `TrainingGraduationPage.tsx` | 行内导出、导出已选名册：同样先选 scope |
| `api/training.ts` | 下载函数增加 `scope` 查询参数 |

下载须走鉴权请求（blob）。

### 7.4 后端类职责

| 类 | 职责 |
|----|------|
| `TrainGraduationController` | 接收 `scope`，传入导出服务 |
| `GraduationCertifiedRosterExportService` | 按 scope 过滤后填模板；文件名带 `_已获证_` / `_全部_` |
