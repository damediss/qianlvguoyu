# 编码规范与开发约束

## 后端分层约束

| 层 | 命名 | 职责 |
|---|---|---|
| Controller | `*Controller` | REST API，参数接收、权限入口、结果返回 |
| Application | `*ApplicationService` | 用例编排、事务边界、跨领域协调 |
| Domain | `*DomainService` | 核心业务规则 |
| Repository | `*Repository` / `*Mapper` | MyBatis-Plus 数据访问 |
| Entity | `*Entity` | 数据库表映射（不直接暴露给前端） |
| DTO | `*CreateReq`、`*UpdateReq`、`*QueryReq` | 请求对象 |
| VO | `*VO`、`*DetailVO` | 返回对象 |
| Converter | `*Converter` | MapStruct 转换 |

## API 响应规范

- 统一返回结构 `{ code, message, data }`
- 分页数据包裹在 `data` 中，含 `total`、`page`、`size`、`records`
- 所有列表接口使用同一分页参数（PageQuery），响应统一分页结构（PageResponse）

## 数据访问与隔离

- Controller 不直接写 SQL，Entity 不直接暴露给前端
- 涉及企业/项目/用户的数据必须带 `tenant_id` 和数据权限过滤
- 多租户过滤通过 MyBatis-Plus 多租户插件自动处理，不在业务代码里手动拼接 tenant_id 条件
- 逻辑删除统一用 MyBatis-Plus 的 `deleteById` / `deleteBatchIds`，禁止手动 `setDeleted(1) + updateById`

## 认证与权限

- 后端是权限最终裁决点，前端只做展示控制
- AI / MCP 调用必须走受控 API 或 Application 层，不能绕过权限直接访问 Mapper
- Sa-Token token-style 为 tik，不使用 JWT 持久化 extra

## 审计日志

- 所有写操作记录操作日志

## 异常处理

- 全局异常处理器覆盖：认证失败、权限不足、参数校验失败、业务异常
- 不要在 filter/interceptor 中静默吞异常

## 数据库规则

- MySQL 8.4，主键雪花 ID，类型统一 `BIGINT`
- 多租户字段 `tenant_id`，逻辑删除字段 `deleted`
- 业务主表必须包含：`id`、`tenant_id`、`created_at`、`updated_at`、`created_by`、`updated_by`、`deleted`
- Flyway 迁移脚本放在 `services/platform-api/src/main/resources/db/migration/`
- 迁移命名：`V{YYYYMMDD}_{序号}__{描述}.sql`
- 包含种子数据的迁移必须幂等，可重复执行不报错
- 不修改已应用的 Flyway 迁移文件内容
- Flyway outOfOrder 已启用
- 业务主状态以 MySQL 为准，Redis 只用于缓存/会话/验证码/限流

## 前端规则

### 数据管理

- 页面级数据请求使用 TanStack Query
- 用户信息、菜单、主题、折叠状态使用 Zustand
- 表格优先 ProTable，表单优先 ProForm，图表统一 ECharts
- 菜单从后端动态加载，不在前端写死

### HTTP 错误处理

- apiClient 响应拦截器必须覆盖 401/403/500：
  - 401：清除 store 中 token + currentUser，让 AuthGate 展示登录表单
  - 403：展示权限不足提示，不自动跳转
  - 500：区分代理错误和业务错误

### 登录态管理

- AuthGate 使用 store 中 currentUser（同步）作为主判定条件
- 页面刷新后：先取 localStorage token → 同步展示 UI → 后台异步验证 /api/auth/me
- /api/auth/me 返回 401 时静默清除本地 token

### 多租户

- 请求拦截器附加 X-Tenant-Id header
- tenantId 持久化到 localStorage

### 路由注册

- 使用 pageMap 机制：菜单 code → React 组件映射
- 路由注册在 `apps/admin-web/src/main.tsx`

### 目录结构

```
src/

  stores/  hooks/  utils/  types/
  pages/
    dashboard/  system/  course/  question/
    exam/  training/  workflow/  ai/
```

## 文件规范

- 所有源码、配置、Markdown 文件使用 UTF-8 without BOM
- PowerShell Set-Content 默认带 UTF-8 BOM — 改源码用 Edit/Write 工具，不要走 shell 管道
- YAML 中版本号、数字串字段使用引号包裹

## 防御性编程

- 所有 MyBatis Mapper 返回值做 null 检查后再使用
- 所有外部 API/网络请求的响应先做空值和类型检查
- 认证、授权、权限校验路径必须打印 warn/error 级别日志
