# 跟班考勤「导出考勤表」功能方案

> 状态：已实施（2026-10-14），待部署验收 —— 后端 19 测全绿、前端 4 测全绿、全量回归 1989 测仅 12 个既有失败（competition/certification/knowledgefix，与本功能无关）
> 位置：培训管理 → 运营流程 → 跟班 → 考勤页签
> 口径来源：用户四项拍板（矩阵式 / 全部考勤日期 / 按日合并 / 身份证+签名+汇总列）+ 三项补充拍板（零考勤导空表 / 新权限码 / 模板加班级信息行）

## 1. 需求背景

跟班考勤页签当前只有「导入考勤表」（吃人社/培训平台 xlsx）和单条 出勤/缺勤 登记，没有导出能力。班主任/监管上报需要纸质考勤表打印签字，要求一键导出矩阵式考勤表。

## 2. 已确认口径

| 决策点 | 拍板 |
|---|---|
| 表格形态 | **矩阵式**：每行一个学员、每列一个考勤日期 |
| 日期范围 | **该班全部考勤日期**（`train_attendance` 中有记录的日期，升序） |
| 课次粒度 | **按日合并**：同一天多个课次合并一格，状态取最优，优先级 出勤(1) > 迟到(2) > 早退(3) > 缺勤(0) |
| 学员列 | 序号 / 姓名 / 手机 / **身份证号** |
| 行末列 | 出勤天数 / 迟到 / 早退 / 缺勤 / **已上课时 / 完成率**（与页面同口径）/ **签名（空白列）** |
| 零考勤班级 | **照常导出空表**（只有学员列 + 统计列，日期列零列），打印后手工勾签也是真实场景 |
| 权限 | **新增权限码 `train:attendance:export`**（导出含身份证号，敏感动作与 view 分开） |
| 模板 | **加班级信息行**（班级名称 / 培训工种及等级 / 培训时间 / 班主任及电话 / 企业 / 导出日期，见 §3） |

合并口径与前端 `FollowClassWorkbench.mergeDayAttendanceRows` 一致（`attendanceStatusRank`：1→4、2→3、3→2、0→1，取最大；无任何记录则空格，不显示「未登记」字样）。

## 3. 表样

```
                    职业技能培训考勤表
班级名称：电工高级工1班     培训工种及等级：电工 / 三级（高级工）     培训时间：2026-09-01 至 2026-10-10
企业：广西某某铝业有限公司   班主任：张三 13800000000            导出日期：2026-10-14
序号 | 姓名   | 手机        | 身份证号           | 10-08 | 10-09 | 10-10 | ... | 出勤 | 迟到 | 早退 | 缺勤 | 已上课时 | 完成率  | 签名
1    | 黄毅坚 | 15878607437 | 4526**********1234 | 出勤  | 缺勤  | 出勤  | ... | 12   | 0    | 0    | 1    | 32.0     | 25.4%   |
2    | 唐秀锡 | 13667769235 | ...                | 出勤  | 出勤  |       | ... | 13   | 0    | 0    | 0    | 0.0      | 0.0%    |
```

- 第 1 行：大标题「职业技能培训考勤表」，合并居中。
- 第 2~3 行：班级信息行（六个字段排两行），程序填入，无值显示「—」：
  - 班级名称（`TrainInfoClassEntity.title`）
  - 培训工种及等级（`workTypeId` → `exam_work_type` 名称 + `workTypeLevel` 等级文案，解析照抄 `GraduationCertifiedRosterExportService.resolveWorkTypeName / formatLevelLabel`）
  - 培训时间（`dateStart ~ dateEnd`）
  - 企业（`companyId` → `sys_org`，照抄 `resolveCompanyName`）
  - 班主任及电话（`train_class_role` 中 `roleCode=head_teacher` 的 `displayName + phone`，多个班主任顿号连接）
  - 导出日期（当天）
- 日期列头格式 `MM-dd`（跨年时 `yyyy-MM-dd`），窄列。
- 无考勤记录的格子留空（不填「未登记」）。
- 状态文案：出勤 / 迟到 / 早退 / 缺勤，不加颜色（打印友好）。
- 签名列整列空白、加宽，供打印手签。
- 日期列过多（>31 天）不做特殊处理，xlsx 无打印宽度限制，打印时由使用者横向缩放。

## 4. 后端设计

### 4.1 接口

```
GET /training/classes/{classId}/attendances/export
权限：train:attendance:export（新增，见 §6）
响应：xlsx 附件流，Content-Disposition: attachment; filename*=UTF-8''...
文件名：考勤表_<班级名>_<yyyyMMdd>.xlsx
```

- 放在 `TrainAttendanceController`（与考勤域同控制器）。
- 导出走读事务，复用现有 mapper 查询，不加异步（班级考勤量级小，同步导出足够；将来如需大批量再按「快速返回 + 异步 + 轮询」拆）。

### 4.2 数据装配

新增 `TrainAttendanceExportService`（trainingdepartment.service 包）：

1. **班级**：`TrainInfoClassMapper.requireClass(classId)`（班级名/展示名解析照搬 `GraduationCertifiedRosterExportService.resolveClassDisplayName`）。
2. **班级信息行**：工种名、等级文案、企业名、班主任（含电话）按 §3 装配。
3. **学员**：`TrainPeopleListMapper` 查 `train_class_id=classId AND type='student' AND deleted=0`，按 id 升序 → 序号 / 姓名 / 手机 / 身份证号。
4. **考勤**：`TrainAttendanceMapper` 查该班全部未删记录（不手拼 tenant 条件，MyBatis-Plus 多租户插件自动过滤；仅做与 `TrainFollowClassHourApplicationService.compute` 同款的 `tenantId == null || equals` 内存兜底）。
5. **课时**：复用 `TrainFollowClassHourApplicationService.compute(classId, tenantId)` 得每学员 `attendedHours / completionRate`（与页面「已上课时 / 完成率」完全同口径，不另写一套计算）。
6. **矩阵装配**：
   - 日期列 = 考勤记录去重日期升序；
   - 每学员 × 日期：按 §2 优先级取最优状态；出勤/迟到/早退/缺勤天数按**合并后**计（与格内文字一致）；
   - 无任何考勤记录的学员行：状态格全空、统计列全 0、课时列照常（按课时服务口径算，可能非 0）。

### 4.3 写出

参照 `GraduationCertifiedRosterExportService` 的模板范式：

- 模板：`resources/templates/attendance-sheet.xlsx`（手工排好标题行、班级信息行、表头样式、列宽、边框；程序填信息行 + 数据行；数据行不够时复用该服务 `ensureDataRows` 同款插入行逻辑，不新造轮子）。
- 首版即模板方式，不做纯代码建表降级。
- 班级无学员 → 400「该班级暂无学员，无法导出考勤表」；有学员但零考勤记录 → **照常导出空表**（已定）：信息行照常填，日期列零列，表头照常。

## 5. 前端设计

- 位置：考勤页签「导入考勤表」按钮右侧，加「导出考勤表」按钮（`Button icon={<DownloadOutlined/>}`，权限 `train:attendance:export` 控制显隐）。
- 交互：点击直接触发下载（按现有导出按钮的既有写法对齐，如获证名册导出按钮），无弹窗（范围已拍板=全部日期）。
- API 层：`api/training.ts` 加导出方法，复用现有 download 工具。
- 无学员时按钮禁用 + tooltip「班级暂无学员」。

## 6. 权限与迁移

- 新权限码 `train:attendance:export`（导出考勤表），挂在既有菜单「考勤管理」(page 4928, `/training/attendance`) 下。
- 权限种子迁移：实施时查询测试/生产两库 `SELECT MAX(version) FROM flyway_schema_history` 取号（共用目录 `_001` 递进），`tenant_id=10159`，三步链：复用菜单 4928 → 新增权限码种子 → `sys_role_permission` 给运营角色授权（参照 V20260520_004 的授权写法）。
- 前端无新增菜单（按钮在既有跟班页面内）。

### 7.1 矩阵装配用例

## 8. 验收清单（手动）

实施完成后按此逐项过：

1. **权限链路**：给测试账号授 `train:attendance:export` 后按钮出现；撤销后消失（403 不出现按钮）；无授权直接调接口返回 403。
2. **数据对拍**：选一个上午/下午双课次都有导入考勤的班，导出 xlsx 与跟班考勤页逐学员、逐日期核对：格内状态、出勤/迟到/早退/缺勤天数、已上课时、完成率 完全一致（至少抽 3 名学员 × 全部日期）。
3. **合并口径专项**：找一个「同日上午缺勤、下午出勤」的学员，格内必须是「出勤」，且出勤 +1、缺勤不 +。
4. **边界**：零考勤班级导出空表（信息行齐全、日期零列）；无学员班级报「该班级暂无学员」提示。
5. **信息行**：工种/等级/企业/班主任/培训时间/导出日期 与本班实际一致，缺失字段显示「—」。
6. **打印**：A4 横向打印预览，签名列留白可手签，日期列头清晰可读；>31 日期班级可缩放打印。
7. **审计**：导出动作在操作日志留痕（@AuditLog 生效）。
8. **迁移**：种子迁移在空库跑通；两库 MAX(version) 取号无撞号；tenant_id=10159；权限三步链完整（接口不再 403 才算过）。

## 9. 不做的事

- 不做长表明细 Sheet、不做日期范围选择弹窗（口径已定全部日期）；
- 不改 `FollowClassHourCalculator` 课时计算口径；
- 不对导出文件加水印/密码（含身份证号属敏感，文件由下载者自行保管——如需密码保护可后续加）；
- 不做导出的异步化/进度轮询（量级小，同步导出）。
