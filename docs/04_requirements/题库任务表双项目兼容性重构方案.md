# 题库任务表双项目兼容性重构方案

## 1. 背景

gjjd_phalcon（PHP）和 qianlvguoyu_saas（Java）两个项目需要共用同一个 MySQL 数据库（gjjddb2026）的 13 张题库任务表。
本文档分析两库表结构差异，规划使双方都能正常操作 gjjddb2026 所需的全部改动。

### 1.1 确认的决策

| 决策点 | 选定方案 | 理由 |
|--------|---------|------|
| `addtime` 类型 | 统一为 `datetime` | saas 已使用 datetime，phalcon 侧改代码 |
| `sno_0`/`sno_1` 类型 | 保持 `json` | saas 已使用 JSON，phalcon 侧改代码写合法 JSON |
| 归档功能字段 | **不加列**到 gjjddb2026 | saas 不需要归档功能，phalcon 侧自行容错或移除 |
| audit 辅助字段 | **加列**到 gjjddb2026 | `uptime` 和 `exam_idea` 对 phalcon 审核流程必要 |

---

## 2. 兼容性分析总结

### 2.1 三方对照说明

以下分析涉及三个层面：
- **gjjddb**：phalcon 当前使用的数据库
- **gjjddb2026**：目标共享数据库（saas 当前使用）
- **saas Entity**：saas 项目 Java 实体类字段定义

### 2.2 逐表差异矩阵

#### 主表（4 张）：task_exam / task_examshicao / task_examsub / task_ximu

| 字段 | gjjddb | gjjddb2026 | saas Entity | 问题级别 | 说明 |
|------|--------|------------|-------------|---------|------|
| `addtime` | `int(10)` 时间戳 | `datetime` | `LocalDateTime` | **A-运行时** | phalcon 写 int 到 datetime 列会报错/数据损坏 |
| `is_archived` | `tinyint(1)` | **不存在** | **不存在** | **A-运行时** | phalcon 归档功能写此列会报 "Unknown column" |
| `archived_at` | `datetime` | **不存在** | **不存在** | **A-运行时** | 同上 |
| `archived_reason` | `varchar(50)` | **不存在** | **不存在** | **A-运行时** | 同上 |
| `tenant_id` | 不存在 | `int` | `Integer` | C-无影响 | phalcon 不写此列，gjjddb2026 有默认值 1 |
| `deleted` | 不存在 | `tinyint` | `Integer` | C-无影响 | 同上 |
| `create_time`/`updated_at`/`created_by`/`updated_by` | 不存在 | 存在 | 存在 | C-无影响 | 同上 |

#### task_exam_detail（理论命题明细）

| 字段 | gjjddb | gjjddb2026 | saas Entity | 问题级别 |
|------|--------|------------|-------------|---------|
| `level` | `varchar(20)` | `int` | `Integer` → `String` | **A-运行时** |

**改动**：
- **Flyway 迁移**：`ALTER TABLE task_exam_detail MODIFY COLUMN level varchar(20)`
- **Entity**：`ExamTaskExamDetailEntity.level` 类型 `Integer` → `String`
- **VO**：`ExamTaskExamDetailVO.level` 类型 `Integer` → `String`
- **Service**：Excel 导入 `parseIntOrNull` → 直接取字符串
- **前端 TS**：`level?: number` → `level?: string`

#### task_examshicao_detail（实操命题明细）

| 字段 | gjjddb | gjjddb2026 | saas Entity | 问题级别 |
|------|--------|------------|-------------|---------|
| 所有 saas Entity 字段 | ✓ 存在 | ✓ 存在 | ✓ 已映射 | 无问题 |

**结论**：完全兼容，无需改动。

#### task_examsub_detail（主观命题明细）

| 字段 | gjjddb | gjjddb2026 | saas Entity | 问题级别 |
|------|--------|------------|-------------|---------|
| `isJisuan` | `int` 列名 `isJisuan` | `int` 列名 `is_jisuan` | `Integer isJisuan` | C-无影响 |
| `nanyicd` | **不存在** | `varchar(20)` | `String` | C-无影响 |
| `isblod` | **不存在** | `int` | `Integer` | C-无影响 |
| `pic` | `varchar(200)` | `varchar(500)` | `String` | C-无影响 |

> `isJisuan`（phalcon）vs `is_jisuan`（gjjddb2026）：Phalcon ORM 自动将 camelCase 属性名转为 snake_case 列名，因此 `isJisuan` 会自动映射到 `is_jisuan`，**不会报错**。

**结论**：saas 侧完全兼容。phalcon 侧也兼容（`isJisuan` → `is_jisuan` 自动映射）。

#### task_examsub_audit_records（主观命题审核记录）

#### task_ximu_detail（细目表明细）

| 字段 | gjjddb | gjjddb2026 | saas Entity | 问题级别 | 说明 |
|------|--------|------------|-------------|---------|------|
| `sno_0` | `varchar(100)` | **`json`** | `String` | **A-运行时** | phalcon 写普通字符串到 JSON 列，MySQL 拒绝 |
| `sno_1` | `varchar(100)` | **`json`** | `String` | **A-运行时** | 同上 |

> saas 侧：Entity 用 `String` 类型 + `@TableField("sno_0")`，读写 JSON 列时 MySQL 返回 JSON 字符串，Java String 可以承载。**但 saas 写入时也必须保证值是合法 JSON**（如 `"\"某字符串\""` 或 `[1,2,3]`），否则 MySQL 也会拒绝。

| `tenant_id` | **不存在** | `int NOT NULL DEFAULT 1` | `Integer` | **B-数据** | phalcon 不写此列，全部默认租户 1 |
| `created_at`/`updated_at`/`created_by`/`updated_by`/`deleted` | **不存在** | 存在 | 存在 | C-无影响 | phalcon 不写审计字段 |

## 3. saas 项目需做的工作

### 3.1 数据库加列（Flyway 迁移）

> saas Java Entity **无需修改**。以下仅为 phalcon 兼容而在 gjjddb2026 中添加列。

**新建迁移文件**：`V20260623_002__add_phalcon_compat_columns.sql`

```sql
-- 为 phalcon 兼容添加的列（saas 不使用这些列，仅保证 phalcon 写入不报错）

-- task_exam_audit_records: 添加 uptime 和 exam_idea
ALTER TABLE task_exam_audit_records
  ADD COLUMN `exam_idea` varchar(500) DEFAULT NULL COMMENT '解析/备注(phalcon用)',
  ADD COLUMN `uptime` int NOT NULL DEFAULT 0 COMMENT '更新时间戳(phalcon用)';

-- task_examshicao_audit_records: 添加 uptime
ALTER TABLE task_examshicao_audit_records
  ADD COLUMN `uptime` int NOT NULL DEFAULT 0 COMMENT '更新时间戳(phalcon用)';

-- task_examsub_audit_records: 添加 uptime
ALTER TABLE task_examsub_audit_records
  ADD COLUMN `uptime` int NOT NULL DEFAULT 0 COMMENT '更新时间戳(phalcon用)';

-- task_ximu_audit_records: 添加 uptime
ALTER TABLE task_ximu_audit_records
  ADD COLUMN `uptime` int NOT NULL DEFAULT 0 COMMENT '更新时间戳(phalcon用)';
```

### 3.2 saas 侧不需要改动的部分

| 类别 | 原因 |
|------|------|
| **所有 13 个 Entity 类** | 字段已与 gjjddb2026 完全对齐 |
| **所有 Mapper 接口** | 纯 MyBatis-Plus BaseMapper，不涉及表结构差异 |
| **所有 Service / Controller** | 不直接引用 phalcon 独有字段 |
| **前端代码** | 通过 REST API 访问，不感知数据库结构 |
| **sno_0 / sno_1** | saas Entity 用 String 读写 JSON 列，功能正常 |
| **addtime** | saas Entity 用 LocalDateTime 对应 datetime 列，已正确 |

## 4. phalcon 项目需做的工作（供参考）

> 以下为 phalcon 侧改动清单，不在 saas 项目中实施，但需 phalcon 开发者知悉。

### 4.1 addtime int→datetime 改造（5 张表）

涉及文件：
- `app/models/TaskExam.php` / `TaskExamshicao.php` / `TaskExamsub.php` / `TaskXimu.php` / `TaskExpert.php`
- `app/controllers/api/ApptaskController.php` / `YunexpertController.php` / `YuntikuController.php`

改动内容：
- 所有 `$model->addtime = time()` 改为 `$model->addtime = date('Y-m-d H:i:s')`
- 所有查询中 `addtime` 的排序/比较逻辑适配 datetime 格式
- 历史数据中 int 类型的 addtime 需要一次性 UPDATE 转换

### 4.2 sno_0 / sno_1 JSON 适配

涉及文件：
- `app/models/TaskXimuDetail.php`
- `app/controllers/api/ApptaskController.php`

改动内容：
- 写入时确保 `sno_0` / `sno_1` 值是合法 JSON（如 `json_encode($value)`）
- 读取时用 `json_decode()` 解析
- 历史数据中 varchar 值需要一次性 UPDATE 转换为合法 JSON

### 4.3 归档功能容错

涉及文件：
- `app/models/TaskExam.php` / `TaskExamshicao.php` / `TaskExamsub.php` / `TaskXimu.php`

改动内容（二选一）：
- **方案 A**：移除归档相关属性和方法
- **方案 B**：在写入前检测列是否存在，不存在时跳过（容错模式）

### 4.4 task_expert 字段补齐

涉及文件：
- `app/models/TaskExpert.php`
- `app/controllers/api/YunexpertController.php`

改动内容：

- 新增 `tenant_id` 属性，写入时设置为当前租户 ID
- 新增 `created_at`/`updated_at`/`deleted` 等审计字段

## 5. 数据迁移注意事项

将 gjjddb 数据导入 gjjddb2026 时需要处理的转换：

| 转换项 | 方法 |
|--------|------|
| `addtime` int→datetime | `FROM_UNIXTIME(addtime)` |
| `sno_0`/`sno_1` varchar→json | `CAST(sno_0 AS JSON)` 或 `CONCAT('"', REPLACE(sno_0, '"', '\\"'), '"')` |
| `isJisuan`→`is_jisuan` | 列名映射 |
| 审计字段 | 补充 `tenant_id=1`, `deleted=0`, `create_time=NOW()` 等默认值 |
| 归档字段 | 丢弃 `is_archived`/`archived_at`/`archived_reason`（不导入） |

示例迁移 SQL（以 task_exam 为例）：

```sql
INSERT INTO gjjddb2026.task_exam
  (id, work_type_id, level, nums, status, expert_start, expert_end, file_path,
   addtime, tenant_id, deleted, create_time, updated_at)
SELECT
  id, work_type_id, level, nums, status, expert_start, expert_end, file_path,
  FROM_UNIXTIME(addtime),
  1,  -- tenant_id 默认
  0,  -- deleted 默认
  NOW(), NOW()
FROM gjjddb.task_exam;
```
