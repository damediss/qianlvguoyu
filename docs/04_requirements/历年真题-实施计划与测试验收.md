### 2.3 文件存储（复用 FileStorage，深模块）

- 存储：`FileStorage.put("zhenti/{examId}/{md5}.pdf", in, size, "application/pdf")`，`file_key` 落库，**任何出参不得含 file_key**（契约测试断言）。
- 读取：F1 经 `FileStorage` 的本地读盘/COS 通道取流；不做"服务端自回环 HTTP 拉自己的文件"（坑 #26）。
- 物理清理：软删满 90 天的记录，`FileStorage.delete(file_key)` + 删表行；删除失败仅告警不阻断。
- COS 直链（`presignedDownloadUrl`）**本期不用于真题**：学员预览必须经 F1 签名流（防盗链是硬需求）；管理端"预览"也走 A2 换签名，不暴露 COS 直链。

### 2.4 上传校验（后端强制，单测全覆盖）

| 校验 | 规则 | 失败码 |
|---|---|---|
| 扩展名 | 仅 `.pdf`（大小写不敏感） | 415 |
| Magic number | 首 5 字节 `%PDF-`（先读流头再落盘，内存缓冲前 5 字节即可） | 415 |
| 单 PDF 大小 | ≤50MB（代码层，读 `Content-Length` + 实际计数双保险） | 413 |
| zip 大小/条目 | ≤200MB、≤100 个条目、拒绝目录穿越条目（`..`/绝对路径） | 413 / 400 |
| 恶意 PDF | 扫描 `/JavaScript`、`/Launch`、`/EmbeddedFile` 关键词，命中记 WARN 日志并记录审计（一期不拦截，留观测） | — |
| 去重 | 同 exam_id 下同 file_md5 且未删除 → 409（提示已有标题）；同名同年份不同 MD5 允许并存 | 409 |
| 0 字节/坏 zip | 400 + 明确 msg | 400 |

### 2.5 文件名元数据解析器（纯函数，规则与详规 §4.1 逐条对齐）

输入文件名（去扩展名）→ `{title, year, subject, metaPending}`：

1. 年份 `/(19|20)\d{2}/` 首个匹配；
2. 科目关键词 `理论|实操|综合`（仅记录展示，不入筛选）；
3. 工种等级 `^(.+?)（(.+?)）(五级|四级|三级|二级|一级)`；
4. 分隔符清理（首尾 `-_【】[]（）()`）；
5. year 或工种等级解析不出 → `metaPending=1`（title 兜底为清理后的文件名主体）。

### 2.6 签名与文件流 F1

- 算法：`sign = HMAC-SHA256(secret, id + "." + t)`，十六进制；`t` = 过期 Unix 秒，有效期 **600 秒**；secret 配置项 `platform.zhenti.sign-secret`（dev 默认值仅本地，生产走 env，不入库）。
- 校验：`id+t` 绑定（防 A 签下 B）、`t` 与服务器时钟偏差 >60s 拒绝、HMAC 常量时间比较。
- F1 响应：`200 application/pdf`，`Content-Disposition: inline`，`Cache-Control: private, no-store`；**支持 `Range`**（`206` + `Content-Range`，pdf.js 分片必需）；`deleted=1` → 404，下架 → 仍可访问至签名过期，无签名/错签/过期 → 403。
- F1 **不校验登录态**：在 `SecurityConfig` 将该路径加入 permitAll 清单（参考 `/appsmart/**` 的挂法，`AppTokenAuthFilter` 之前的链路不受它影响，因为 F1 只信签名）。

### 2.7 A1/A2（App 侧，走 AppTokenAuthFilter 链）

- 挂 `/appzhenti/list`、`/appzhenti/preview`，加入 SecurityConfig permitAll（App itoken 由 `AppTokenAuthFilter` 校验，与 `/appsmart/**` 同模式）。
- A1：仅 `status=1 AND deleted=0`，排序 `year DESC, sort ASC, id DESC`；出参 id 字符串化（R2）。
- A2：出参 `{viewerUrl, title}`；`viewerUrl = {origin}/pdf-viewer/viewer.html?file={urlencode(/appzhenti/file/{id}?sign=..&t=..)}`；**viewerOrigin 配置化**（`platform.zhenti.viewer-origin`，默认 `https://java.app.gjjd168.com`），方便测试环境换域。
- 埋点：A2 调用写 INFO 日志（学员 id、真题 id、时间），支撑"哪份真题被看得最多"统计（主方案 §2 教育产品建议）。

### 2.8 配置与部署参数

| 项 | 值 | 位置 |
|---|---|---|
| multipart | max-file-size 200MB / max-request-size 210MB | application.yml |
| nginx | `client_max_body_size` 50M → **210M**（或仅 `/api/appzhenti/admin/` location 放开） | deploy/nginx.conf，reload 生效 |
| 响应包络 | `ApiResponse`，成功 code `"0"` | 既有 |
| viewer | `public/pdf-viewer/` 随 admin dist 发布；viewer.html 移除 download/print 按钮与对应菜单项 | admin-web（§3.4） |

### 2.9 异步批量导入（遵守异步红线）

- >50 文件转异步：HTTP 线程捕获 tenantId/userId 入参传递，Worker 线程 `TenantContextHolder.setTenantId` + `finally clear()`，**整条链禁调 SecurityContext**；线程池拒绝策略 `AbortPolicy`。
- 进度即状态：`exam_zhenti_import_log` 行内更新 total/finished/status，D6 轮询读表（不自建内存态）。
- 同步模式（≤50）直接返回 results。

### 2.10 审计与状态机

- D2/D3/D4/D5 全部 `@AuditLog`（操作人/时间/目标 id/变更前后值）。
- 状态机（详规 §4.3）：上传默认**上架**；下架后 A1 不返回、管理端可见可再上架；删除=软删（`deleteById`，禁止 `setDeleted(1)+updateById`），不可再上架，F1 立即 404。

### 9.2 落地时确认/偏差（均为必要调整）

1. **分页出参**：仓库实际 `PageResponse` 为 `{items,page,pageSize,total}`（与 AGENTS.md 描述的 records 未对齐，直接改会波及 100+ 既有接口）。本模块新增 `ZhentiAdminPageVO` / `ZhentiAppListVO`，D1/D6/A1 输出 R1 要求的 `{records,total,page,size}`，零回归。
2. **新增 D7 `POST /appzhenti/admin/preview`**：管理端 Bearer 是 Sa-Token，无法通过 `AppTokenAuthFilter`；详规 §2.1 明确允许“管理端专用签名接口”。
3. **D1 额外返回 `years`**：年份下拉直接复用当前考试项目的去重年份，避免新增接口。
4. **新增 V20261018_004**：历年真题页的考试项目下拉复用 `/training/exam-lists`（需 `train:exam-list:view`）。003 只按 `exam:question:view/exam:make-plan:view` 授角色，故 004 把「已持有考试计划查看权」的角色补齐菜单与两个权限码（幂等）。
5. **multipart 未下调**：全局原本已是 1GB（高于方案 200MB）。下调会误伤其它大文件上传，故保留；50MB 单 PDF / 200MB zip / 100 条目全部在代码层强制，nginx 已调 210M。
6. **失败行“补录重试”**：解析失败的文件已入库（metaPending=1），重试走 D4 补录；类型非法/超限/重复等未入库的硬失败提示重新上传（zip 未保留，无法二次取文件）。
7. **审计“前后值”**：`@AuditLog` 记录操作人、目标 id 与入参（即变更后值）；变更前值可由 D1 现状与服务日志回溯。`AuditLogAspect` 补充了从入参 DTO 的 `id()`/`getId()` 解析目标 id。
8. **清理任务表锁**：JdbcTemplate 原生 SQL 跨租户扫描（逻辑删除会自动追加 deleted=0），单批 200 条、删除失败仅告警。
