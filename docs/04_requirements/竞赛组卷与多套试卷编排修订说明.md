# 竞赛组卷与多套试卷编排修订说明

> 日期：2026-09-17
> 适用范围：竞赛理论、实操组卷计划及赛段编排。本文覆盖“竞赛实操自动组卷”，不改变已发布历史快照。

## 一、总体口径

1. 组卷计划保存整卷参数：细目表版本、生成套数、整卷总分（默认 100 分）、考试时长、及格分、考试类型、标题及确定性随机种子。实操蓝图计划不再接受主题题量、主题分值或手工选题作为组卷输入。
2. 实操蓝图是结构和分值权重的唯一来源。计划保存时锁定细目表版本；预检、结构预览、正式生成和多套试卷生成必须经过同一个 `CompetitionPracticalMakeExamAllocator`。
3. 实操蓝图计划可以生成 1～50 套试卷。单套使用 `P`，多套使用 `P1`、`P2`……；每套快照独立保存，历史 `A/B/P` 快照只读兼容。
4. 理论组卷继续沿用题型、题量、单题分值和难度规则，仍只生成一套；本次实操调整不得改变理论分配口径。

## 二、实操计划字段

实操蓝图计划只编辑以下整卷字段：

- 当前赛事工种等级对应的已锁定细目表版本；
- 生成套数、整卷总分、考试时长、及格分、标题、考试类型和备注；
- 可选确定性随机种子。未填写时由赛事范围、蓝图、标题、时长、总分和套数计算稳定种子并落库。

`details`、`topicRules`、主题题量和主题分值不参与实操蓝图组卷。旧客户端仍可提交 `topicRules`，后端只记录 warn 日志并忽略；系统最多把最终已生成的结构结果以每单元 `questionCount=1`、目标分值、顺序写入旧规则表，作为审计投影，不能反向驱动组卷。

考试时长是计划级独立参数，不自动被某一题覆盖。每套所选题目的参考时长求和并返回；超过计划时长时给出预警，是否允许继续由业务确认。

## 三、细目表结构归一化

### 3.1 输入结构

归一化节点至少包括：`id`、`parentId`、`nodeLevel`（仅展示）、`code/fullCode`、`name`、`weight`、`selectMode`、排序号。算法不假定“三级主题”或固定层数；题库绑定必须指向当前蓝图版本的有效末级叶子节点。

系统同时支持：

- 竞赛实操标准 13 列模板（一级/二级/主题/末级考评点）；
- 标准复合四级模板（一级/二级/技能主题/末级考评点）；
- 自定义四级及其他任意深度的父子节点结构。

Excel 合并单元格先向下填充值，再构建父子树；主题、技能要求等模板列只影响导入映射，不影响组卷算法的层级判断。`questionQuota` 只用于题库库存、覆盖率和候选数提示，绝不作为一张试卷的题数。

### 3.2 选择模式

将参与组卷的结构节点归一化为两种模式：

- `REQUIRED`：每个必考结构节点是一个最终组卷单元；
- `CHOOSE_ONE`：同一业务范围、同一精确父节点下的可选兄弟结构节点合并为一个选择组，最终只选一个结构候选。

中文及英文模式按以下规则识别：`必考`、`全部必考`、`必选`、`全部`、`required`、`mandatory` 归为 `REQUIRED`；`任选一项`、`任选1项`、`任一`、`任选`、`选考`、`任意一项`、`任意`、`optional`、`chooseone`、`choose_one`、`choose-one` 归为 `CHOOSE_ONE`。空白或未知模式不猜测为必考，直接返回错误。可选节点不得跨父节点合组。

组卷单元由上下级选考关系共同确定，不能固定绑定到某个层级名称：

- 上级只是汇总节点、下级为 `REQUIRED` 时，每个下级必考节点分别形成一个题位，并直接使用该节点自身的整卷绝对权重；上级汇总权重不得再次相乘。
- 上级为 `REQUIRED`、同一上级下的直接下级为 `CHOOSE_ONE` 时，上级只形成一个必考题位，下级节点是该题位的候选范围。系统先任选一个下级范围，再从其末级考评点绑定题库中抽取一道完整实操题。
- 上述任选组使用父级必考范围的整卷权重，各候选继承该组权重；多个候选的权重不能相加，也不会生成多道题。

标准 13 列模板存在两种实际数据形态：G 列为“设备准备”等短名称时，G/H/I 可构成下层组卷范围；G 列为 `1.1.1能……` 等编号技能要求时，G 只是 E/F 二级范围的属性，E/F/H/I 才是可选择的二级节点。解析器必须区分两者。最终题位权重合计必须为 100%。

## 四、候选题与组卷规则

1. 每个最终单元选择一条完整实操题；题目必须启用、未逻辑删除、属于当前租户和赛事工种等级、存在当前蓝图版本绑定，且绑定节点是当前结构下的有效叶子。
2. 题目必须有合法原始总分和正整数参考时长。原始总分为空、零、负数或时长无效的题目排除并在预检中说明。
3. 一张试卷内题目不得重复。多套生成优先避免跨套重复；题库不足时按确定性顺序复用并返回“跨套去重不足”预警。
4. 试卷题数等于归一化后的最终必考题位数，与叶子节点数量、`questionQuota`、候选题数量无关。例如：
   - “氧化铝焙烧工四级”细目表的下层 14 个范围均为必考，因此每套固定 14 题，按 8/4/4/4/1/2/2/10/15/30/6/4/5/5 分组成 100 分；
   - “矿山生产集控员二级”细目表的一级 A/B/C/D 均为必考，二级均为任选一项，因此每个一级只形成一个题位，每套固定 4 题。A 题位从其二级 A/B 中任选一个范围，B、C、D 同理，四题按一级权重计 10/40/40/10 分。
5. 若某个必考单元没有候选题，或某个选择组所有候选均无可用题，预检和正式生成均失败；不能把整组静默跳过。

预检返回归一化结构预览，包括选择组、选择模式、结构路径、组权重、目标分值、候选节点、候选题数、选中的完整题目、原始总分、`scoreScale`、参考时长、警告和错误。正式生成使用相同输入和种子，以保证预览与生成一致。

## 五、分值与评分快照

1. 计划总分和目标单元分值最多保留两位小数。采用最大余数法及稳定顺序补余数，确保每套目标单元分值之和精确等于计划总分。
2. 每个单元保存 `sourceTotalScore` 和 `scoreScale = targetScore / sourceTotalScore`。来源总分为空、零、负数或不合法时，该候选不能入卷。
3. 评分项中的普通配分项按 `scoreScale` 缩放，保留两位小数；最后一个普通配分项承担舍入差额，使缩放后的普通评分项合计精确等于目标单元分值。
4. 评分方式、扣分上限、扣分步长、评分标准、考核内容、否定项/终止语义和“不配分”标记一并进入快照；不配分或否定类结构不得被当成普通配分项。缩放后的评分项仍须满足正分、扣分规则和执行端校验。
5. 计划时长不参与分值缩放。选题参考时长求和写入预检结果和快照生成日志；超过计划时长只产生可见预警。

## 六、兼容、权限与发布

- 已发布计划、已发布快照以及历史 A/B/P 数据不重新计算、不因新蓝图修改而变化。
- 无蓝图的历史实操计划继续支持显式选择一条实操题的单题兼容路径；新实操自动组卷应使用蓝图路径。
- 题库绑定、节点、候选题和快照查询均按租户、赛事范围、启用状态和逻辑删除条件过滤；后端是权限和数据隔离的最终裁决点。
- 雪花 ID 在计划、蓝图、节点、题目及预检结构响应中按字符串返回，避免前端 JavaScript `Number` 精度损失。
- 新增 `random_seed` 字段及多套快照代码约束由新的 Flyway 迁移提供；不修改已应用迁移。

## 七、验收重点

至少覆盖：标准 13 列的“短名称下层范围”和“编号技能要求属性”两种形态、自定义四级导入；14 个下层必考范围生成 14 题并组成 100 分；一级 A/B/C/D 必考且二级任选时生成 4 题并按 10/40/40/10 分组成 100 分；必考单元权重不与上级汇总权重重复相乘；任选候选权重不累加；空白或未知模式报错；`questionQuota` 不改变题数；有效叶子绑定和题库不足；同卷去重与跨套复用预警；确定性种子；两位小数精确守恒；原始分值缩放和普通评分项差额补偿；计划时长超限预警；历史无蓝图兼容；理论组卷回归；后端编译、相关 JUnit、前端类型检查和组卷页面测试。
