# 职业标准驱动教材生成 · 专家共创深化方案

> 版本：v0.2　日期：2026-08-21
> 定位：对《职业标准驱动教材生成功能方案》v1.0 的深化，不推翻 v1.0 的表结构与 M1–M3 一期范围，仅把"专家角色"从**审定者**升级为**主笔**，把平台/模型从"代笔"降级为**研究助理 + 写手**。
> **v0.2 变更说明（STORM 8 视角评审后修订，评审记录见 §8）**：
> - 砍掉：试教验证看板（改手工试读）、DCS/槽控机数据入库、现场影像入库（延后）、自建语音转写管道、自动脱敏设想、`textbook_source` 独立全量表（改复用 knowledge 模块）
> - 简化：DIF 三列打分 → "写透/删除"两种标记；scope 三态 → 两态（deprecated 改内部批注）；8 个模型工具 → 3 个后端能力；素材收集 12 类 → 一期只收 3 类；口述转写 → 只收外部转写文本
> - 新增：素材四级密级 + 授权字段（合规前置条件）

## 0. 角色重定义（深化的核心）

| 角色 | v1.0 口径 | 本深化方案口径 |
|---|---|---|
| 专家 | 评审大纲、审定/打回正文、确认字数系数 | **主笔**：定结构、写要点、补经验、选案例；模型产出物只是其草稿。**设计原则：专家只动嘴和动笔——凡要专家逐条点鼠标的设计都会烂尾** |
| 编辑/教研岗（新增） | 无 | 承担素材分类、打标、可读性/术语检查结果处理等"点鼠标"工作，不进专家界面 |
| 模型/平台 | 按节直写正文，专家判合格 | **研究助理**：整理素材、整理转写稿、扩写要点、检查文本——**不替专家做决定，无专家要点不直写** |
| 正文来源 | 标准条目 + 模型生成 | 标准条目（骨架，v1.0 不变）+ **原始素材（血肉）** + **专家经验（灵魂）** |

v1.0 §8.2 的五条护栏（字数、覆盖、术语、禁区、留痕）全部保留，触发点从"模型生成后"前移到"专家写作过程中"。

## 1. 顶尖专家编写教材时会做的事（v1.0 未要求项）

有色金属/关键金属领域的顶尖专家（标准起草人、技能大师工作室领衔人、大型铝厂总工程师/生产厂长、鉴定站高级考评员）编写培训教材时，实际会做而 v1.0 未覆盖的事：

### 1.1 下现场做岗位写实

进电解车间跟班观察真实操作——换极、出铝、抬母线、阳极效应处理、异常槽况处置——记录实际作业顺序、动作要领、耗时、劳保穿戴、几人配合。标准的"能更换阳极"是**结果性表述，不含怎么做**；教材的"怎么做"只能来自现场写实（观察记录 + 摄像 + 访谈在岗工人）。没有这一步，教材写出来的是"标准的同义改写"，工人看了不会干活。

### 1.2 区分内容的教学权重

专家心中对每个任务有一杆秤：难度、重要性、频率。**低频高危操作（如漏槽应急处置）反而要写透**——出了事就是人命；高频例行操作可略写。v1.0 §7.3 用"条目数占比"分节字数，会让救命内容与例行操作篇幅相近。
**落地口径（v0.2 简化）**：不做 DACUM/DIF 系统化打分（专家不会逐条点鼠标），只在大纲页提供两种标记——**「写透」**（该节字数上浮，由专家用 v1.0 §7.4 人工微调落实）和**「删除/了解即可」**；其余条目数兜底。DACUM 研讨作为线下方法保留，不进系统。

### 1.3 提取默会知识（认知任务分析）

老师傅"看火苗颜色判断槽膛冷热""听声音预判阳极效应""凭手感判断电解质黏度"——这类**诊断性、感官性经验写不进国家职业技能标准**，但它是顶尖专家与普通讲师的分水岭，也是教材对工人最有价值的部分。方法：关键事件访谈（"讲一次你判断失误/判断对了避免事故的经历"），整理成"征兆 → 判断 → 处置"决策链。**获取形态：专家口述（自用手机录音+讯飞听见转写），平台只收转写文本**——专家评审确认：老师讲 20 分钟比写 3000 字轻松十倍，这是主笔模式的主入口。

### 1.4 界定三类内容的边界

- **标准内（考评范围）**：逐条覆盖，与鉴定对齐；
- **超标准但岗位必需**：标准 2020 版滞后于现场的内容——大型预焙槽新结构、智能化槽控、新环保排放要求；不教工人上岗就抓瞎；
- **标准已滞后/现场已不用**：审定阶段直接删节（v0.2：不再做 deprecated 入库标注——评审视角指出，正式材料中公开指摘现行国标"淘汰"会被打回）。

### 1.5 建案例库

成人职业培训的主要载体是案例不是条文——一线工人评审确认：**事故案例和虚惊事件是全部功能中对他们最值钱的**。收集：事故案例（应急管理部公开事故通报）、违章案例、优秀操作案例、虚惊事件（差点出事但避免的，教学价值极高）。每个案例按 背景 → 经过 → 原因 → 教训 → 对应标准条目 五段式改写。
**来源约束（v0.2 合规修订）**：一期只用①应急管理部/行业公开通报②企业安全部门书面审批的脱敏稿；企业内部事故汇编原文、含责任认定的材料不收（详见 §2.1 密级）。

### 1.6 按工作过程重组教学顺序

不按标准表格的行政顺序排章，而按工人**真实成长路径**：认识设备与物料 → 交接班 → 正常操作 → 参数调整 → 异常识别 → 应急处置。已出版的《铝电解工职业技能鉴定培训教材》正是这个体例（"第一篇 预焙槽操炉 / 第一章 操炉准备工作 / 第一节 交接班"，每节含学习目标、工作程序、重点难点）。v1.0 §3.2 的骨架映射兼容，但**顺序开放给专家拖拽重排**（sort_no 动、source_no 不动，保留与标准条目的溯源）。

### 1.7 控制可读性与配套设计

面向初中文化水平的一线工人：术语首次出现必解释、长句拆短、口诀化、每页有图、重要安全事项加警示框。配套：章首学习目标、章末习题（题型对齐鉴定题库）、实操训练指导单。一线工人评审确认：可读性检查与配图点位是 8 个工具中对终端学员价值最直接的两个，优先级应靠前（执行者为编辑岗，不是专家）。

### 1.8 试读与修订

初稿拿给目标学员（新工人）试读，收集"哪里看不懂"后修订。**v0.2：不建试教看板，试点阶段手工执行**——导出章节给 3–5 个新工人读，编辑手工记录看不懂的点位；柯氏四级/对照班等正式效果验证单独立项（见 §6）。

## 2. 专家会用的原始素材（一手素材，非已整理素材）

v1.0 的唯一输入是《国家职业技能标准》docx——那是**二手的、压缩后的考评依据**。专家编写教材的真实素材起点：

| 类别 | 具体素材 | 一期收不收（v0.2 白名单） |
|---|---|---|
| 公开素材 | 国家/行业标准法规原文、应急管理部公开事故通报、职业分类大典 | **收**（无授权障碍） |
| 专家自带 | 老教材、内部培训讲义、历届 PPT、技师论文、专家个人笔记 | **收**（专家个人授权） |
| 访谈转写 | 技能大师口述转写文本（专家自行转写）+ 授权书 | **收**（只存转写稿，不留原始录音） |
| 企业文件 | 工艺技术规程、SOP、安全操作规程 | **暂缓**：脱敏（删参数值）+ 企业书面审批后逐类开放 |
| 案例档案 | 企业内部事故汇编、虚惊事件记录 | **暂缓**：去标识化 + 安全部门审批文号后开放 |
| 鉴定档案 | 常见失分点统计（聚合数据，匿名化） | 暂缓，随统计功能对接 |
| ~~数据记录~~ | DCS/槽控机参数曲线、报警记录、生产日志 | **不收**——EHS 评审确认：曲线形态即核心工艺 know-how，脱敏也救不回来，改用专家手绘示意图 |
| ~~设备图纸~~ | 厂商技术手册与图纸 | **不收**——第三方知识产权，企业无权转授权；用公开规格或自制示意图替代 |
| ~~现场影像~~ | 含人脸/装置布局的照片视频 | **延后**——PIPL 肖像授权成本不可控，试点分册完成后再议 |

### 2.1 素材四级密级（合规前置，EHS 评审输入）

所有入库素材强制标注：**公开 / 内部脱敏 / 秘密 / 核心秘密**。
- **核心秘密（DCS 数据等）不出厂、不入库**；秘密级（工艺参数段）不入库，仅专家线下查阅；
- **只有"公开 + 内部脱敏"两档允许进入 LLM prompt**（要点扩写/案例改写的前置过滤规则），涉参数内容强制走专家自写——这是本方案最大的泄密通道，必须堵住；
- 脱敏由企业安全部门线下执行 + 书面审批，**平台不做自动脱敏**（规则各厂不同，漏一处即事故）；
- 素材按租户严格隔离，不跨分册复用；入库素材记录**密级 + 授权状态 + 审批文号**三字段，缺一不可。

## 3. 专家会用的方法与工具（传统 + 平台赋能）

### 3.1 方法论（线下方法，不全部进系统）

| 方法 | 干什么 | 进不进系统 |
|---|---|---|
| DACUM 研讨 | 专家集体拆解职责/任务 | 不进——线下开会，结论由编辑代录为"写透/删除"标记 |
| 认知任务分析 / 关键事件访谈 | 提取默会诊断经验 | 半进——口述转写文本进平台，模型整理决策链草稿，专家确认 |
| 工作过程系统化 | 按真实工作过程排章 | 进——大纲页拖拽重排 |
| 柯氏四级评估 | 验证教材效果 | 不进本期——试点阶段手工试读（§1.8），正式验证单独立项 |

### 3.2 传统工具（专家自带习惯，不替代）

Word 修订、纸笔（**要点可拍照上传**）、腾讯文档/飞书、XMind、Visio/亿图/CAD、知网、讯飞听见（专家自行转写）。平台只做导出兼容（docx 带修订痕迹、图片包导出），**不自建语音转写**。

### 3.3 平台模型工具（v0.2：8 个入口归并为 3 个后端能力）

架构师评审结论：8 个工具后端同构，归并为 3 个；前端可保留分类入口。

| 后端能力 | 覆盖的原工具 | 使用者 | 说明 |
|---|---|---|---|
| **① 辅助写作**（多模板草稿接口） | 访谈整理、要点扩写、案例改写 | 专家 | 同一管线：输入文本/要点 → FaqLlmClient → ai_generation_draft 留痕 → 专家修订留痕；只是 3 套 prompt 模板 |
| **② 文本检查**（报告接口） | 可读性检查、术语对齐、配图点位 | **编辑岗** | "输入正文出报告"单向输出：未解释术语、超长句、术语密度、与标准不一致术语、"此处应配图"清单；模型不改正文 |
| **③ 素材检索** | 素材工作台 | 专家只用"搜"，编辑管"理" | 复用 knowledge 模块检索（见 §5.1） |

**专家界面只保留 3 个主笔入口：口述转写整理、要点扩写、案例改写**——专家评审原话："其余五个看都不会看，别占我的界面和工时。"

红线（沿用 v1.0 §8.2 并强化）：工艺参数、安全规程、法规条文**只引用已入库素材原文**，且仅"公开+内部脱敏"两档可进 prompt（§2.1）；无从引用时输出 `[待专家补充]`；所有产出标来源/模型/时间/操作人；发布前必须人工确认。

## 4. 除需求方与方案作者外，证明方案可实施且教材有效的第三方证据

### 4.1 制度依据

人社部实行"国家基本职业培训包"制度，职业技能等级培训须按"国家职业标准 + 职业培训包 + 职业培训教材"统一内容（见[五部门关于长期照护师培训的通知](https://www.cncaprc.gov.cn/xxzcfg/770341.jhtml)）；人社部教材工作委员会对教材有组织化遴选评审，已公布 [429 种国家级教材目录](https://www.mohrss.gov.cn/xxgk2020/fdzdgknr/qt/gztz/202205/t20220507_446645.html)。**"标准 → 教材 → 评审"的通道客观存在，本方案是在企业内复刻这条已验证通道。**

### 4.2 同类先例

中国劳动社会保障出版社"国家职业技能等级认定培训教材"系列由人社部教材办公室**组织专家编写**（如[电工（初级）](https://www.bookskys.com/books/book_893862479.html)）——"专家主笔 + 组织化审定"是通行模式。铝电解工已有鉴定培训教材实物（[初级工版](https://www.renrendoc.com/paper/265981900.html)），其"工作过程排章 + 学习目标 + 工作程序 + 重点难点"体例可直接对标。

### 4.3 方法论先例

DACUM 与"工作过程系统化"课程开发在人社系统技工院校推行多年，有成熟方法论与外部师资可请。

### 4.4 效果自证（单独立项，不占本期资源）

试点分册上线后：教材章节 × AI同步学错题数据对齐（呼应 STORM 分析 G1 成绩回流）、A/B 班对照、考证通过率对比。本期只做手工试读（§1.8）。

### 4.5 可实施性的内部证据

v1.0 §1.1 的复用资产已经细目表/AI 课件两条产品线验证；v0.2 收敛后，新增能力全部落在 knowledge / file / question_bank / ai_generation_draft 四个既有模块的薄封装上（架构师评审确认），无新技术风险。

## 5. 对 v1.0 的功能改动清单（v0.2 收敛版）

| # | 改动 | v0.2 口径 | 量级（工程评审） |
|---|---|---|---|
| 5.1 | 素材库 | **不建 `textbook_source` 全量表**——复用 knowledge 模块（kb_space 按分册建空间、Tika 解析、切片、检索、溯源引用、ACL 全有），仅加一张薄关联表（分册 ↔ 文档/切片 ↔ 正文段落引用）+ 密级/授权状态/审批文号三字段。一期只收 §2 白名单三类 | 5–7 人天 |
| 5.2 | 大纲页标记 + 重排 | **DIF 三列打分取消**——改"写透 / 删除"两种标记（默认不填），篇幅调整走 v1.0 §7.4 人工微调通道（`words_manual` 已存在）；拖拽重排只动 sort_no | 4–6 人天 |
| 5.3 | 专家主笔 | 三模式收敛：①自写 = 编辑器（不单独立项，v1.0 §9.3 已有 content_md/status 流）；②**要点扩写（核心，唯一待验证假设）**：支持纸笔要点拍照/粘贴文本输入；③口述转写 = **只收外部转写文本**，不建录音/ASR 管道 | 8–10 人天 |
| 5.4 | `textbook_case` 案例表 | 保留（五段式结构化利于跨节复用，工人视角判定为最大价值项）+ **审批文号字段**；来源白名单（§1.5） | 4–5 人天 |
| 5.5 | `scope` 字段 | **两态** standard/extended + 导出区别排版；deprecated 取消（审定阶段直接删节） | 2–3 人天 |
| 5.6 | 习题映射 | 复用 theorygen 出题管线（`exam_theory_gen_draft` 已是完整"知识点→LLM 出题→草稿"通道），只做按节过滤拉取 + 题型对齐标注；**禁新写出题引擎** | 6–8 人天（M5） |
| ~~5.7~~ | ~~试教验证看板~~ | **移出本期**，试点阶段手工试读（§1.8）；正式效果验证单独立项 | 0 |
| 5.8 | M4 范围调整 | 保留：全自动按节生成降级为备选（不建独立入口），优先交付专家主笔工作台；护栏从"机器拦截"变"提示专家"，实现难度下降 | 见 5.3/5.4/5.5 |

**新增工作量合计约 25–35 人天**（工程评审口径；v0.1 全量口径 70+ 人天，一期边界会被塞爆）。

## 8. STORM 评审记录（v0.1 → v0.2 的依据）

8 个独立视角（工程交付、领域专家本人、买单方、一线工人、企业 EHS 合规、平台架构师、教材审定、减法红队）对 v0.1 做质询评审，每问三档判定（保留-可实施 / 保留-但需简化 / 砍或延后）。**8 视角全部判"需瘦身"，无一"做不了"，无一"全保留"**。

跨视角一致结论（≥3 视角独立命中）：

| 结论 | 命中视角 | v0.2 处置 |
|---|---|---|
| 试教看板移出本期（不产出教材，依赖运营周期） | 工程/专家/买单方/工人/架构师/审定/红队（7） | §5.7 移出，手工试读替代 |
| DIF 三列打分专家不会用（DACUM 是开会不是点鼠标） | 专家/买单方/工人/审定/红队（5） | §5.2 改"写透/删除"标记 |
| 口述是专家最顺的输入，但平台不自建转写 | 专家/工程/架构师/审定/红队（5） | §5.3 只收转写文本 |
| 要点扩写是最不能砍的核心（唯一待验证假设） | 工程/专家/买单方/审定/红队（5） | M4 核心，§6 验收口径 |
| 素材库须有密级与授权，DCS/影像/图纸不可入库 | EHS/审定/买单方（3） | §2 白名单 + §2.1 四级密级 |
| `textbook_source` 独立表是重复建设 | 架构师/工程/红队（3） | §5.1 复用 knowledge |
| 8 工具后端同构应归并，专家界面只留 3 个 | 架构师/专家/红队（3） | §3.3 |
| 案例库是终端学员最大价值项，但来源须白名单 | 工人/EHS/审定（3） | §5.4 保留 + 审批文号 |

分歧点及裁决：

- **口述转写**：专家视角评为"最顺"，红队评为"砍"——裁决：保留模式、砍自建 ASR 管道（专家用讯飞听见，平台收文本），两方诉求同时满足；
- **案例表**：红队认为"可先写进 content_md 不建表"，工人视角判为"最不能砍"——裁决：建表（五段式结构化成本仅 4–5 人天，跨节复用价值真实），但来源收窄；
- **deprecated 标注**：v0.1 设计为三态，审定视角指出指摘现行国标会被评审打回——裁决：取消，审定阶段直接删节。
