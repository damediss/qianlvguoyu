# 跟班考勤「导出考勤表」功能方案

> 状态：待审核（2026-10-14）
> 位置：培训管理 → 运营流程 → 跟班 → 考勤页签
> 口径来源：用户四项拍板（矩阵式 / 全部考勤日期 / 按日合并 / 身份证+签名+汇总列）

## 1. 需求背景

跟班考勤页签当前只有「导入考勤表」（吃人社/培训平台 xlsx）和单条 出勤/缺勤 登记，没有导出能力。班主任/监管上报需要纸质考勤表打印签字，要求一键导出矩阵式考勤表。

## 2. 已确认口径

| 决策点 | 拍板 |
|---|---|
| 表格形态 | **矩阵式**：每行一个学员、每列一个考勤日期 |
| 日期范围 | **该班全部考勤日期**（`train_attendance` 中有记录的日期，升序） |
| 课次粒度 | **按日合并**：同一天多个课次合并一格，状态取最优，优先级 出勤(1) > 迟到(2) > 早退(3) > 缺勤(0) |
| 学员列 | 序号 / 姓名 / 手机 / **身份证号** |
| 行末列 | 出勤天数 / 迟到 / 早退 / 缺勤 / **已上课时 / 完成率**（与页面同口径）/ **签名（空白列）** |

合并口径与前端 `FollowClassWorkbench.mergeDayAttendanceRows` 一致（`attendanceStatusRank`：1→4、2→3、3→2、0→1，取最大；无任何记录则空格，不显示「未登记」字样）。

## 3. 表样

```
        职业技能培训考勤表（班级：XXX班）                        导出时间：2026-10-14
序号 | 姓名   | 手机        | 身份证号           | 10-08 | 10-09 | 10-10 | ... | 出勤 | 迟到 | 早退 | 缺勤 | 已上课时 | 完成率  | 签名
1    | 黄毅坚 | 15878607437 | 4526**********1234 | 出勤  | 缺勤  | 出勤  | ... | 12   | 0    | 0    | 1    | 32.0     | 25.4%   |
2    | 唐秀锡 | 13667769235 | ...                | 出勤  | 出勤  |       | ... | 13   | 0    | 0    | 0    | 0.0      | 0.0%    |
```

- 日期列头格式 `MM-dd`（跨年时 `yyyy-MM-dd`），窄列。
- 无考勤记录的格子留空（不填「未登记」）。
- 状态文案：出勤 / 迟到 / 早退 / 缺勤，不加颜色（打印友好）。
- 签名列整列空白、加宽，供打印手签。

## 4. 后端设计

### 4.1 接口

```
GET /training/classes/{classId}/attendances/export
权限：train:attendance:export（新增，见 §6）
响应：xlsx 附件流，Content-Disposition: attachment; filename*=UTF-8''...
文件名：考勤表_<班级名>_<yyyyMMdd>.xlsx
```

- 放在 `TrainAttendanceController`（与考勤域同控制器）。
- 导出走读事务，复用现有 mapper 查询，不加异步（班级考勤量级小，同步导出足够；将来如需大批量再按「快速返回 + 异步 + 轮询」拆）。

### 4.2 数据装配

新增 `TrainAttendanceExportService`（trainingdepartment.service 包）：

1. **班级**：`TrainInfoClassMapper.requireClass(classId)`（班级名/展示名解析照搬 `GraduationCertifiedRosterExportService.resolveClassDisplayName`）。
2. **学员**：`TrainPeopleListMapper` 查 `train_class_id=classId AND type='student' AND deleted=0`，按 id 升序 → 序号 / 姓名 / 手机 / 身份证号。
3. **考勤**：`TrainAttendanceMapper` 查该班全部未删记录（不按 tenant 手拼，MyBatis-Plus 多租户插件自动过滤；仅做与 `TrainFollowClassHourApplicationService.compute` 同款的 `tenantId == null || equals` 内存兜底）。
4. **课时**：复用 `TrainFollowClassHourApplicationService.compute(classId, tenantId)` 得每学员 `attendedHours / completionRate`（与页面「已上课时 / 完成率」完全同口径，不另写一套计算）。
5. **矩阵装配**：
   - 日期列 = 考勤记录去重日期升序；
   - 每学员 × 日期：按 §2 优先级取最优状态，计数 出勤/迟到/早退/缺勤 天数（按原始课次行计次还是按合并后计次？——按**合并后**计，与格内文字一致）；
   - 无任何记录的学员行：状态格全空、统计列全 0、课时列照常（按课时服务口径算，可能非 0）。

### 4.3 写出

参照 `GraduationCertifiedRosterExportService` 的模板范式：

- 模板：`resources/templates/attendance-sheet.xlsx`（手工排好标题行、表头样式、列宽、边框，程序只填数据行；数据行数不够时用 `ensureDataRows` 同款逻辑插入行——照抄该服务的既有实现，不新造轮子）。
- 无模板可用时降级为纯代码建表（首版直接做模板）。
- 班级无学员 → 400「该班级暂无学员，无法导出考勤表」；有学员但零考勤记录 → 照常导出（只有学员列+统计列，日期列零列，文件里写明「暂无考勤记录」于标题下，或直接 400——**倾向照常导出空表**，打印后手工勾签也是真实场景，待审核确认）。

## 5. 前端设计

- 位置：考勤页签「导入考勤表」按钮右侧，加「导出考勤表」按钮（`Button icon={<DownloadOutlined/>}`，权限 `train:attendance:export` 控制显隐）。
- 交互：点击直接触发下载（window.open 或 a[download] 指向接口 URL，带 token 的请求头方式——按现有导出按钮的既有写法对齐，如获证名册导出按钮），无弹窗（范围已拍板=全部日期）。
- API 层：`api/training.ts` 加 `exportAttendancesUrl(classId)` 或复用现有 download 工具。
- 按钮仅在班级有学员时可用（与需求描述「有学员数据的班级」一致：无学员禁用并 tooltip「班级暂无学员」）。

## 6. 权限与迁移

- 新权限码 `train:attendance:export`（导出考勤表），挂在既有菜单「考勤管理」(page 4928, `/training/attendance`) 下。
- 权限种子迁移：查询测试/生产两库 `SELECT MAX(version) FROM flyway_schema_history` 取号（共用目录 `_001` 递进），`tenant_id=10159`，三步链 菜单（复用 4928，无需新菜单）→ 权限码 → `sys_role_permission` 给运营角色授权（参照 V20260520_004 的授权写法）。
- 前端菜单无新增（按钮在既有跟班页面内），不需菜单种子。

## 7. 测试与验收

- 后端单测（Mockito，不启 Spring）：
  - 矩阵装配：多课次合并取最优、无记录空格、统计计数与格内一致；
  - 优先级边界（同一天 缺勤+出勤 → 出勤）；
  - 空学员 → 400；零考勤 → 空表可导出；
  - 课时列与 `FollowClassHourCalculator` 口径一致（复用 compute 天然一致，测装配映射）。
- 手动验收：跟班页选一个有课次考勤的班 → 导出 → 打开 xlsx 核对 3 名学员 × 若干日期 与页面逐格一致；打印预览确认签名列与列宽可手签。

## 8. 不做的事

- 不做长表明细 Sheet、不做日期范围选择弹窗（口径已定全部日期）；
- 不改 `FollowClassHourCalculator` 课时计算口径；
- 不对导出文件加水印/密码（含身份证号属敏感，文件由下载者自行保管——如需密码保护可后续加）。
