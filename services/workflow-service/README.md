# workflow-service

工作流服务，统一承载 Flowable 流程和审批能力。

## 职责

1. 管理流程定义、流程实例、审批任务和流程记录。
2. 支撑课程发布审批、认定材料审核、补贴审批、归档流程等业务流程。
3. 向 `platform-api` 提供受控流程接口。

## 边界

1. Flowable 管核心业务流程状态，n8n 只做外部自动化动作。
2. 不把审批状态散落在多个业务模块各自实现。
3. 不让 n8n 成为核心业务状态源。

## 约定

1. 一期可先将 Flowable 集成到 `platform-api`，但接口和数据边界按独立服务设计。
2. 流程文件放入 `workflows/bpmn/`。
3. 健康检查接口预留为 `/actuator/health`。
