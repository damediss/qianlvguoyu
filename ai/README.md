# ai

放 AI 相关资产和配置说明。

AI 能力按“岗位 Agent 工作台 + 项目记忆系统 + MCP 受控工具 + 草稿优先机制 + 人工确认闭环”建设。这里沉淀 Prompt、Skill、Agent 配置和知识库目录规范，不存放真实密钥，不直接堆未整理大文件。

## 子目录

| 目录 | 用途 |
| --- | --- |
| `prompts/` | Prompt 模板 |
| `skills/` | 岗位 Skill，如课程生成、材料检查、项目周报 |
| `agents/` | Agent 配置说明 |
| `knowledge-base/` | 知识库目录规范和索引，不直接堆大文件 |

## 规则

1. 不复制、不依赖、不传播任何疑似泄漏的专有提示词、源码或内部实现。
2. Prompt 必须写明目标、角色、可用资料、可用工具、禁止事项、输出格式和人工确认点。
3. Agent 写操作默认生成草稿，不直接发布、审批、删除或发送正式通知。
4. MCP Tool 必须走平台受控 API，不直连业务数据库。
5. 项目记忆、模块记忆和任务记忆必须有来源、版本、负责人、更新时间和适用范围。
