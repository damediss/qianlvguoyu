# docs

放项目文档、需求资料、正式交付、草稿、台账和技术决策。

## 子目录

| 目录 | 用途 |
| --- | --- |
| `00_index/` | 项目索引、阅读顺序、目录说明 |
| `01_delivery/` | 正式交付文档 |
| `02_drafts/` | 草稿与过程文档 |
| `03_tracking/` | 项目台账、周报、风险表 |
| `04_requirements/` | 原始需求、流程图、WBS、业务表格 |
| `05_decisions/` | 技术路线、架构决策、选型记录、产品工程、设计方法、AI Agent 工程规范 |

新需求不要放根目录，优先放入 `04_requirements/`。

## 当前开工规格

```text
docs/04_requirements/phase1/
```
