## 一、功能概述

将 gjjd-java 项目的**考试计划**功能完整复刻进 saas 项目。

### 复刻范围

| 模块 | 说明 |
|---|---|
| **考试计划** (train_exam_list) | 核心：CRUD + 关联查询工种列表 |

private void saveWorkTypeList(Long examId, List<Long> courseIdList, Long userId, Long tenantId) {
    // 软删除旧记录（修正后）
    List<TrainExamWorkTypeListEntity> existing = workTypeListMapper.selectList(
        new LambdaQueryWrapper<TrainExamWorkTypeListEntity>()
            .eq(TrainExamWorkTypeListEntity::getExamId, examId)
            .eq(TrainExamWorkTypeListEntity::getDeleted, 0));
    for (TrainExamWorkTypeListEntity e : existing) {
        workTypeListMapper.deleteById(e.getId());
    }

    for (Long courseId : courseIdList) {
        // 查 Course 获取 workTypeId 和 level
        ExamCourseEntity course = examCourseMapper.selectById(courseId.intValue());
        TrainExamWorkTypeListEntity wte = new TrainExamWorkTypeListEntity();
        wte.setExamId(examId);
        wte.setCourseId(courseId);
        if (course != null) {
            wte.setWorkTypeId(course.getWorkTypeId() != null ? course.getWorkTypeId().longValue() : null);
            wte.setLevel(course.getLevel() != null ? String.valueOf(course.getLevel()) : null);
        }
        wte.setTenantId(tenantId);
        workTypeListMapper.insert(wte);
    }
}

@Transactional
public int importPeopleFromTrain(Long examId, Long trainId) {
    Long tenantId = SecurityContext.currentUser().getTenantId();

    // 查培训人员（通过 train_people_list 表）
    List<TrainPeopleListEntity> trainPeople = trainPeopleListMapper.selectList(
        new LambdaQueryWrapper<TrainPeopleListEntity>()
            .eq(TrainPeopleListEntity::getTrainId, trainId)
            .eq(TrainPeopleListEntity::getDeleted, 0));

    // 查培训信息获取 workTypeId
    TrainInfoListEntity trainInfo = trainInfoListMapper.selectById(trainId);
    Long workTypeId = trainInfo != null ? trainInfo.getWorkTypeId() : null;

    int count = 0;
    for (TrainPeopleListEntity people : trainPeople) {
        // 跳过已存在的
        Long existing = peopleListMapper.selectCount(
            new LambdaQueryWrapper<TrainExamPeopleListEntity>()
                .eq(TrainExamPeopleListEntity::getExamId, examId)
                .eq(TrainExamPeopleListEntity::getIdCardNum, people.getIdCard())
                .eq(TrainExamPeopleListEntity::getDeleted, 0));
        if (existing > 0) continue;

        TrainExamPeopleListEntity entity = new TrainExamPeopleListEntity();
        entity.setExamId(examId);
        entity.setWorkTypeId(workTypeId);
        entity.setRealname(people.getRealname());
        entity.setIdCardNum(people.getIdCard());
        entity.setPhone(people.getPhone());
        entity.setNormalScore(people.getNormalScore());
        entity.setTenantId(tenantId);
        entity.setLearnTime(0);
        entity.setLearnUseTime(0);
        peopleListMapper.insert(entity);
        count++;
    }
    return count;
}
```

@Transactional(readOnly = true)
public PageResponse<TrainExamListVO> page(TrainExamListQueryReq req) {
    // ... 现有查询逻辑 ...
    Page<TrainExamListEntity> page = mapper.selectPage(...);

    // 批量查 WorkTypeList
    List<Long> examIds = page.getRecords().stream().map(TrainExamListEntity::getId).toList();
    Map<Long, List<TrainExamWorkTypeListEntity>> wtMap = new HashMap<>();
    if (!examIds.isEmpty()) {
        List<TrainExamWorkTypeListEntity> allWorkTypes = workTypeListMapper.selectList(
            new LambdaQueryWrapper<TrainExamWorkTypeListEntity>()
                .in(TrainExamWorkTypeListEntity::getExamId, examIds)
                .eq(TrainExamWorkTypeListEntity::getDeleted, 0));
        wtMap = allWorkTypes.stream().collect(
            Collectors.groupingBy(TrainExamWorkTypeListEntity::getExamId));
    }

    final Map<Long, List<TrainExamWorkTypeListEntity>> finalWtMap = wtMap;
    return new PageResponse<>(
        page.getRecords().stream().map(e -> toVOWithRelations(e, finalWtMap.get(e.getId()))).toList(),
        page.getCurrent(), page.getSize(), page.getTotal());
}
```

**核心逻辑**:
```tsx
import { Modal, Form, Input, Select, InputNumber, message } from 'antd';
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query';
import { createExam, updateExam, importExamPeopleFromTrain } from '../../api/training';
// 查培训列表、课程列表的 API

export function TrainExamListFormModal({ open, editingId, onClose }: Props) {
  const [form] = Form.useForm();
  const queryClient = useQueryClient();

  // 查培训列表 (用于 Select)
  const { data: trainOptions } = useQuery({
    queryKey: ['train-info-options'],
    queryFn: () => pageTrainInfoLists({ pageSize: 999 }),
    enabled: open,
  });

  // 查课程列表 (用于多选 Select)
  const { data: courseOptions } = useQuery({
    queryKey: ['course-options'],
    queryFn: () => pageCourses({ pageSize: 999 }),
    enabled: open,
  });

  // 编辑时加载详情
  const { data: editing } = useQuery({
    queryKey: ['exam-detail', editingId],
    queryFn: () => getExam(editingId),
    enabled: open && !!editingId,
  });

  const saveMutation = useMutation({
    mutationFn: async (values: any) => {
      if (editingId) {
        await updateExam(editingId, values);
      } else {
        const result = await createExam(values);
        // 如果选了培训，创建后自动导入考生
        if (values.trainId && result.id) {
          await importExamPeopleFromTrain(result.id, values.trainId);
        }
      }
    },
    onSuccess: () => {
      message.success(editingId ? '修改成功' : '新增成功');
      queryClient.invalidateQueries({ queryKey: ['exam-list'] });
      onClose();
    },
  });

  // ... 表单渲染 ...
}
```

## 八、注意事项

1. **ExamCourseEntity 主键类型不一致**: `ExamCourseEntity.id` 是 `Integer`，而考试计划中 `courseIdList` 是 `List<Long>`。查询时需要 `courseId.intValue()` 转换。

2. **TrainPeopleList 实体字段差异**: saas 的 `TrainPeopleListEntity` 字段需确认是否有 `idCard`、`realname`、`phone`、`normalScore` 字段（gjjd-java 有这些字段）。导入逻辑中需以 saas 实际字段为准。

3. **TenantId 自动注入**: saas 使用 MyBatis-Plus `TenantLineInnerInterceptor` 自动拼接 tenant_id。但当前代码中部分查询手动写了 `.eq(xxx::getTenantId, tenantId)`。**保持与现有代码风格一致即可**，不需要统一。

4. **json-bigint**: 前端使用 `json-bigint` 处理雪花 ID，大整数 ID 会转为字符串。在比较 ID 时注意类型。

5. **权限码复用**: 新菜单 `kao_shi_ji_hua` 复用现有权限码 `train:exam-list:*`（已有 Controller 上的 @PreAuthorize 注解）。只需新增菜单和权限记录，不修改 Controller 上的权限注解。
