# 测试验收清单

版本：V0.1 草稿  
日期：2026-05-01

## 一、数据库验收

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| DB-01 | MySQL 空库迁移 | Flyway 全部迁移脚本执行成功 |
| DB-02 | MySQL 字段校验 | 核心表字段、索引、唯一约束符合表结构设计 |
| DB-03 | MySQL 初始化数据 | 内置租户、角色、菜单、字典初始化成功 |
| DB-04 | 雪花 ID | 批量创建 10,000 条数据无重复 ID |
| DB-05 | 逻辑删除 | 删除后列表不可见，数据库保留记录 |
| DB-06 | 租户隔离 | A 租户无法查询 B 租户业务数据 |

## 二、后端验收

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| API-01 | 登录成功 | 返回 access token、refresh token、当前用户 |
| API-02 | 登录失败 | 密码错误返回明确错误，不返回 token |
| API-03 | 刷新 token | refresh token 有效时可换取新 access token |
| API-04 | 退出登录 | refresh token 被撤销，再刷新失败 |
| API-05 | 当前菜单 | 不同角色返回不同菜单 |
| API-06 | 无权限接口 | 无权限角色访问接口返回 403 |
| API-07 | 用户管理 | 可新增、编辑、停用、重置密码 |
| API-08 | 角色授权 | 角色绑定菜单和按钮权限后立即生效 |
| API-09 | 文件上传 | 本地磁盘适配器可保存文件并返回元数据 |
| API-10 | 文件删除 | 删除后元数据状态更新，下载失败或不可访问 |

## 三、可控服务化验收

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| SVC-01 | 服务边界 | `platform-api`、`ai-gateway`、`mcp-server`、`file-service`、`workflow-service` 职责清楚，无重复实现用户、租户、权限和审计规则 |
| SVC-02 | 受控调用 | AI Gateway 和 MCP Server 只能通过 `platform-api` 受控 API 调用业务能力 |
| SVC-03 | 数据库边界 | MCP Server 和 AI Gateway 不直连业务数据库 |
| SVC-04 | 健康检查 | 每个独立服务预留健康检查接口 |
| SVC-05 | 故障隔离 | AI、MCP、文件或流程样板故障时，核心登录、课程、考试主流程不整体不可用 |

## 四、性能与资源验收

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| PERF-01 | 列表分页 | 后台所有列表接口都有分页参数和最大 `pageSize` 限制，不返回全量数据 |
| PERF-02 | 索引检查 | 核心表常用过滤字段包含 `tenant_id`、`status`、`created_at`、业务外键等索引 |
| PERF-03 | 无状态服务 | `platform-api` 不依赖本机内存保存登录状态，token、菜单权限、字典和任务状态可放 Redis |
| PERF-04 | 慢任务异步 | AI 生成、文件解析、批量导入、报表生成、通知发送不阻塞主请求 |
| PERF-05 | 文件资源控制 | 文件内容不存 MySQL，大文件路径预留预签名 URL 直传 OSS/COS 方案 |
| PERF-06 | AI 隔离 | AI Gateway 超时或失败时，登录、课程、考试、成绩接口仍可正常使用 |
| PERF-07 | 聚合接口 | 首页、工作台、学员首页有聚合接口方案，避免前端串行请求过多 |
| PERF-08 | 前端按需加载 | 后台和学员端大模块按路由懒加载，大表格分页渲染 |

## 五、产品工程与设计验收

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| PDX-01 | 需求完整性 | 每个一期功能都有目标、角色、流程、页面、字段、状态、权限、异常场景和验收标准 |
| PDX-02 | 需求可验收 | 需求不能只写“做一个管理功能”，必须说明业务动作和完成标准 |
| PDX-03 | 模糊需求处理 | 模糊需求先有原型或样板流程验证，不直接进入大规模开发 |
| PDX-04 | 文档对应 | PRD、API 合同、表结构、前端页面清单和测试清单能互相对应 |
| PDX-05 | 后台一致性 | 后台页面使用统一布局、菜单、表格、表单、弹窗、状态标签和错误提示 |
| PDX-06 | 学员端适配 | 学员端页面在手机视口可正常阅读、点击、答题和提交 |
| PDX-07 | 状态覆盖 | 页面包含加载、空数据、错误、无权限、提交成功和提交失败等基础状态 |
| PDX-08 | 组件复用 | 公共表格、上传、字典选择、状态标签、权限按钮不能在多个页面重复实现 |

## 十、不通过判定

出现以下任一情况，一期不能视为通过：

1. MySQL 空库无法执行迁移。
2. 不同租户之间能访问对方课程、题库、考试或用户数据。
3. 前端隐藏按钮但后端接口仍可被无权限调用成功。
4. 文件上传只是假返回，没有真实保存或元数据。
5. 学员答题提交后不能生成成绩。
6. AI 结果直接覆盖正式课程内容，未经过人工确认。
7. Flowable 样板不能记录审批留痕。
8. AI Gateway 或 MCP Server 绕过平台权限直连业务数据库。
9. 列表接口默认返回全量数据，或核心查询没有租户、状态、时间等必要索引。
10. AI、文件解析、导入导出等慢任务阻塞核心业务接口。
11. 需求没有字段、状态、权限和验收标准就进入开发。
12. 后台或学员端页面缺少加载、空数据、错误、无权限等基础状态。
13. AI 或 MCP 工具直接执行发布、审批、删除、正式通知等高风险动作，未经过人工确认。
14. AI 记忆或知识库绕过租户、角色和数据权限被读取。
