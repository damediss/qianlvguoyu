- 使用功能类优先的 CSS 方案，通过 colors/layout/typography/utilities 四类工具类组合构建 UI
- API 响应遵循统一 Result 格式 { code: 1(成功)/0(失败), msg: "提示", data: {...} }
- 页面间传参支持两种方式：简单 id 用标准 URL 参数，复杂对象用 encodeURIComponent(JSON.stringify(options))
- tabBar 页面跳转使用 switchTab，普通页面使用 navigateTo 或 redirectTo
- 所有 API 调用统一使用 utils/index.js 或 utils/java.js 封装的 request 函数
- WebSocket 心跳间隔 15 秒，断线自动重连
