# 竞赛简易试题管理

## 目标

在“竞赛试题管理”下新增“简易试题”目录，供不需要配置竞赛细目表的赛事按统一 Excel 格式批量导入试题。

## 菜单结构

```text
竞赛试题管理
└── 简易试题
    ├── 理论试题
    └── 实操评分项
```

原有细目表与题库页面保留。

## 简易试题 - 理论试题

- 仍按赛事、工种和等级归属试题。
- 提供批量导入与导入进度查询，不要求赛事先导入或启用细目表。
- 列表只显示未绑定细目表的理论试题。
- Excel 工作表使用“竞赛试题”，列顺序为：序号、题型、题干、参考答案、回答、选项 A 至选项 H。
- 本期支持单选题、多选题、判断题和填空题；也接受模板代码 2、7、1、3 分别表示单选、多选、判断、填空。模板中的简答、计算、论述、名词解释、制图、分析等题型待后续确认题目模型及评分规则后接入。
- 导入试题不创建细目表考评点绑定。
- 本期不调整组卷、考试和评分规则。

## 简易试题 - 实操评分项

- 按赛事、工种和等级归属实操考核项目，不要求先导入或启用细目表。
- 支持通过新增弹窗手工录入单个考核项目，并为项目添加多行评分项。
- 支持逐个考核项目导入评分明细表；一个 Excel 文件只包含一个考核项目和一个有效明细工作表。
- 导入表头按以下顺序提供：考核项目、考核内容、评分项、评分标准、计分方式、步骤、分值。
- 同一项目可有多行评分项；相同考核内容的评分项归入同一内容组。项目名、考核内容、评分项、评分标准、计分方式和分值为必填字段。
- 计分方式支持加分制和扣分制；扣分制的“步骤”填写正数扣分步长，且须能整除该评分项分值。加分制下“步骤”作为步骤说明保存。
- 项目总分由评分项分值合计得出，须大于 0 且不超过 100 分。
- 支持查看已导入项目的评分明细和删除项目；不提供手工编辑或细目表考评点绑定。
