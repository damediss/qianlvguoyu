# 认定管理数据面板指标候选清单

版本：V0.1
日期：2026-06-12
用途：供产品筛选认定管理数据面板一期指标，选定后再开发统计 API 和前端图表。

## 一、建议页面定位

数据面板只汇总“认定管理”业务数据，不复用现有职训平台数据面板中的培训、回款、课程、讲师等模拟指标。

建议一期页面结构：

1. 顶部统一筛选区
2. 核心指标卡
3. 任务与认定对象分析
4. 过程与资源分析
5. 风险、材料与归档分析
6. 明细下钻

## 四、当前不建议直接展示的结果指标

以下指标业务价值高，但当前主要存在于成绩花名册、公示文件等归档文件中，尚未形成稳定的结构化表，直接统计会产生口径不一致：

| 编号 | 指标 | 当前问题 | 建议补充 |
| --- | --- | --- | --- |
| R01 | 理论平均分 | 无统一结构化成绩明细 | 新增认定结果明细或标准成绩导入 |
| R02 | 实操平均分 | 无统一结构化成绩明细 | 新增认定结果明细或标准成绩导入 |
| R03 | 考试通过率 | 缺少统一合格状态字段 | 明确理论、实操、综合合格口径 |
| R04 | 缺考率 | 缺少考试出席状态 | 增加出席、缺考、违纪状态 |
| R05 | 获证人数/获证率 | 获证花名册目前为文件 | 增加证书结果导入和证书编号字段 |
| R06 | 成绩复核/异常率 | 缺少结构化复核记录 | 增加结果复核记录 |

## 五、推荐一期组合

若目标是先做一个真实、稳定、可下钻的数据面板，建议首批选择：

`A01 A02 A03 A04 A05 A06 A08 B01 B02 C01 C03 D01 D03 D04 E01 E04 E05 F11 F12 F13 F14 F18`

推荐首批图表：

1. 指标卡：任务总数、进行中、已完成、计划人数、实际人数、归档完成率
2. 环形图：任务阶段分布
3. 横向柱图：工种人数排名
4. 堆叠柱图：工种 × 等级人数
5. 折线图：月度任务与归档趋势
6. 状态卡：考评人员、考务人员、考点、设备可用情况
7. 风险列表：高风险和逾期任务
8. 合规列表：待归档、材料不完整、导入异常任务
