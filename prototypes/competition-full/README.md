# 竞赛数字化平台全量静态原型

本目录为竞赛模块全角色、全流程静态原型，共覆盖 5 个端、102 个页面视图。全部页面使用原生 HTML、CSS 和 JavaScript，无构建与后端依赖；页面数据、上传、AI 回答、考试计时和实时刷新均为评审用模拟效果。

页面数按可通过 URL hash 直达的独立视图统计，既包括导航页，也包括赛事详情、任务详情、考试过程、超时结果、初赛监控等深层详情或过程页；Modal、Drawer、Sheet、Confirm 等弹窗交互不重复计为页面。

## 打开方式

直接用浏览器打开 `index.html`，可进入全部五个端。建议通过任意静态服务器访问，以获得与部署环境一致的 hash 路由体验。

| --- | ---: | --- | --- |

## 推荐演示链路

### 1. 组织方完整办赛链路

`数据驾驶舱 → 赛事列表 → 赛事详情 → 创建竞赛（6步）→ 流程模板库 → 流程设计器 → 节点详情/配置 → 报名审核 → 专家指派 → 命题/审题 → 资源配置 → 任务详情/看板/甘特图 → 预算对比 → 成绩/排名/晋级/获奖 → 档案详情 → 一键归档导出`

重点演示新增与编辑表单、详情抽屉，以及审核、驳回、发布、阶段结束、删除、归档等二次确认。

### 2. 企业组织选拔链路

`企业总览 → 我的竞赛 → 赛事详情 → 企业任务中心 → 任务详情/成果提交 → 报名组织 → 参赛人员审核 → 企业初赛配置与发布 → 初赛监控/异常处理 → 成绩排名 → 晋级推荐 → 企业数据 → 通知与资料`

重点演示批量导入、报名审核、初赛发布和推荐名单提交弹窗。

### 3. 选手参赛链路

`登录 → 首页 → 我的赛事 → 赛事详情 → 竞赛报名 → 通知与须知 → 我的任务 → 赛前学习 → 开考说明 → 在线答题 → 超时自动交卷/正常交卷 → 我的成绩 → 排行榜 → 竞赛流程助手/专业知识助手 → 消息 → 账号与隐私`

选手端按移动设备宽度设计，浏览器桌面预览时建议开启移动设备模拟。

### 4. 专家履职链路

`专家工作台 → 我的任务 → 任务详情/接受/回避 → 技术文件批注 → 线下研讨归档 → 版本对比与签认 → 命题中心 → 审题任务 → 裁判评分 → 工作记录`

重点演示文件意见、版本签认、新建/选取题目、匿名审题和现场评分提交。

### 5. 外部公开展示链路

`赛事概览 → 赛程阶段 → 参赛阵容 → 实时动态 → 成绩排名 → 获奖名单 → 精彩媒体`

该端只展示审核通过的公开、脱敏数据，不展示内部预算、专家隐私和未公开成绩。

## 交互约定

- 各端导航均使用 URL hash，可复制链接直达并在刷新后恢复页面；
- 新增、编辑、导入、审核、提交、发布等关键操作具有真实 modal、drawer、sheet 或 confirm 演示；
- 五个端均提供返回原型总览入口；
- 组织方后台支持赛事与角色切换，企业端严格展示本企业数据，选手与专家端按本人授权范围展示；
- 外部大屏遵守公开审核与个人信息脱敏边界。

## 文件说明

- `index.html`：五端原型总入口；
- `admin.html` / `admin.css` / `admin.js`：组织方后台；
- `enterprise.html` / `enterprise.css` / `enterprise.js`：企业竞赛中心；
- `player.html` / `player.css` / `player.js`：选手移动端；
- `expert.html` / `expert.css` / `expert.js`：专家工作台；
- `screen.html` / `screen.css` / `screen.js`：外部赛事数据大屏；
- `coverage-matrix.md`：需求页面与交互覆盖矩阵；
- `deliverable-admin.md`、`deliverable-portals.md`：producer 交付与验证记录。
