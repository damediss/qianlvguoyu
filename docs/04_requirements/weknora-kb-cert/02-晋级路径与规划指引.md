# 考证晋级路径与学员规划指引

## 一、标准晋级主路径（最常见）
1. **无证 / 拟从业** → 先报 **初级（五级）**（年满16周岁即可）。
2. **初级** → **中级**：初级证后累计本职业或相关职业工作满 **3年**；或累计工作满 **5年**；或具备相关学历（含应届）。
3. **中级** → **高级**：中级证后累计工作满 **4年**；或累计工作满 **10年**；或技工院校高级工班及以上学历；或中级证+高职/专科及以上相关专业学历等。
4. **高级** → **技师**：高级证后累计工作满 **5年**；或具备相应职称/预备技师班等条件。
5. **技师** → **高级技师**：技师证后累计工作满 **5年**；或具备相应中级/高级职称等条件。

## 二、问诊话术模板
### 当下考什么
请学员补充：①目标工种 ②已持证书最高级别及取证时间 ③累计本职业/相关职业工龄 ④最高学历及是否应届/高级工班 ⑤是否企业新型学徒 ⑥有无电工/焊工特种证或 X 证书。
然后输出：建议申报级别 + 依据条款原文要点 + 若不够格差什么。

### 考完下一步
在「当前可拿证级别」之上，给出下一级，并列出：
- 路径A（持证晋级+工龄）
- 路径B（学历/学徒制/职称，若适用）
提醒：具体开考批次、评价机构范围以教务通知为准。

## 三、企业新型学徒制选条（来自扩写版备注）
- 申报**中级工**：优先选「取得本专业或相关专业技工院校或中等及以上职业院校、专科及以上普通高等学校毕业证书（含在读应届毕业生）」这一条；电工相关还可关注低压电工作业特种证满3年通道。
- 申报**高级工**：优先选「技工院校高级工班及以上毕业证书（含在读应届毕业生）」这一条。
- 申报**技师**：优先选「取得高级工证书满2年的技师学院预备技师班、技师班学生」相关条款；在校生毕业学年可申报技师。
- 申报**高级技师**：优先选「取得技师证书满2年的高级技师班企业新型学徒制学徒」这一条。

## 四、学历通道注意（高级）
- 已有中级证 + 高职/专科及以上相关专业毕业证：**晋级申报不需评估论证**。
- 仅有经评估论证的高职/专科及以上相关专业毕业证、无中级证：**直接申报需评估论证**。
