# 千铝工投云平台与智能体开发部前端开发与用户体验管理办法

制度编号：QLGT-YFGL-2026-001　　版本：V1.0　　发布日期：2026-10-16

## 第一章　总则

**第一条**　为统一管理控制台、数据可视化大屏、用户端实训教学界面的开发规范，明确页面加载速度、多浏览器兼容、交互逻辑、操作容错率等体验标准，持续优化用户体验，降低使用故障率，特制定本制度。

**第二条**　本制度适用于 admin-web 管理端、数据大屏、学员端 H5/小程序/App 前端代码；后端接口规范按平台既有约定执行，前端只做展示控制，鉴权裁决在后端。

## 第二章　开发规范

**第三条**　工程规范：

1. 源码 UTF-8 无 BOM；改代码用编辑工具，不走命令行管道（避免引入 BOM 与编码损坏）；
2. 类型检查真跑 `tsc -b`（项目构建入口），`tsc --noEmit` 不视为检查通过；
3. API 统一消费 `{ code, message, data }` 与分页结构，列表统一走分页组件；
4. 组件按领域目录组织，通用组件入公共目录并登记技术资产清单。

**第四条**　交互规范（3 人团队自用产品的经验固化）：

1. 常用操作平铺展示，不收入"更多"下拉折叠；
2. 页面反馈必须可见：长页面板操作后自动滚动定位到反馈区域，禁用无提示的静默成功；
3. 破坏性操作二次确认，确认文案写清后果（"删除后不可恢复，共 N 条"）；
4. 面向用户的提示用业务白话，不暴露参数名、接口名、内部文档名。

**第五条**　空态与容错：列表空态、加载失败、无权限、网络异常各有明确提示与恢复入口；不允许白屏与无限 loading。

## 第三章　体验标准

**第六条**　量化标准（对应附录 A 乙档基线，2026 记录基线值）：

| 项 | 标准 |
|---|---|
| 页面首屏加载 | ≤3 秒（内网环境） |
| 接口 P95 响应 | 核心查询 ≤500ms，核心提交 ≤1s |
| 浏览器兼容 | 管理端覆盖 Chrome/Edge 最新两个大版本；小程序覆盖主流机型；App 覆盖 Android/iOS |
| 操作容错 | 表单校验前置，错误定位到字段，不整页报错 |

**第七条**　新功能上线前完成 UI 走查：用项目无头浏览器脚本按走查清单逐项过（布局、文案、空态、权限显隐、反馈可见性），走查记录随 MR 归档。

## 第四章　发布与回归

**第八条**　前端随版本发布，发布前完成：类型检查 0 错误、构建产物归档、核心流程冒烟（登录、主导航、一个核心业务闭环）。

**第九条**　大版本（涉及路由、权限模型、全局状态）上线前，管理端按灰度策略先单租户验证。

## 第五章　附则

**第十条**　本制度由部门负责人负责解释，自发布之日起施行。
