# 竞赛组卷与多套试卷编排修订说明

> 日期：2026-09-07  
> 适用范围：竞赛理论、实操组卷计划及赛段编排。

## 当前业务口径

1. 一个竞赛组卷计划只负责生成一套独立试卷。计划必须设置每套试卷总分，并在组卷规则中设置题型、题量和单题分值；题库题目只维护题干、答案和评分规则，不再维护单题分值，快照分值统一取组卷计划规则。
2. 需要 A/B 或更多套试卷时，业务人员分别创建多个组卷计划并分别发布，不能在一个组卷计划内同步生成 A/B 卷。
3. 赛段编排按赛事、工种和等级列出已发布的竞赛组卷试卷，业务人员可选择一套或多套绑定到当前赛段。绑定后生成当前赛段的执行快照（例如 P1、P2）。
4. 选手与试卷配置、考试场次配置负责决定试卷分配方式：可以按场次固定指定，也可以执行随机分配；分配完成后保留选手、场次和试卷快照的关联。

## 兼容与校验

- 历史 A/B 快照保留用于只读兼容；新建组卷计划统一生成 P 卷。
- 同一赛段选择试卷时不依赖评分规则，也不校验多套试卷的考试时长、总分和及格分一致性；以已发布的竞赛组卷快照为绑定来源。
- 试卷快照发布后不可修改，重复创建计划产生新的计划版本和独立试卷快照。
