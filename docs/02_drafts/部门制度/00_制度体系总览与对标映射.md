# 云平台与智能体开发部制度体系总览与对标映射

> 版本：V1.0（体系总览）　　编制日期：2026-10-16　　编制：云平台与智能体开发部
> 本文件是部门制度体系的**总索引与对标底稿**，不是制度本身。各项制度的正文见同目录对应文件。

## 一、体系定位与编制依据

本体系以三份材料为依据编制：

1. **公司《千铝工投云平台与智能体开发部管理制度清单（全KPI指标对标）》**：29 项制度、5 大分类、每项挂公司官方 KPI，另附 23 个配套台账模板与 5 条制度执行保障条款。本体系以此为对标 frame，逐项落位。
2. **19 份待审制度草案**（研发 9 项 YF-01～09、运维 10 项 YW-01～10，2026-08-20 版）：工程主线已成稿，且规则均提炼自培鉴赛 SaaS 平台真实踩坑（Flyway 取号、雪花 ID、逻辑删除、多租户隔离、异步链路上下文等），质量可靠，作为体系基底修订沿用。
3. **现有 SaaS 项目实践**：本体系把项目已验证的工程方法固化为条款（见 §五），避免制度与实操两张皮。

## 二、编号规则与版本管理

- 编号格式：`QLGT-{分类码}-2026-{序号}`。分类码：BMGL 部门治理 / CPGL 产品策划 / YFGL 技术研发 / YWGL 运营运维 / SWGL 商务创收 / XZGL 协同绩效。QLGT 取"千铝工投"拼音首字母；如公司另有编号规范，按公司规范替换，不影响本体系结构。
- 序号分段：**001 起为本轮新写制度；101 起为修订沿用的原草案**（原 YF-01～09 依次对应 QLGT-YFGL-2026-101～109，原 YW-01～10 依次对应 QLGT-YWGL-2026-101～110），原编号 GYSZ-* 停用。
- 每项制度独立成文、独立版本号；修订采用 V1.0 → V1.1 递增，修订内容、原因、生效日期在制度文末"修订记录"中留痕。
- 19 份原草案编号 GYSZ-YFGL/YWGL-2026-00X 随名义变更同步更换为 QLGT 编号（见 §六修订清单），原文内容主体保留。

## 三、3 人团队组织模型（本体系的总约束）

部门现实：**3 名开发岗成员（覃健、程志伟、郝少盟），均为后端/全栈出身，无专职前端、测试、运维、产品、商务岗位**。因此本体系所有条款按以下模型设计，不设无法执行的岗位：

| 岗位/角色 | 人数 | 承担人（以公司任命为准） | 说明 |
|---|---|---|---|
| 部门负责人 | 1 | 覃健（兼） | 兼产品策划、技术方案、对外接口 |
| 开发岗（主岗） | 3 | 覃健 / 程志伟 / 郝少盟 | 按模块分工，人人都是全栈补位 |
| 质量角色（兼任） | 3 人互审 | 轮换 | 代码互审、提测准入把关 |
| 运维角色（兼任） | 3 人轮值 | 按月轮值 | 告警首响、巡检、发布执行 |
| 知识管理员（兼任） | 1 | 由部门负责人指定 | 文档归档、技术资产清单、工作档案 |

**三条适配铁律**（写进各相关制度）：

1. **双人制可执行，但设例外**：操作人 + 复核人；仅 1 人在岗时允许事后 24 小时内补复核并留痕，不阻塞工作。
2. **系统接口人合并**：原草案按系统设 8 名接口人，3 人团队合并为 3 组——SaaS 平台组、仿真与私有化组、工作流与第三方组。
3. **不设专职岗的职责全部并入兼任矩阵**，兼任情况记入个人工作档案（制度 02），季度复盘时评估兼任负荷。

## 五、固化为条款的项目工程方法（"长在项目上"）

以下方法已在培鉴赛 SaaS 平台验证，直接写入对应制度，作为部门工程标准：

| 项目实践 | 固化位置 |
|---|---|
| 规则引擎计算、LLM 只做解释与生成（"规则算、模型说"） | 10、12、13、14、YF-09 修订 |
| 参数全部收口 sys_dict，读写经钳制函数并记告警日志 | 05（参数变更视同配置变更） |
| 先方案后动手、方案给 A/B/C 选项、确认后实施 | 01（协作机制）、05（需求评审） |
| 文档与代码同库，docs/04_requirements → docs/05_decisions → 实现 → 复盘 | 01、YF-08 修订 |
| 提交可追溯（ Conventional Commits + file:line 证据） | YF-04 修订 |
| Flyway 取号两库并行查 MAX(version) 留间隔 | YF-05 修订 |
| X-Tenant-Id 可伪造，禁止用作鉴权依据 | YF-07 修订 |
| AI 生成代码与人工代码同标准，提交前必跑回归 | YF-04 修订（草案已有，保留） |
| 前端真检查用 tsc -b，UI 走查用无头浏览器 | 09 |
| LLM 调用测试可 mock，不依赖真实模型 | YF-09 修订（草案已有，保留） |
| git 身份 8 署名映射，人效统计按 name+email 归集 | 28（取数规则） |
