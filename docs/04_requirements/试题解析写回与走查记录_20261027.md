### 走查中发现并修复的真实缺陷（必须随批披露）

**六页模板渲染期崩溃**：`hasTable/resolveToHtml/isAiResolveSource` 在 M3/M5 只做了顶层 import，uni-app Options API 模板不解析实例外函数 → 真机点击「生成解析」后渲染 TypeError（`_ctx.hasTable is not a function`），解析永不显示。构建与源码契约测试均无法发现（无运行时渲染检查）。

修复：六页 methods 增加包装方法暴露三个函数；新增契约守卫（模板引用 ↔ methods 包装成对断言，tests/resolveEntryPages.test.js）。appnext 144 测绿 + build:h5 绿。

### 误打生产披露

页面登录请求走 `domain.pro`（PHP 生产主机），生产恰存在同名演示账号（id=608 gannn），因此发生过 2 次生产登录（仅 platform_user_token 登录审计写入，无业务数据变更）。已停止该路径（dev 链路替换），未造成数据影响。
