# file-service

文件服务，统一封装本地磁盘、阿里云 OSS、腾讯云 COS 等存储能力。

## 职责

1. 管理文件元数据。
2. 提供上传、下载、预签名 URL、删除、权限校验和归档能力。
3. 屏蔽具体对象存储供应商差异。

## 边界

1. 业务模块不能直接绑定云厂商 SDK。
2. 不把文件内容存入 MySQL。
3. NAS 只作为已有素材和历史资料的索引来源，不作为平台标准上传文件主存储。

## 约定

1. 本地开发使用 local-disk adapter。
2. 生产通过 Cloud OSS Adapter 选择阿里云 OSS 或腾讯云 COS。
3. 一期可独立部署，也可先作为 `platform-api` 内部模块，但接口和职责按独立服务设计。
