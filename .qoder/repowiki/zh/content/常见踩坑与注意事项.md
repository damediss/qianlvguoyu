# 常见踩坑与注意事项

## 必读踩坑清单（新进项目 Agent 先读这 6 条）

### 1. MyBatis-Plus 默认 snake_case

Flyway 迁移的列名必须 snake_case，跟 Java 命名策略对齐。MyBatis-Plus 配置 `map-underscore-to-camel-case: true` 自动将 `created_at` 映射为 `createdAt`。如果 Flyway 中使用了 camelCase 列名，Java 实体字段将无法正确映射。

### 2. setDeleted(1) + updateById 永远是假删

软删统一用 `mapper.deleteById(...)`, 全项目禁止 `setDeleted(1)`。MyBatis-Plus 的逻辑删除插件会自动在查询时拼接 `WHERE deleted = 0`，但 `setDeleted(1) + updateById` 会绕过这个机制。

### 3. PowerShell Set-Content 默认带 UTF-8 BOM

Java 编译会报非法字符。改源码用 Edit/Write 工具，不要走 shell 管道（`cat | Set-Content` 等）。PowerShell 中使用分号（`;`）替代 `&&` 执行多条命令。

### 4. Flyway 批量重命名迁移要按 description 还原真实 version

不要靠 description 猜 version，先 `SELECT description, version FROM flyway_schema_history` 反查。已应用的迁移文件内容不可修改，新增迁移必须用新 version 号。

### 5. 前端 tsx 引用同目录 css 是约定

移植 Vue → React 时别漏 `import './xxx.css'`。每个页面组件对应一个同目录的 CSS 文件。

### 6. producer 阶段 25min 硬上限装不下全链路 E2E

拆 sub-task，或 owner 自己跑 E2E，或明确不让 verify-as-task 进 plan。

## 其他常见问题

### ErrorCode 常量名必须使用已定义字段

`ErrorCode` 只有 `BAD_REQUEST("400")`、`NOT_FOUND("404")`、`INTERNAL_ERROR("500")` 等常量。不存在 `VALIDATION_ERROR`，使用时需确认常量名在 ErrorCode.java 中已定义。

### SaaS 菜单 code 必须以 API 响应为准

菜单的 `code` 字段从后端 `/api/system/menus` 接口动态获取，前端 pageMap 注册必须与 API 返回的 code 精确匹配，不能凭主观猜测。

### antd TreeSelect 搜索需显式指定 treeNodeFilterProp

TreeSelect 默认不搜索任何字段，必须显式设置 `treeNodeFilterProp="title"` 或 `treeNodeFilterProp="name"` 才能支持输入搜索。

### 用户状态值必须为 'enabled' 才能登录

登录认证逻辑中检查 `user.getStatus() == "enabled"`，状态为 `disabled` 或其他值的用户无法通过认证。

### 评分数据字段名前后端不一致会导致渲染为空

后端返回的字段名（如 `scoreDetail`）与前端 VO 中定义的字段名（如 `scoreDetails`）必须严格一致，否则数据将渲染为空值。

### 前端大整数需安全处理

Axios 配置了 `transformResponse` 处理大整数，避免 JavaScript `Number` 精度丢失。雪花 ID 等 BIGINT 值应作为字符串处理。

### /api/exam/courses pageSize 上限为 200

科目列表接口的 `pageSize` 参数最大值为 200，超过会被截断。

### MySQL 客户端执行含中文 SQL 需指定 utf8mb4

使用 `mysql.exe` 执行包含中文注释的 SQL 文件时，需显式指定字符集：`mysql.exe --default-character-set=utf8mb4`。

### DBeaver MySQL 客户端位数不匹配导致 error=193

DBeaver 在 Windows 上可能因 32/64 位不匹配报 `error=193`，建议使用 MySQL 官方客户端替代。
