# 竞赛赛前练习推送管理与选手端接收需求

## 目标

在「竞赛 → 选手管理 → 赛前练习」下与「试题配置」并列增加「推送管理」。业务人员可将已生成的赛前练习任务推送到指定单位或指定选手；竞赛选手登录选手端后，在「赛事任务 → 赛前练习」中查看收到的任务。

本阶段打通任务配置到选手端收件箱的链路。实际试题快照下发、题目展示、作答、判分和成绩回传留到下一阶段。

## 管理端推送

1. 选择赛事、赛事工种、参赛等级；按赛事、工种和等级查询已生成且状态为「已配置」的赛前练习任务。
2. 查询该范围内已激活、具备竞赛选手账号的选手，显示选手编号、姓名和所属单位。
3. 支持按单位筛选；单位筛选后的名单可逐个勾选，也可全选当前筛选结果。
4. 选定一个已生成任务后提交推送。服务端重新校验任务范围、选手资格和单位筛选条件。
5. 每次提交生成独立推送批次及选手收件记录。同一任务可重复推送，同一批次内同一选手只会收到一条记录。
6. 推送记录展示任务、赛事范围、推送人数和推送时间；任务配置列表标明任务已推送，同时保留再次推送能力。

## 选手端接收

- 使用竞赛选手独立登录态获取任务，不接受客户端传入 playerId 作为收件范围。
- 收件箱按当前 token 关联的租户和选手账号查询，只返回推送给该选手的任务记录。
- 每条推送批次作为独立收件项展示，重复推送会产生多条可区分的记录。
- 任务卡片展示任务名称、赛事、工种、等级、赛段、题量和推送时间，不返回题目快照、答案或解析。
- 选手端在竞赛选手 APP 现有「赛事任务」页面（`pages/competition-app/tasks.vue`）查看赛前练习收件箱，并沿用 APP 已有的竞赛选手登录态。

## 数据与权限

- 推送批次和选手收件记录独立于试题配置任务表；批次固化赛事范围和任务名称快照，收件记录固化选手、报名和单位信息。
- 新增权限码 `competition:player-pre-practice:push`；查看沿用 `competition:player-pre-practice:view`。
- 所有管理端查询和写入遵守当前租户；选手端只允许当前已认证选手读取收件箱。
- 推送写操作记录审计日志。

## 暂不实现

- 从课程题库重新生成或下发试题快照。
- 选手查看题目、答题、保存作答、提交、判分、查看成绩或错题。
- 推送撤回、进度统计、完成状态和再次推送后的历史任务合并。
