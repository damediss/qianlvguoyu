# 职业技能等级认定 · 申报条件知识库说明

## 知识库用途
本知识库面向学员「考证咨询与规划」，回答：
1. 某级别一般要满足什么申报条件
2. 企业新型学徒制应选择哪一条申报
3. 初级→中级→高级→技师→高级技师的晋级关系
4. 电工、焊工等特种作业操作证、教育部门 X 证书可走的通道
5. 新旧规程差异（文件印发前已受理的可按原规定执行）

## 级别阶梯（由低到高）
五级/初级工 → 四级/中级工 → 三级/高级工 → 二级/技师 → 一级/高级技师

## 回答原则（给智能体）
- 申报条件以「新规程申报条件（2023.11）」为准；需要对比时再引用旧规程。
- 学员问「我能不能报某级别」：先列出该级别全部可选路径（满足任一路径即可），再根据学员自述的学历/工龄/持证情况指出最可能适用的一条；信息不足时明确列出还缺哪些信息（当前持证级别、取证时间、累计工龄、学历、是否学徒、有无特种证/X证）。
- 学员问「考完下一步考什么」：在当前级别之上给出下一级，并给出 1～2 条最短常见路径（工龄晋级 / 学历或学徒制路径），不要编造本班未开考的工种。
- 本班具体「考什么证、什么工种」以班级配置/教务真数据为准；本库只解释**通用申报资格规则**。
- 禁止用通用百科编造年限；年限与证书要求必须来自本库条款。
