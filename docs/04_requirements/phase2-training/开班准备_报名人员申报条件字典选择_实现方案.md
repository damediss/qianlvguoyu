## 1. 背景与结论

人员编辑弹窗中「申报条件」字段（`#declarationCondition`）当前因接口 `condition_list` 为空，回落为普通 `Input`。

产品选择 **方案 A（字典入库）**：条件进 `sys_dict` / `sys_dict_item`，运营可在「系统 → 字典管理」维护；前端有选项时使用 `Select` 按预约等级筛选并填入全文。

相对前端静态 JSON：后期规程变更只需改字典数据，无需发版。

## 2. 目标与非目标

| 类型 | 内容 |
|------|------|
| 目标 | Excel 条件入库；按 `reqLevel` 下拉可选；选中写入人员 `condition` 全文；改等级清空重选 |
| 非目标 | 本期不做独立「申报条件」业务页；不存字典 id 到人员表；不做改字典后历史人员自动同步 |

## 3. 级别映射

| Excel 级别 | `reqLevel` | 页面等级文案 |
|------------|------------|--------------|
| 初级 | 0 | 五级/初级工 |
| 中级 | 1 | 四级/中级工 |
| 高级 | 2 | 三级/高级工 |
| 技师 | 3 | 二级/技师 |
| 高级技师 | 4 | 一级/高级技师 |

条数：初级 2 / 中级 8 / 高级 10 / 技师 7 / 高级技师 4；当前最长文案约 **111** 字。

## 4. 数据模型

### 4.1 字典头

| 字段 | 值 |
|------|----|
| `sys_dict.code` | `signup_declaration_condition`（与现有 `DemandTrainApplicationService#loadConditionsFromDict` 已对齐） |
| `name` | 报名申报条件 |
| `status` | `enabled` |
| `tenant_id` | 各使用租户各一份（见 §7） |

### 4.2 字典项约定（关键）

| 字段 | 用途 | 示例 |
|------|------|------|
| `item_value` | 稳定业务键（租户+字典内唯一）：`{reqLevel}-{序号}` | `0-01`、`2-07` |
| `item_label` | 完整条件文案（下拉展示 + 写入人员表） | `（1）年满16周岁…` |
| `sort_order` | 同级内排序，建议用 Excel 总序号 | `1`…`31` |
| `status` | `enabled` / `disabled`（停用即可下线，不必物理删） | |

**过滤规则**：按 `item_value` 前缀 `{reqLevel}-`（或显式 `reqLevel` 字段）筛选。  
**禁止**继续使用 PHP 遗留硬编码 id 区间 `2522–2541`（见 `filterDeclarationConditions`）。

### 4.3 字段长度（必须先做）

- 现状：`item_label` 为 `varchar(128)`；DTO `@Size(max = 128)`。
- 当前 Excel 最长 111，能写入，但后期改文案易超限。
- **本期**：Flyway 将 `item_label` 扩至 `varchar(512)`（或 `text`），同步放宽 Create/Update DTO；字典管理页该项改为 `TextArea`。

人员表仍存 **文案全文**（`train_sign_up_people_self.condition` / 表单 `declarationCondition`），不存字典 id，避免改字典后历史对不上号。

## 5. 后端改造

### 5.1 已有能力（主流程复用）

- `getDemandPublicData(..., "condition")` → `loadDeclarationConditions`：先字典，再 `train_base_data` 回落。
- 人员保存已映射 `declarationCondition` → `condition`。
- 默认模板导出已用 `person.getDeclarationCondition()` 作为 `${condition}`。

### 5.2 `condition_list` 项结构（增量兼容）

```json
{
  "id": 1234567890,
  "title": "（1）年满16周岁，拟从事本职业或相关职业工作。",
  "value": "0-01",
  "reqLevel": 0
}
```

- `title` ← `item_label`（Select 的 value/label 继续用 title）。
- `value` ← `item_value`；`reqLevel` 由 `item_value` 解析（`split("-")[0]`）。
- 仅返回 `deleted=0` 且 `status=enabled`。

涉及类：`DemandTrainApplicationService#loadConditionsFromDict`（及必要时 base_data 回落映射）。

### 5.3 初始化 / Seed

1. 解析 Excel（跳过「级别 / 新规程」类标题行）。
2. 幂等写入目标租户：
   - 无 `code=signup_declaration_condition` 则建字典；
   - 按 `item_value` upsert：`item_label` / `sort_order` / `status`。
3. 实现形态二选一：Flyway/SQL 脚本，或一次性运维命令；预览数据见 `申报条件_seed_preview.json`。

`train_base_data` 回落本期可不依赖；若后续兼容 PHP 共享库，建议 `data_key` 使用同类 `{reqLevel}-{序号}`，过滤同样按键而非 id。

## 6. 前端改造

### 6.1 人员编辑 `SignUpPeopleEditModal`

现有分支保留：`conditionOptions.length > 0` → `Select`，否则 `Input` 兜底。

改 `signUpPeopleEditConstants.ts#filterDeclarationConditions`：

- 优先：`item.reqLevel === reqLevel`，或 `String(item.value).startsWith(\`${reqLevel}-\`)`。
- `reqLevel` 为空：建议 **先选预约等级再出条件**（或临时展示全部，产品确认其一）。
- 删除硬编码 id 区间。

交互保持：

- 改 `reqLevel` → 清空 `declarationCondition`（已有 `handleReqLevelChange`）。
- Select：`allowClear` + `showSearch`。
- 提交仍为文案字符串。

### 6.2 维护入口（零/少开发）

复用 `apps/admin-web` → **系统字典**（`DictPage`）：

1. 找到编码 `signup_declaration_condition`；
2. 增删改项：遵守 `item_value` 规则，`item_label` 填全文，`status` 上下架。

二期可选：对该 code 增加「适用等级」下拉，自动生成 `item_value` 前缀。

## 7. 多租户

- 加载按当前登录 `tenant_id` 查字典 → **每个使用中的租户都需 seed**。
- 新租户：开通培训能力时复制模板字典，或提供「从模板同步申报条件」运维接口。
- 权限：沿用系统字典权限。

## 8. 实施步骤

1. 扩 `item_label` 列 + DTO/字典页 TextArea。  
2. Seed：Excel / JSON → 目标租户写入字典及 31 项。  
3. 后端：`condition_list` 增加 `value`、`reqLevel`。  
4. 前端：按等级过滤，去掉旧 id 区间。  
5. 联调：等级切换选项变化；保存回显；默认模板 `${condition}` 正确。  
6. 给运营一份短说明：如何在字典中改文案 / 停用 / 新增。

## 9. 后期运维

| 变更 | 操作 |
|------|------|
| 改文案 | 改 `item_label`；**已报名人员历史 `condition` 不自动变** |
| 作废 | `status=disabled` 或逻辑删除 |
| 新增 | 新 `item_value`（同级新序号，如 `2-11`）+ 全文 label |
| 整表换规程 | 旧项批量 disabled；新 Excel 再 seed（建议 value 加版本前缀如 `v2026-0-01`） |

若未来要求「改字典同步历史人员」，需改为存 `item_value` 再解析展示——本期不做。

## 10. 风险与测试

| 风险 | 处理 |
|------|------|
| label 超 128 | 先扩列 |
| 租户未 seed → 仍是 Input | 初始化覆盖；联调检查 `condition_list` |
| `item_value` 填错 | 约定文档；二期等级辅助录入 |
| 长文案 Select 难看 | option 省略 + tooltip / 加宽（非阻塞） |

测试要点：

- 五级仅见 2 条初级；改四级见中级条件。  
- 改等级清空已选条件。  
- 无字典租户仍可手输。  
- 保存后再打开回显一致；导出材料条件字段正确。
