## 一、结论（先看）

| 问题 | 答案 |
|------|------|
| 要解决什么 | P0 只稳写「证号 + 文件 + 半截等级/工种」；本期把证书正文**完整字段**解析入库，供名单展示、补贴申领表、获证名册等复用 |
| 为何现状不一致 | `parsePdf` 用 `contains("三级")` 等关键词，写成 `"三级"` / `"技师"`，丢掉 `"三级/高级工"`、`"二级/技师"`；发证机构/日期/职业未写 |
| 能否与 PDF 一致 | **能**（有文本层时）：按版式抽**证面原文**入库；抽不到则留空+警告，**宁缺毋错** |
| 数据落点 | 仍落 **`train_certificate`**；扩列承载「职业名称、评价机构」等；已有列补写**证面原文** |
| 匹配键 | **不变**：已选班花名册身份证 → `people_id`；姓名仅校验告警 |
| 交互 | **不变**：预览 → 确认回填；预览表展示全部解析字段（与将入库值一致） |
| 历史数据 | **仅允许**持原 PDF **重导覆盖**；禁止无 PDF 的等级臆造补丁脚本 |

**一句话：** 在现有上传回填链路上，按证面原文解析入库；存储信息必须可与 PDF 逐项核对一致。

## 三、现状缺口

### 3.1 解析（`GraduationCertificateImportApplicationService.parsePdf`）

| 项 | 现状 | 问题 |
|----|------|------|
| 身份证 / 证号 | 正则抽取 | 可用，保留 |
| 姓名 | 主要文件名第二段 | 可用；宜与文首姓名交叉校验 |
| 等级 | `contains("三级")` → 存 `"三级"`；`contains("技师")` → 存 `"技师"` | **与证书「三级/高级工」「二级/技师」不一致** |
| 工种 | 仅白名单（炭极/铝电解等） | 其他工种为空 |
| 职业 / 发证机构 / 评价机构 / 日期 | 未解析或未写入 | 补贴申领表等无法复用证面信息 |
| 发证日期 | commit 写 `LocalDate.now()` | 与证面日期不符 |

### 3.2 存储（`train_certificate`）

已有可用列：`certificate_no`、`work_type`、`level`、`issue_date`、`issuing_authority`、`file_path`、`user_name`、`certificate_type` 等。  
缺失列：`occupation`、`evaluation_org`（及可选 `id_doc_type`、`query_urls`）。

### 3.3 下游影响

- 获证名册 / 补贴个人申领表若读 `train_certificate.level`，会得到半截等级。  
- 系统其它处标准称谓为：`五级/初级工` … `一级/高级技师`（见名册导出 `LEVEL_LABELS`），导入侧应对齐。

## 四、产品规则（本期冻结）

### 4.0 证面一致性铁律（最高优先级）

1. **原文优先**：能从 PDF 文本抽到的字段，入库字符串须与证面该字段一致（仅允许空白压缩、日期格式归一）。  
2. **宁缺毋错**：抽不到 → 存 `NULL`/空 + 预览警告；**禁止**用推断、班级工种、系统默认值填进证面字段。  
3. **禁止截断**：证面为 `三级/高级工` 时不得存 `三级`；证面为 `二级/技师` 时不得存 `技师`。  
4. **禁止臆造补全**：证面只有 `三级` 时不得自动改成 `三级/高级工`；只有 `技师` 时不得自动改成 `二级/技师`。  
5. **预览即入库**：预览表展示值必须与 commit 写入值相同，禁止确认时再改写。  
6. **系统元数据隔离**：`certificate_type`、`tenant_id`、`people_id` 等非证面字段可写，但 UI/导出「证书信息」区不得把它们标成证面原文。

### 4.1 解析成功门槛（可确认回填）

**硬门槛（与 P0 相同）：** 必须解析出 **身份证号 + 证书编号**，且已选班内身份证唯一匹配。

**软字段（职业/工种/等级/机构/日期等）：**

- 解析成功 → 预览展示**原文**并写入；  
- 解析失败 → **不挡主流程**（仍可回填证号+文件），对应列留空 + 警告「某某字段未识别」；  
- **不做**「半截等级 → 标准五档」的自动补全。

### 4.2 等级字段规则（与证面一致）

| 证面文本（等级行） | 入库 `level` |
|--------------------|--------------|
| `三级/高级工` | `三级/高级工` |
| `二级/技师` | `二级/技师` |
| `一级/高级技师` | `一级/高级技师` |
| `四级/中级工` | `四级/中级工` |
| `五级/初级工` | `五级/初级工` |
| 仅有 `三级`（无「/高级工」） | `三级`（原文；警告「非完整级数/称谓」） |
| 抽不到 | `NULL` |

说明：系统内其它模块的「五档标准称谓」可用于**展示映射或校验提示**，**不得在导入时改写证面原文**。若下游报表强制要五档，应另列 `level_normalized`（可选 P1），与 `level`（证面）分离。

### 4.3 覆盖策略（沿用并细化）

| 场景 | 行为 |
|------|------|
| 无证书行 | INSERT，写全量**本次解析原文** + 文件 |
| 已有 `GC-…` 假号 | 允许覆盖证号、文件及全部解析字段 |
| 已有相同真实证号 | 更新文件路径 + 用本次解析原文**覆盖**对应字段（幂等重导纠错） |
| 已有不同真实证号 | 拒绝（`EXISTING_CERT_CONFLICT`） |
| 软字段本次为空、库内已有值 | **保留库内旧值**（避免解析失败把已正确证面擦空） |

### 4.4 身份证号与姓名

- 身份证号：仅作匹配键，**默认不写入** `train_certificate`（避免敏感冗余）；需要「证面全量归档」时另议。  
- 姓名：`user_name` **优先写 PDF 解析姓名**；与花名册不一致 → 警告仍可写（以证面为准）。**禁止**在已解析到证面姓名时改用花名册姓名落库。

## 五、解析设计

### 5.1 输入与前置

- 仅处理有**文本层**的 PDF（PDFBox `PDFTextStripper`）。  
- 无文本 / 加密 / 损坏 → `PARSE_FAILED`（OCR 二期）。  
- ZIP / 多文件夹展开逻辑复用 P0。

### 5.2 版式锚点（人社技能等级证常见版式）

以样例结构为基线（行序可能因抽取换行略变，实现时用「正则 + 相对位置」双保险）：

```
{姓名}
居民身份证
{18位身份证}
{S…证书编号}
本证书由      {发证机构}      颁发，
…
————————————
{职业名称}        ← 分隔线后第 1 个非空短行
{工种名称}        ← 第 2 行
{等级称谓}        ← 第 3 行（含「级」或「技师」）
{评价机构全称}    ← 日期上一行
{yyyy}年{M}月{d}日
{查询 URL 若干}
```

### 5.3 字段抽取优先级

| 字段 | 优先级 |
|------|--------|
| 证书编号 | ① 正文 `S\d{18,}` ② 文件名第一段；不一致 → 以正文为准 + warning |
| 身份证 | 正文 18 位正则（不从文件名第三段猜） |
| 姓名 | ① 文首姓名行 ② 文件名第二段；与花名册不一致 → warning |
| 证件类型 | 正文含「居民身份证」等 → **原文**；抽不到 → 空（**禁止默认填「居民身份证」**） |
| 发证机构 | 「本证书由…颁发」中间机构名（去多余空白，不改字） |
| 职业 / 工种 / 等级 | 分隔线后连续三行**整行原文**；失败则留空（**禁止**工种白名单猜词冒充） |
| 评价机构 | 匹配 `yyyy年M月d日` 上一非空行，且不像 URL、不像等级行 |
| 核发日期 | `(\d{4})年(\d{1,2})月(\d{1,2})日` → 存 `yyyy-MM-dd`（与证面同一天；**禁止**导入日） |
| 查询地址 | 抽取证面 URL **原文**列表（P1）；不得改域名或丢「(国家)/(广西)」标注除非单独存 note |

### 5.4 代码落点

| 项 | 建议 |
|----|------|
| 解析器 | 抽取独立类 `RensheSkillCertPdfParser`（便于单测），`GraduationCertificateImportApplicationService` 只编排 |
| 单测样本 | 至少覆盖：三级/高级工、二级/技师、一级/高级技师、工种非白名单、证号与文件名不一致、无日期 |
| 预览缓存 | `CachedItem` 扩展携带新字段，commit 一并写入 |

## 九、风险与对策

| 风险 | 对策 |
|------|------|
| 不同省份/协会版式差异 | 解析器插件化；失败降级为「仅证号+文件」+ 警告 |
| 「技师」与「高级技师」 | 等级行**整行匹配**优先于子串；禁止把「高级技师」存成「技师」 |
| 职业与工种行序颠倒 | 用等级行（含 `/` 或「级」「技师」）定位，向上取两行原文；单测多版式 |
| 日期写成导入日 | 单测断言：有证面日期时 `issue_date` 必须等于证面日 |
| 臆造补全 | Code Review / 单测禁止「仅三级→三级/高级工」类逻辑 |
| 重导擦掉已有工种 | 软字段「空不覆盖」 |
| 大包超时 | 沿用 P0 分批；必要时异步 preview（P1） |
