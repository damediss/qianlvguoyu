# 第一阶段可编码规格

版本：V0.1 草稿  
日期：2026-05-01  
用途：作为第一阶段创建后端、前端、数据库迁移、接口和测试用例的直接依据。

## 已锁定范围

第一阶段采用“平台底座 + 培训学习考试闭环”：

1. 后台底座：登录、租户组织、用户、角色、菜单、字典、文件、操作日志。
2. 培训基础：课程、章节、题库、试卷、考试安排。
3. 学员闭环：课程学习、练习/考试、成绩、错题。
4. 流程样板：课程发布审批，支持提交、通过、驳回、留痕。
5. AI 样板：课程大纲草稿生成，结果只保存为草稿，不直接发布。

## 实施默认值

| 项目 | 默认值 |
| --- | --- |
| 主工程 | `services/platform-api/` |
| AI Gateway | `services/ai-gateway/` |
| MCP 工具服务 | `services/mcp-server/` |
| 文件服务 | `services/file-service/`；一期可独立，也可先作为 `platform-api` 内部模块 |
| 工作流服务 | `services/workflow-service/`；一期可先将 Flowable 集成在 `platform-api`，但按独立边界设计 |
| 后台前端 | `apps/admin-web/` |
| 学员端 | `apps/student-web/` |
| 数据库 | MySQL + Flyway 迁移 + 核心接口测试 |
| 主键 | 雪花 ID，数据库类型统一 `BIGINT` |
| 多租户字段 | `tenant_id` |
| 文件本地开发 | local-disk adapter |
| 生产文件存储 | Cloud OSS Adapter，供应商可配置 |
| 流程引擎 | Flowable，第一阶段只做课程发布审批样板 |
| AI/MCP | 独立服务边界，第一阶段只做课程大纲草稿样板和一个受控工具调用样板 |
| 架构口径 | 可控服务化起步，不做全量微服务 |
| 性能口径 | 轻核心、慢任务异步、热点缓存、文件走 OSS/COS、AI 独立隔离 |
