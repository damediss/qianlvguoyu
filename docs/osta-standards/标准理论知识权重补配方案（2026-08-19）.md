## 3. 本方案不配的课程及原因

### 3.1 B 类：车轮轧制（228-232）——国标明确不适用

《金属轧制工》标准原文："本职业包含但不限于下列工种：轧钢工、热压延工、冷压延工、轧管工、车轮轧制工、轧制备品工。**本标准仅适用于热压延工、冷压延工两个工种**。"

即该标准的权重表对车轮轧制工**无法律效力**。若强行借用热压延工列：树节点"轧辊加工及处理、备品选配及加工"在标准中无对应项目，标准的"质量检查"在树中无对应节点，映射质量差、误导引擎。

**建议**：跳过不配（引擎走回退链 ② type=0 人工规则）；待取得车轮轧制工适用标准后按指南 §4.3 流程补配。**请拍板**。

### 3.2 C 类：有题但知识树残缺（283、285、291、292）

| 课程 | 题量 | 知识树现状 |
|---|---|---|
| 283 焊接设备操作工初级 | 1709 | 两个"基本要求"L0 根、两个"职业道德"L1，另有"焊工"等疑似测试根节点 |
| 285 焊接设备操作工高级 | 607 | 存在"焊工/1/2/3"垃圾节点链 |
| 291 电工技师 | 504 | 仅 1 个 L1（职业道德），全部题挂在唯一 L3 上 |
| 292 电工高级技师 | 348 | 同上 |

权重必须挂在健康的 L1 节点上才有意义。这 4 门需**先修/重建知识树**（单独任务），本方案不配。

### 3.3 D 类：无题且无知识树（23 门）

矿山救护工 263-267、电焊工 268-272、气焊工 273-275、钎焊工 278-281、焊接设备操作工 284/286/287、电工 288-290。

无 L1 节点可挂（物理无法配置），且题库无题（配置后引擎也无题可取）。其中 263 矿山救护工初级的 L1 节点标题带"A-A"后缀，疑似测试数据。本方案不配；待题库与知识树建成后按指南 §4.3 流程补配。

## 4. 执行方式与 SQL 规范

1. **执行通道**：Agent 通过本机 mysql CLI 直连 `114.132.67.185:3308/gjjddb`（账号 `gjjddb`）执行；不经过 SaaS 后端。
2. **幂等设计**（可重复执行不产生重复行）：
   - 主表：`INSERT ... SELECT ... FROM DUAL WHERE NOT EXISTS (SELECT 1 FROM exam_knowledge_rate WHERE course_id=? AND type=3 AND deleted=0)`，随后用 `ROW_COUNT()` 判断是否本次新插入；
   - detail：仅当主表本次新插入（`ROW_COUNT()=1`）时才插入，rate_id 取该课程已有 type=3 行 id。
3. **字段口径**：`type=3`，`title='国标理论知识权重'`，`is_standard=1`，`sort_number=1`，`status=1`，`user_id=NULL`，`deleted=0`，`tenant_id=10159`；主表 comments 注明标准名+等级+工种列；detail comments 注明标准项目名（合并/改名节点附注树节点名）。
4. **不改 PHP 任何代码、不动存量 type=0 行**（指南 §7）。

FROM exam_knowledge_rate r
JOIN exam_knowledge_rate_detail d ON d.knowledge_rate_id = r.id AND d.deleted = 0
WHERE r.type = 3 AND r.deleted = 0
  AND r.course_id IN (163,164,165,166,167,198,199,200,201,202,208,209,210,211,212,
                      213,214,215,216,217,218,219,220,221,222,223,224,225,226,227)

SELECT course_id, COUNT(*) AS cnt FROM exam_knowledge_rate
WHERE type=3 AND deleted=0 GROUP BY course_id HAVING cnt > 1;
-- 预期：0 行

-- ③ detail 挂载节点确为理论树 L1 且未删除
