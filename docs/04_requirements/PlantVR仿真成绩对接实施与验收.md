# PlantVR 仿真成绩对接实施与验收

## 目标

云平台竞赛的“成绩与排名”模块通过受控内部接口查询 PlantVR 赛事场次成绩，使用身份证号匹配云平台赛段选手，再以姓名和赛事范围进行二次核验。确认后的成绩进入现有统一成绩来源、总分计算和排名快照链路；不采用一次性文件导入作为对接方案。

## 接口流程

1. 云平台赛事先完成参赛单位、选手、工种/等级和仿真赛段配置；报名名单通过云平台选手模板预检后导入，成绩不通过报名表导入。
2. 在仿真赛段的“配置 PlantVR 赛事场次”窗口中，云平台分页查询 PlantVR 场次目录，由业务人员搜索并选择赛事场次。列表展示场次名称、主办租户和状态；主办租户 ID 与场次 ID 不再要求手工填写，可选仿真模块过滤条件保留。
3. 点击“查询并核验”后，云平台异步分页读取 PlantVR 的成绩尝试和 `scoreDetail`，快速返回同步批次并轮询状态。
4. 云平台只持久化脱敏身份证号、外部流水号、匹配结果、成绩快照和评分明细；原始身份证号仅在内存中用于匹配。
5. 身份证号唯一匹配且姓名一致的记录进入可确认列表；缺少选手、姓名不一致、总分与明细不一致、同一选手多次尝试等记录保留为异常，不自动覆盖。
6. 人工确认后通过统一成绩来源写入 `source_system=plantvr`、`source_type=simulation`，自动触发现有总分和排名计算。每条外部流水号幂等，重复同步不会产生重复成绩。

## 页面口径

仿真科目面板提供 PlantVR 场次配置、同步状态、异常条数和核验行列表。“配置 PlantVR 赛事场次”通过场次目录查询和搜索选择，不让业务人员抄录或猜测接口 ID。选中选手后，明细按完整成绩单展示：标题为“考核模块 - 模块名称”，列为“序号、考核项目、得分标准、配分、扣分项、得分”。

字段必须按来源分别映射：序号取考核阶段/分组标题，考核项目取项目名称，得分标准取评分规则文本，配分取该项满分（`maxScore` / `allocatedScore`），得分取实际得分（`score` / `earnedScore`）；不得用得分回填配分。扣分项汇总对应扣分原因和分值。非空字段原样展示；选手记录中缺失的字段显示为空白，不使用短横线或推测值。旧版仅含环节名和得分的数据仍可显示，未上报的配分、标准和扣分项保持空白。

## 收口验收

赛事名称固定为：

`2026年全国行业技能职业竞赛“中国铝业杯”第十八届全国有色金属行业职业技能竞赛——铝电解操作工`

验收数据要求：

- 赛事标识为 `2026nqgxyjnzyjszglybdsbjqgysjsxyzyjnjsldjczg2026102216`，以选手“黄永权”的仿真成绩作为完整明细样例。
- 云平台只启用仿真内容，赛事、赛段、工种/等级、选手身份证号和姓名与 PlantVR 场次一致。
- 使用 PlantVR 场次绑定执行一次查询、核验、人工确认和总分刷新。
- 在云平台“成绩与排名”中检索“黄永权”，仿真总分必须与 PlantVR 当前正式成绩一致，评分明细的项目、配分、扣分项和得分逐项一致。完整样例包含“装炉准备 / 穿戴劳保用品 / 穿戴劳保用品 +5分 / 配分 5 / 扣分项空白 / 得分 5”；后续“焦粒铺放、装炉、软连接与分流片、通电焙烧、拆除不停电装置、焙烧测量、焙烧收尾”等行按 PlantVR 原始数据展示。
- 若 PlantVR 存在同一选手多次尝试，必须先在 PlantVR 选定正式成绩或在云平台异常列表中处理，禁止自动取最高分或最新分。
- 验收记录应保存云平台同步批次、PlantVR 外部流水号、云平台成绩来源 ID、同步时间和结果截图/导出文件，便于追溯。

## 配置

云平台环境变量见 `infra/env/platform-api.env.example`：`PLANTVR_COMPETITION_ENABLED`、`PLANTVR_BASE_URL`、`PLANTVR_INTERNAL_SECRET`、超时和分页大小。PlantVR 侧使用已有 `X-Internal-Secret` 内部接口守卫，不把共享密钥写入仓库或返回前端。
