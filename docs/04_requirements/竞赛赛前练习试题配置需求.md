# 竞赛赛前练习试题配置需求

## 目标

在竞赛模块「选手管理」下增加「赛前练习」目录，首期提供「试题配置」页面。管理员按赛事工种、参赛等级和赛段建立赛前练习任务，从课程题库中按题型抽取指定数量的试题。

首期只创建后台任务和题目快照，不向 APP 选手端推送。任务数据需保留目标赛事范围、题库来源范围、题型配额、抽中的试题和任务状态，为后续选手端分发提供稳定输入。

## 管理端流程

1. 选择赛事、赛事工种、参赛等级和该范围内已启用的赛段。
2. 从课程题库多选工种和等级。题库范围按所选工种与等级组合查询。
3. 系统展示各题型当前可用数量；管理员为题型填写抽取数量，数量不得超过可用数量。
4. 输入任务名称或使用系统生成的默认名称，提交后生成赛前练习任务。
5. 任务列表展示赛事范围、题库范围、题型配额、总题数、状态和生成时间。

## 课程题库口径

- 资源来自课程模块的 `exam_course`、`exam_knowledge_structure`、`exam_exam_detail`，与竞赛正式比赛题库分开。
- 只统计启用课程、三级知识点下启用且终审通过的题目；题型沿用平台题型白名单。
- 课程等级统一按国标等级选择：5 级/初级工至 1 级/高级技师；后端按 `exam_course.level` 的 0 至 4 序数换算。
- 题型配额在任务生成时再次校验。若题库审核状态或试题数量已变化，返回错误并要求刷新可用数量。

## 任务数据与后续分发

- 任务保存赛事、赛事工种、参赛等级、赛段名称快照，以及课程题库工种/等级范围和题型数量快照。
- 生成时为每道入选试题保存源题 ID、源课程信息和题目内容快照。后续课程题库编辑不会改变已生成任务中的题目。
- 首期任务状态为「已配置」，分发状态为「未推送」。本期不创建选手名单、选手端任务查询、推送、作答、判分或结果回传接口。
- 后续 APP 推送按任务关联的赛事、工种、等级和赛段解析适用选手；推送记录应单独建模，以支持重试、撤回和选手任务进度，不覆盖本期的题目配置数据。

## 验收范围

- 菜单路径为「竞赛 → 选手管理 → 赛前练习 → 试题配置」。
- 赛事工种、参赛等级、赛段按前置选择联动；切换上游范围会清除失效的下游选择。
- 题库工种和等级支持多选；题型表显示当前可用数，并阻止超量配置。
- 任务只在课程题库权限校验通过后创建，保存成功后列表可查询，并显示「已配置 · 待推送」。
- 选手端推送与作答功能不属于本期交付。
