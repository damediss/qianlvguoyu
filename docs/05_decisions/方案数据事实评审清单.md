# 方案数据事实评审清单（轻量，随方案走）

> 来源：《Agent数据关系理解增强方案》T6（2026-10-20）。不新建重量级模板；供方案文档 §现状 自检 + owner/verifier 抽查用。
> 背景事故：真题共享方案只对 `train_exam_list` 做 `SHOW COLUMNS` 就断言"工种/等级只存在于标题文本"，漏掉已有 1067 行数据的 `train_exam_work_type_list`（踩坑库 #37）。

## 自检三问（producer 提交前）

1. 现状表每一行是否有 SQL 或 `file:line` 证据路径？
2. 存在性断言（肯定/否定）是否附了 `schema-find` 输出原文或五步结果？
3. 无证据路径的行是否已标"未核实"、且未进入结论？

## verifier / owner 抽查

- **否定性结论**（"不存在/只有/没有"）：按 `docs/agent/数据关系速查.md` 30 秒红线独立重跑并附结果，不得由生产者自证。
- **肯定性结论**（"在 X 表 / 由 X 提供"）：同样独立重跑——ER 图画错与漏表同罪（未确认的关系不要画）。
- 抽查入口：`node scripts/agent/schema-find.mjs <关键词> [--db test]`。
- 单 Agent 阶段无 verifier：直接检查方案文档内的输出原文，不依赖口头说明。
