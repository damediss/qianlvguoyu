# 千铝工投云平台与智能体开发部账号与访问权限管理制度

制度编号：QLGT-YWGL-2026-103　　版本：V1.1　　发布日期：2026-10-16

## 第一章　总则

**第一条**　为管控云平台、服务器、数据库等各类账号的完整生命周期，落实最小权限与离职回收，堵住权限失控风险，特制定本制度。本制度遵循部门制度“简洁、可测试、可维护、持续迭代”的共同标准。

**第二条**　本制度适用于：云控制台账号、服务器 SSH 账号与密钥、数据库账号、VPN/跳板机账号、代码仓库账号，以及 LLM API Key、对象存储密钥等第三方服务凭证。

## 第二章　账号分类与申请审批

**第三条**　云主账号仅由运维负责人持有并开启多因素认证；日常使用一律通过子账号，按角色授予权限。

**第四条**　服务器禁止 root 直接登录，统一使用个人账号加 SSH 密钥登录，sudo 权限按岗位开通。

**第五条**　数据库账号按“环境 + 用途”创建，禁止多人共用同一账号；应用程序使用专用账号，与个人账号分离。

**第六条**　账号申请流程：申请人说明用途、权限范围、期限 → 直接上级审核 → 运维负责人批准 → 开通并登记账号清单。第三方服务凭证（如 LLM API Key）按系统申请，禁止个人私开。

## 第三章　最小权限原则与权限分级

**第七条**　权限分三级：只读（查询、看日志）、操作（部署、重启、常规变更）、管理（账号、权限、安全配置）。默认只授予完成工作所必需的最低级别。

**第八条**　生产数据库写权限仅限运维负责人与备份、应用程序专用账号持有；开发人员排查生产问题原则上使用只读账号。

**第九条**　临时权限（如故障处置期间的提权）须设定有效期，到期自动或人工回收，最长不超过 7 天。

## 第四章　SSH 密钥与凭证管理

**第十条**　禁止通过即时通讯工具明文发送密码与密钥；凭证传递使用部门认可的密码管理工具或加密渠道；禁止明文密码出现在命令行与会话记录（如 shell history、脚本参数、终端回显）。

**第十一条**　禁止将密码、密钥、API Key 提交至代码仓库（含配置文件的明文形式）。发现凭证进入仓库历史的，当日吊销轮换并清理历史。

**第十二条**　SSH 私钥必须设置保护口令，不得复制给他人使用；服务器密码、数据库密码、API Key 每 180 天轮换一次，怀疑泄漏时立即轮换。密钥轮换由部门负责人组织执行，具体操作按公司密钥管理流程办理。

## 第五章　权限定期复核与离职/转岗回收

**第十三条**　每季度由 3 人团队交叉互核（轮换）执行权限复核：导出各类账号清单，由各资源责任人逐项确认“保留、降权、回收”，复核记录归档。

**第十四条**　员工离职当日，由运维负责人回收其全部账号与密钥，包括云控制台、服务器、数据库、VPN、代码仓库与第三方服务；回收清单经双方确认后归档。

**第十五条**　员工转岗后 3 个工作日内完成权限调整，仅保留新岗位必需权限。

## 第六章　附则

**第十六条**　本制度由部门负责人负责解释。

**第十七条**　本制度自发布之日起施行。
