# 竞赛模块 MVP 范围清单

本清单是 [competition-development-plan.md](competition-development-plan.md) 的可执行摘要。

## MVP 交付闭环

```text
运营/企业管理员创建赛事、赛段和基础任务模板 → 平台赛事邀请企业或企业创建内部赛
→ 企业导入并确认参赛名单 → （按赛事配置）运营审核 → 发布通知
→ 选手身份证匹配和手机号验证码注册 → 资格激活 → 选手查看并提交基础任务
→ （按任务配置）运营验收 → 运营端查看可追溯任务记录
```

## 包含

- 当前先交付 `apps/admin-web` 的平台赛事、企业内部赛、赛段、企业名单导入/审核、基础任务模板和站内通知运营能力。
- 当前 `platform-api` 先交付赛事—企业参与关系、赛事、赛段、任务模板、企业名单、资格和站内通知；权限、多租户、审计、统一 API 响应。
- `apps/competition-h5`、身份证匹配、手机号验证码、选手身份、文件 ID 关联、任务实例/提交/验收均移至基础链路 B。

## 不包含

- 在线考试、自动交卷、学习课程、成绩/排名/晋级。
- 专家工作台、公开数据大屏；企业管理能力先以内嵌 `admin-web` 企业角色视图交付。
- AI 助手、MCP 写操作、复杂流程编排。

已冻结：企业导入名单为唯一报名入口、企业可建内部赛、统一题库复用、两个 AI 入口。身份证匹配、手机号验证码、短信供应商成本和文件规则当前延后至基础链路 B；评分细则、防作弊、排行公开与大屏内容继续以专项任务建设。
