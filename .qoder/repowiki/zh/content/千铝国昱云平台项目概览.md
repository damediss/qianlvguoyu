# 千铝国昱云平台项目概览

## 项目定位

千铝国昱云平台是一套面向铝加工行业的 SaaS 培训考试平台，核心目标是跑通"平台底座 + 培训学习考试闭环"。一期 MVP 不涉及复杂驾驶舱、SSO 登录、计费套餐、自动组卷算法等高级功能。


## 目录结构

| 目录 | 用途 |
| --- | --- |
| `docs/` | 需求、方案、正式交付、项目台账、技术决策 |
| `prototypes/` | HTML 原型、系统截图、流程演示页面 |
| `apps/` | 正式前端应用（管理后台 admin-web、学员端 student-web） |
| `services/` | 正式后端服务（platform-api、ai-gateway、mcp-server、file-service、workflow-service） |
| `packages/` | 共享类型、UI 组件、内部 SDK |
| `ai/` | Prompt、Skill、Agent 配置 |
| `workflows/` | n8n、BPMN、流程自动化规则 |
| `infra/` | Docker、Nginx、数据库、环境变量模板 |
| `scripts/` | 文档生成、数据处理、启动脚本 |
| `data/` | 导入模板、脱敏样例、业务字典 |
| `assets/` | 公共图片、图标、演示素材 |
| `outputs/` | 生成产物（禁止作为需求源头） |
| `archive/` | 历史资料和暂未整理文件 |

## 已实现功能

- **平台底座**：租户管理、组织管理、用户管理、角色权限、菜单权限
- **权限框架**：Sa-Token Token 管理（3天过期、并发登录），Spring Security `@PreAuthorize` 鉴权
- **多租户**：TenantContextHolder + TenantContextFilter + MyBatis-Plus TenantLineInnerInterceptor
- **全局异常处理**：覆盖 Sa-Token 异常、参数校验、业务异常
- **知识库**：知识库 CRUD、文档管理、权限控制
- **题库管理**：工种管理（树形结构）、科目管理、专家授权管理
- **试题管理**：试题 CRUD、导入/导出（Excel）
- **知识结构（细目表）**：知识点树管理、导入/导出
- **组卷计划**：组卷配置、科目分配
- **查证管理**：用户管理、证书查询、Excel 导入导出、API 查证
- **前端管理端**：登录页、AppShell 布局、侧栏菜单、各业务页面

## 一键启动开发环境

```bash
# macOS: 双击根目录 start-dev.command
# Windows: 使用 scripts/start-dev-server.cmd 或手动启动

# 后端构建
$env:JAVA_HOME = "D:\Program Files\Java\oracleJdk-21"
mvn.cmd compile -f services/platform-api/pom.xml -s scripts/custom-maven-settings.xml

# 前端开发服务器
cd apps/admin-web && npm run dev

# 访问
# 前端: http://localhost:5173
# 后端: http://localhost:8080/api
# 健康检查: http://localhost:8080/api/actuator/health
```

启动时添加 `-Dspring.profiles.active=dev` 或 `-Dspring.profiles.active=prod`，logback-spring.xml 中的 `<springProfile>` 自动切换。默认无 profile 时行为等同于 dev。

## 部署策略

- 测试、预生产和生产服务器使用 Linux Docker Engine / Docker Compose
- 一期不引入 Kubernetes
- 文件存储优先使用阿里云 OSS 或腾讯云 COS（一期不用 MinIO）
- Redis 优先使用托管 Redis / Tair
