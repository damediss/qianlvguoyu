    ADD COLUMN update_time DATETIME DEFAULT CURRENT_TIMESTAMP

## 6. 风险 / 暗坑

| 风险 | 触发条件 | 应对 |
|---|---|---|
| Flyway 迁移失败 | `V20260609_001` 跟历史 version 撞车 | 先 `SELECT version, description, success FROM flyway_schema_history ORDER BY installed_rank DESC LIMIT 5` 确认 09 号段没被占 |
| 后端 updateTime 字段没透传 | 漏改 VO Converter / DTO | 检查 `ExamExamDetailVO` / `ExamExamDetailConverter`,必要时手动 copy |
| 前端 `batchDeleteExamDetails` 接口后端没 | 后端 worker 没排这个任务 | 临时走循环单删,P2 补接口 |
| 菜单 SQL 跑挂 | parent_id=2064170197574156289 不存在 | 先 SELECT 父菜单,缺则停手汇报 |
| 多租户隔离被批量删除绕过 | 忘了带 tenantId | 后端 batchDelete 必须先按 `tenant_id` 过滤再删,前端不用管 |
| 列名 `update_time` vs `updated_at` | 不同团队命名习惯 | 后端约定 `update_time`,前端 TS 字段名 `updateTime`,MyBatis-Plus 默认命名策略对齐 |
| 删除后行号跳变 | 序号列用了 `index + (page-1)*size` 但 total 没刷 | 用 `queryClient.invalidateQueries` 后,ProTable/Table 自带分页刷新 |
