# ai-gateway

AI 能力入口服务，可采用 Spring Boot + Spring AI 或 Node / TypeScript 实现。

## 职责

1. 统一接入大模型。
2. 管理 Prompt 模板、AI 任务、生成记录和调用日志。
3. 提供课程大纲草稿生成、材料检查等 AI 样板能力。

## 边界

1. 不直连业务数据库。
2. 不直接发布课程、审批或修改核心业务状态。
3. 写操作默认生成草稿或待办，关键动作必须由人工确认。

## 约定

1. 通过 `platform-api` 受控 API 读取业务数据和保存草稿。
2. 健康检查接口预留为 `/health` 或 `/actuator/health`。
3. 模型 Key、网关地址和供应商配置只放环境变量模板，不提交真实密钥。
