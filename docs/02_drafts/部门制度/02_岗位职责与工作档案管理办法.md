# 千铝工投云平台与智能体开发部岗位职责与工作档案管理办法

制度编号：QLGT-BMGL-2026-002　　版本：V1.0　　发布日期：2026-10-16

## 第一章　总则

**第一条**　为细化各岗位完整工作职责、任职资质条件、标准化工作清单，建立全员个人工作档案，实现平台开发、模型研发、场景落地、运维交付等所有工作成果全程留痕、可查可溯，明确各岗位指标落地责任，杜绝权责模糊、工作脱节，特制定本制度。

**第二条**　本制度以 2026-09-09 版《云平台与智能体开发部岗位职责（内部管理版）》为基础扩建；原件随原交付目录遗失的，以本制度为准重建。

**第三条**　部门现实为 3 名开发岗成员，本制度按"2 类主岗 + 6 个兼任角色"设计，不设无法由现有人员承担的专职岗位。

## 第二章　岗位设置与兼任矩阵

**第四条**　主岗分两类：

| 主岗 | 职责范围 | 任职资质 |
|---|---|---|
| 平台开发岗 | 后端主干（Java/Spring Boot）、数据库、接口、管理端联调 | 3 年以上 Java 后端经验，熟悉多租户与 MySQL 优化 |
| 智能体研发岗 | AI 三学算法、LLM 集成、RAG 与知识库、数据运营 | 2 年以上 AI 应用开发经验，熟悉 prompt 工程与检索链路 |

**第五条**　兼任角色 6 个，全员按矩阵分担：

| 兼任角色 | 职责 | 任期 |
|---|---|---|
| 部门负责人 | 制度制定、重大变更与故障升级审批、月度指标评审、对外接口 | 公司任命 |
| 产品与方案 | 需求梳理、PRD 编制、技术方案与选型论证 | 长期 |
| 质量角色 | 代码互审、提测准入把关、缺陷定级复核 | 按月轮换 |
| 运维轮值 | 告警首响、巡检、发布执行、台账维护 | 按月轮值 |
| 知识管理员 | 文档归档、技术资产清单、工作档案、图书台账 | 长期 |
| 商务配合 | 线索收集、客户对接、素材提供、申报材料 | 长期 |

**第六条**　分工建议（以公司任命文件为准，每季度复盘时评估调整）：

| 成员 | 主岗 | 兼任 |
|---|---|---|
| 覃健 | 平台开发岗 | 部门负责人、产品与方案 |
| 程志伟 | 平台开发岗 | 质量角色 |
| 郝少盟 | 智能体研发岗 | 运维轮值、商务配合 |

**第七条**　兼任上限：每人兼任角色不超过 2 个；季度复盘时评估兼任负荷，超负荷的由部门负责人调整分工或上报公司申请增员。

## 第三章　标准化工作清单

**第八条**　每名成员的例行工作清单（兼任角色另有专项清单）：

| 频率 | 事项 |
|---|---|
| 每日 | 认领告警与待办（轮值期）；提交信息可追溯 |
| 每周 | 参加周例会；完成周检表本人条目；更新所负责台账 |
| 每月 | 输出本人月度成果小结（供月报脚本归集）；参与月度复盘会 |
| 每季度 | 参与权限复核与兼任负荷评估；完成所负责制度的执行自查 |

**第九条**　任务分解到个人，完成标准事先写明；超期任务在周例会说明原因并重新定级或拆分。

## 第四章　个人工作档案

**第十条**　每名成员建立个人工作档案，一人一档，内容包括：

1. 岗位与兼任任命记录（含生效日期）；
2. 工作成果记录：需求单、MR、验收报告、复盘报告、攻关成果、场景方案（按月归档索引）；
3. 培训与成长记录：参加的培训、分享、考核结果；
4. 违规与整改记录（如有）；
5. 交接清单（人员变动时）。

**第十一条**　档案由知识管理员维护，每月随月报更新一次；成员本人可随时查阅本人档案；部门负责人可查阅全部档案；档案作为绩效考核、晋升评议、工作交接的依据。

**第十二条**　人员变动（离职、转岗、长假）时，交接清单须列明：在办事项、未闭环问题、所负责制度与台账、账号权限回收项（按 YW-03 执行），交接记录归档。

## 第五章　指标落地责任

**第十三条**　附录 A 甲档指标按以下方式落到人：工作闭环完成率、需求按期交付率按需求单责任人计；Review 通过率、缺陷时效按质量角色计；故障响应、备份可恢复按运维轮值计；知识库与喂养按知识管理员计；场景输出按产品与方案角色计。

**第十四条**　丙档贡献指标（线索、素材、转介绍）记入贡献台账，按月通报表扬，不与绩效扣分挂钩。

## 第六章　附则

**第十五条**　本制度由部门负责人负责解释，自发布之日起施行。
