## 一、快速认识培训模块

培训模块帮培训部门把「找企业、定方案、分好班、开起班、跟住过程、接到考试与补贴」放到一套系统里，不再靠 Excel、微信群、纸质台账拼起来。

### 1.1 你能用它做什么

- 统一管理企业培训需求、三年规划、分班方案
- 在线确认班级花名册、课表、师资
- 一键生成开班申报材料、补贴申报材料
- 按班级记录考勤、课堂影像、作业、日志
- 导入人社考试成绩、引用认定结果
- 办理结业、导出获证名册、上传证书
- 跟踪补贴申报与拨款进度

### 1.2 管理端入口

登录管理端后，从左侧菜单「培训」进入，主要页面包括：

- 培训流程导航（企业调研 → 方案规划 → 分班 → 开班准备 → 开班申报 → 跟班 → 考试 → 申报补贴）
- 培训实施工作台（跟班）
- 毕业典礼
- 补贴申报
- 师资库、课表、班级花名册等辅助页面

### 1.3 双端协同

| 端 | 谁用 | 主要用途 |
|----|------|----------|
| 管理端 Web | 培训教务、企业班主任、老师 | 流程推进、审核、材料生成、班级监管 |
| 手机 App | 学员、老师、班长、班主任 | 填报资料、签到、刷题、交作业、上传影像 |

> **关键原则**：管理端与 App 数据相通。学员在 App 填的资料，教务在后台能直接审核；老师在 App 布置的作业，后台能看到完成率。

## 二、总体流程图

```text
阶段① 项目启动与规划
  企业调研 → 方案规划（企业确认） → 分班

阶段② 开班与执行准备
  开班准备（花名册/师资/课表/角色） → 开班申报（材料生成） → 信息收集

阶段③ 培训实施与考核
  跟班（考勤/留痕/作业/日志/刷题） → 考试 → 结课 → 认定获证

阶段④ 项目收尾
  补贴材料 → 拨款跟踪 → 资料归档 → 项目结算
```

## 三、开班前准备

### 3.1 企业调研

**目标**：摸清企业培训需求与人员底数，形成可进入规划的数据。

**操作步骤**：

1. 进入「培训 → 企业调研」，点击「新建调研任务」。
2. 选择或录入企业信息、联系人、调研组织。
3. 创建调研表字段（姓名、身份证、手机、岗位、意向工种、意向等级等）。
4. 通过以下方式采集人员：
   - **导入 Excel**：下载模板，按字段填写后上传
   - **扫码填写**：生成二维码或链接，发给企业人事或员工
5. 查看「采集进度」：应交 / 已交 / 缺项，督促企业补全。

**注意事项**：

- 身份证、手机号必须校验，重复人员会自动提示。
- 调研结果可直接衔接下游「方案规划」，减少二次录入。
- 建议调研结束后再进入方案规划，避免名单不齐导致分班返工。

**验收标准**：明确这家企业要训什么工种、大致多少人、名单基本可用。

---

### 3.2 方案规划

**目标**：输出可被企业确认的人才培养/培训规划，锁定可进入分班的人员范围。

**操作步骤**：

1. 进入「培训 → 方案规划」，点击「新建规划」。
2. 选择关联企业与调研结果，填写：
   - 培训模式（岗位技能提升 / 新型学徒 / 自费认定等）
   - 目标工种、等级、规模
   - 年度安排、培训周期
3. 生成方案后，点击「推送企业确认」。
4. 企业侧收到确认通知，可确认、驳回或要求补交名单/排班资料。
5. 查看确认状态：已确认 / 待补交 / 已驳回。

**注意事项**：

- 企业未确认前，不建议进入分班。
- 若企业要求补交，需重新收集名单或排班表后再推送。
- 支持上传回传附件，系统记录版本。

**验收标准**：企业点头确认后，系统内存在「可分班」的人员池。

---

### 3.3 分班

**目标**：把企业确认名单按规则拆成可开班的班级，并在系统中生成真实班级与花名册。

**操作步骤**：

1. 进入「培训 → 分班」，选择已确认的方案规划。
2. 点击「自动分班」，系统按班额、工种、等级、车间班组等约束生成分班草稿。
3. 在分班草稿中可手动调整：
   - 调人（把学员从 A 班调到 B 班）
   - 拆班（一个班拆成两个班）
   - 合班（两个班合并）
   - 标注异常（身份证重复、信息缺失等）
4. 点击「提交企业审核」，企业在线确认分班方案。
5. 企业审核通过后，点击「物化班级」，系统自动生成班级和花名册。
6. 系统会自动为学员开通/补开 App 账号；未开通账号的学员会给出清单，可一键补开。

**注意事项**：

- 物化前务必确认班级人数、工种、等级无误。
- 物化后班级信息会进入下游「开班准备」和「跟班」。
- 支持按「排班表」驱动分班，若主路径是排班表，请优先使用排班表入口。

**验收标准**：管理端能看到真实班级卡片，花名册人数与企业确认一致，学员可用手机号/身份证 + 默认密码登录 App。

---

### 3.4 开班准备

**目标**：班级落地后，配齐人、师、课表与资料收集入口，达到能申报、能开班条件。

**操作步骤**：

1. 进入「培训 → 开班准备」，选择班级。
2. 维护花名册：
   - 增删改查学员
   - 设置班长（在花名册中标记 `is_leader`）
   - 检查手机号、身份证等关键信息
3. 指派班级角色：
   - 企业班主任 / 跟班教务
   - 理论老师 / 实操老师（从师资库选择）
   - 班长（从学员中选择）
4. 上传课表：
   - 下载课表模板或按系统要求准备 Excel
   - 上传后系统解析上课日期、时段、课程、教师
   - 检查解析结果，手动修正异常行
5. 发起班级资料收集计划：
   - 选择需要收集的字段（照片、学历、身份证影像等）
   - 生成二维码或链接，发给学员填写
6. 查看资料收集齐套率，督促缺件学员补交。

**注意事项**：

- 角色指派后，相关老师/班主任/班长才能在自己的 App 或后台看到该班级。
- 课表一旦保存，后续跟班考勤会按课次执行；如需整体调课，请走调课审批。
- 资料收集不齐，可进入跟班，但建议达到齐套率门槛后再正式开班。

**验收标准**：任意班级可回答：班长是谁、班主任/教务是谁、主讲是谁、课表是否就绪、名单是否齐。

---

### 3.5 开班申报

**目标**：按主管部门或合作机构要求，快速生成开班申报材料包。

**操作步骤**：

1. 进入「培训 → 开班申报」，选择班级或项目。
2. 维护/选择开班材料模板：
   - 按地市选择模板（如来宾、玉林、河池南丹等）
   - 按培训模式选择模板（岗位技能提升 / 新型学徒）
3. 点击「一键生成材料包」。
4. 系统自动带入班级实名数据：班名、人数、负责人、联系电话、教师、课时、培训地点等。
5. 检查缺项提示，补齐缺失信息。
6. 下载生成的材料包（Word / Excel / ZIP）。
7. 如需修改，可重新生成；系统保留版本记录。
8. 记录线下状态：企业盖章、机构提交人社等。

**注意事项**：

- 生成前务必检查班级信息是否完整，否则系统会提示缺项。
- 模板按地市/模式配置，不要随意混用。
- 材料包版本可追溯，建议每次对外提交前重新生成最新版。

**验收标准**：教务无需从零拼 Word/Excel，生成包可经少量核对后对外提交。

---

### 3.6 信息收集

**目标**：组织学员提交报名与开班所需个人信息与证照，完成审核后进入培训执行。

**操作步骤**：

1. 进入「培训 → 信息收集」，点击「新建收集计划」。
2. 配置字段：
   - 必填：姓名、身份证、手机号
   - 可选：学历、工作单位、照片、证件影像等
3. 生成二维码或链接，通过班级群、短信、邮件等方式发给学员。
4. 学员通过 App 或 H5 填写提交。
5. 后台进入「审核」页面：
   - 通过：信息完整且符合要求
   - 驳回补正：说明原因，学员重新提交
   - 批量导出：导出待审/已审名单
6. 查看齐套率摘要（应交 / 已交 / 待审），作为进入跟班的依据。

**注意事项**：

- 信息收集入口与「班级资料收集」区分：前者是全局/项目级，后者是班级级补采。
- 身份证、手机号必须准确，否则会影响后续考勤、成绩导入、证书回填。
- 建议开班前完成信息审核，避免开课后再补材料。

**验收标准**：跟班开训前，班级关键材料审核状态清晰，缺人缺件可催办。

## 四、开班后实施

### 4.1 进入跟班工作台

**目标**：以班级为中心，开展日常教学过程管理。

**操作步骤**：

1. 进入「培训 → 跟班」或「培训实施」菜单。
2. 在班级列表中选择要进入的班级，点击「进班」。
3. 进入跟班工作台，顶部显示班级概览：
   - 学员数
   - 当日出勤与构成
   - 累计出勤率
   - 近日出勤
   - 缺勤/低出勤预警
   - 今日待办
4. 按「业务日」或「课次」切换视图。

**注意事项**：

- 跟班工作台的数据来自学员 App 操作、班长/老师上传、后台导入。
- 不同角色（班主任、教务、老师、班长）看到的操作权限不同。

---

### 4.2 考勤管理

**目标**：如实记录学员到课情况，支撑过程合规与补贴证据。

**操作步骤**：

1. 在跟班工作台中点击「考勤」页签。
2. 选择日期或课次，查看全班考勤状态：
   - 出勤 / 迟到 / 早退 / 缺勤 / 未登记
3. 登记考勤：
   - 学员本人签到：学员在 App 完成
   - 班长/班主任代签：提交后进入「待确认」状态
   - 本人或班主任确认代签后，才算有效出勤
4. 导入人社考勤表：
   - 下载系统提供的导入模板
   - 按身份证匹配本班学员
   - 上传后查看匹配结果与失败清单
5. 查看单个学员历史考勤明细。

**注意事项**：

- 代签必须经确认后才计入有效出勤，防止虚报。
- 同一天多课次可按规则合并。
- 出勤率 = 有效出勤 ÷ 应到。

---

### 4.3 课堂留痕（照片/视频）

**目标**：保留课堂真实发生证据，满足督导与补贴稽核。

**操作步骤**：

1. 在跟班工作台中点击「留痕」或「影像」页签。
2. 选择课次或日期。
3. 上传课堂照片/视频：
   - 班长、班主任、教务均可上传
   - 支持单张上传和批量上传
4. 查看证据列表，检查是否缺当日影像。
5. 必要时对影像进行审核或备注。

**注意事项**：

- 照片/视频是补贴稽核的重要证据，建议每课必传。
- 文件大小和格式受系统限制，上传前注意压缩。
- 影像按班级/课次/日期归档，后续可导出索引。

---

### 4.4 作业与随堂练

**目标**：老师布置课堂练习/作业，学员在 App 作答，管理端查看完成情况。

**操作步骤**：

1. 在跟班工作台中点击「作业」页签。
2. 点击「布置作业/随堂练」：
   - 选择任务类型：正式作业 / 随堂练习
   - 选择挂接的课次或业务日
   - 从题库选题或手动组题
   - 设置截止时间、达标规则
3. 发布任务，系统会自动生成应交学员名单。
4. 学员在 App 中收到任务并作答。
5. 客观题系统自动判分，主观题/人工批改待后续支持。
6. 在作业列表查看：完成率、未交名单、平均分、答卷明细。

**注意事项**：

- 跟班作业与考前刷题是两套体系，不要混淆。
- 题目发布后使用快照，避免题库改题影响已发任务。
- 插班学员对未关闭任务会自动补发。

---

### 4.5 班级刷题与学情

**目标**：在培训周期内提升学员掌握度，班级可限定刷题范围。

**操作步骤**：

1. 在跟班工作台中点击「刷题学情」页签。
2. 为班级配置科目/知识点白名单。
3. 学员在 App「我的班级」或「刷题」入口带班级身份刷题。
4. 查看班级学情看板：
   - 人均刷题量
   - 正确率
   - 薄弱知识点
   - 学员个人刷题明细

**注意事项**：

- 刷题答卷、作业答卷、考前任务答卷分通道统计，不混算。
- 同步学（考前复习）保持既有通道，不与班级刷题混淆。

---

### 4.6 班主任日志

**目标**：班主任记录每日班级情况，形成异常闭环。

**操作步骤**：

1. 在跟班工作台中点击「日志」页签。
2. 选择日期，填写班主任工作日志：
   - 出勤概况
   - 异常学员（缺勤、作业未交、状态异常等）
   - 沟通与处理措施
3. 保存后日志落库，支持按班级与日期查询。
4. 跟班教务可抽查日志并标记合规状态。

**注意事项**：

- 日志不要只写在本地或纸上，必须落库才能用于后续审计。
- 异常学员需跟踪处理结果，形成闭环。

## 五、考试与认定

### 5.1 考试批次

**目标**：培训侧组织考试计划，但不替代人社/认定的正式考场。

**操作步骤**：

1. 进入「培训 → 考试」，点击「新建考试批次」。
2. 选择关联班级，从花名册导入考生名单。
3. 填写考试信息：
   - 理论考期
   - 实操考期
   - 及格线（默认 60，可按批次配置）
   - 关联认定计划/批次（实操用）
4. 保存后，批次状态为 `draft`；名单锁定后变为 `roster_ready`。

**注意事项**：

- 理论考试在人社系统完成，培训侧只收导出成绩。
- 实操考试主数据在认定模块，培训侧引用结果。
- 跟班模拟考/刷题分 **不进入** 正式通过率。

---

### 5.2 导入人社成绩

**目标**：把人社导出的理论成绩表导入系统，匹配到学员。

**操作步骤**：

1. 人社完成理论考试后，导出成绩 Excel 表。
2. 进入考试批次详情，点击「导入理论成绩」。
3. 上传成绩表，系统按身份证 + 姓名匹配本班学员。
4. 查看预览结果：
   - 待写入：匹配成功且成绩可写入
   - 未匹配：身份证不在本班花名册
   - 冲突：同一场考试内同一学员成绩不一致
   - 空分：四项成绩均为空
5. 对于初考/补考/重考多表，系统会按考试时间合并：
   - 补考技能为空时，继承初考技能分
   - 重考有值时，覆盖上一场
6. 确认写入后，学员成绩更新到花名册。

**注意事项**：

- 成绩表必须包含身份证和姓名，缺一不可。
- 多次导入以最新批次为准，系统保留导入历史。
- 同场冲突需人工处理，跨场覆盖是合法行为。

---

### 5.3 实操成绩引用

**目标**：从认定模块引用实操考试结果，不重复录入。

**操作步骤**：

1. 在考试批次详情中填写「关联认定计划/批次 ID」。
2. 认定模块完成实操考试并出分后，点击「同步实操成绩」。
3. 系统按身份证 + 工种/等级 + 认定计划关联，读取合格标志或分数。
4. 查看同步结果，确认写入。

**注意事项**：

- 认定模块需先提供只读查询接口或约定关联键。
- 过渡期如未打通，可手工勾选实操合格，但后续会被同步结果覆盖。

---

### 5.4 查看通过率

**目标**：统计班级考试结果，关注教学效果。

**操作步骤**：

1. 在考试批次详情或班级看板查看通过率。
2. 系统展示：
   - 班级理论通过率
   - 班级实操通过率
   - 班级综合通过率（理论合格且实操合格）
3. 每个数字旁标注来源：「理论·人社导入」「实操·认定」。

---

## 六、结业与毕业

### 6.1 结业办理

**目标**：完成班级/学员结业状态，通知学员。

**操作步骤**：

1. 进入「培训 → 毕业典礼」，查看待结业班级列表。
2. 点击班级进入详情，查看学员名单及成绩达标提示。
3. 勾选需要结业的人员（或全班结业）。
4. 点击「执行结业」：
   - 已达标：标记为 `passed`
   - 未达标但允许结业：标记为 `failed`（默认不发证）
5. 系统按班级更新结业状态，全部班级结业后项目自动完成。
6. 点击「发送通知」，向结业学员发送站内信通知。

**注意事项**：

- 单个班级结业不会直接置项目完成，需全部班级结业。
- 结业状态是后续补贴申报的人员口径依据。
- 通知发送会记录成功/失败明细，失败学员需检查是否有 App 账号。

---

### 6.2 获证人员名册导出

**目标**：导出人社版式《职业技能等级认定获证人员名册》。

**操作步骤**：

1. 在毕业典礼列表或班级详情中，点击「导出人员名册」。
2. 选择导出范围：
   - **已获证**（默认）：只导出证书编号非空的学员
   - **全部**：导出班级全部学员
3. 系统自动生成 Excel，包含：
   - 标题、班级名称
   - 双行表头（考核成绩拆理论/技能/综合/工作业绩）
   - 13 列数据：序号、准考证号、姓名、性别、身份证、报名机构、职业工种、认定等级、四科成绩、证书编号
4. 下载文件并核对。

**注意事项**：

- 即使已获证 0 人，系统也会导出空表，保留标题和表头。
- 认定等级统一输出为「三级/高级工」形式。
- 无成绩单元格显示为 `--`。

---

### 6.3 证书上传回填

**目标**：把人社下发的证书 PDF 挂到学员花名册，回填真实证书编号。

**操作步骤**：

1. 在毕业典礼列表中勾选 ≥1 个班级。
2. 点击「上传证书文件夹」。
3. 选择多个证书文件夹（或 PDF 文件、ZIP 包）。
4. 系统解析每份 PDF：
   - 抽取身份证号
   - 抽取证书编号
   - 与已勾选班级花名册匹配
5. 查看预览表：
   - 可写入：身份证在已选班中唯一命中
   - 需处理：证号冲突、解析失败、不在范围等
6. 确认「可写入」行，点击「确认回填」。
7. 系统把证书编号和文件路径写入 `train_certificate`，学员名单可点开查看 PDF。

**注意事项**：

- 匹配键是 **身份证号**，不是姓名，避免同名串人。
- 同一份证书不要重复上传，系统会幂等处理。
- 证书编号与文件名不一致时，以 PDF 正文为准并提示警告。

---

## 七、补贴申报

### 7.1 创建补贴单

**目标**：按班级整理补贴申报材料，跟踪申报进度。

**操作步骤**：

1. 进入「培训 → 补贴申报」，点击「新建补贴单」。
2. 选择班级或项目。
3. 系统按规则带出：
   - 申报地市（来自项目 `city` 字段，可修改）
   - 培训模式（岗位技能提升 / 新型学徒）
   - 政策年（默认按班级结业日期）
   - 材料配方版本
4. 首次生成材料前可修改政策年；首次生成后锁定四元组。

**注意事项**：

- 政策年不要用系统当前自然年，要用申报预算年或结业所属年。
- 跨年补报需选择旧版 Profile，并记录审计。

---

### 7.2 生成补贴材料包

**目标**：按地市/模式要求一键生成补贴申报材料 ZIP。

**操作步骤**：

1. 在补贴单详情中点击「一键生成材料包」。
2. 系统按当前锁定的 Profile，逐槽位渲染：
   - 拨付请示/资金申请
   - 补贴申请表
   - 申领培训补贴人员花名册
   - 获证/鉴定名册
   - 培训照片（优先引用跟班照片册）
   - 证书 PDF 包
   - 满意度调查表等
3. 系统自动检查必填槽位是否齐全。
4. 若缺项，列出缺项清单，补齐后再生成。
5. 生成成功后下载 ZIP。

**注意事项**：

- 各地市材料清单不同，系统按「地市 × 培训模式 × 政策年 × 版本」配置。
- 模板填空是主路径，不要依赖 LLM 直接生成整包。
- 证书、照片等证据材料需提前在毕业/跟班环节准备好。

---

### 7.3 跟踪拨款进度

**操作步骤**：

1. 在补贴单中记录申报节点：已提交 / 审核中 / 已拨款 / 退件等。
2. 填写拨款金额、到账日期。
3. 退件时记录原因并补充材料后重新提交。

## 九、常见问题

### Q1：学员登录 App 提示「账号不存在」怎么办？

- 检查该学员是否已在班级花名册中。
- 检查是否已开通 App 账号（分班物化时会自动开通，补开可在「开班准备 → 花名册」操作）。
- 确认学员使用的是手机号或身份证 + 默认密码登录。

### Q2：导入人社成绩时很多人「未匹配」怎么办？

- 检查花名册中身份证号是否录入正确。
- 检查成绩表身份证格式是否为 18 位。
- 确认导入的是本班学员的成绩表。

### Q3：代签的考勤为什么没计入出勤率？

- 代签需要本人或班主任确认后才算有效出勤。
- 在「考勤」页签查看待确认代签并处理。

### Q4：补贴材料包生成失败提示缺项？

- 按缺项清单补齐材料：
  - 缺照片：回「跟班 → 留痕」补传
  - 缺证书：回「毕业典礼」上传证书
  - 缺满意度：发起满意度调查
- 补齐后重新生成。

### Q5：结业后才发现成绩错了怎么办？

- 若尚未发送通知和归档，可撤销结业后重新打标（如系统支持）。
- 若已归档，建议新建备注记录，并在补贴申报时特别说明。
