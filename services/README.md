# services

放正式后端服务。一期采用可控服务化起步，核心业务集中在 `platform-api`，AI、MCP、文件、工作流等边界清晰能力按独立服务目录准备。

## 子目录

| 目录 | 用途 |
| --- | --- |
| `platform-api/` | Java Spring Boot 核心业务主服务，承载账号权限、租户组织、课程、题库、考试、学习记录、成绩、错题 |
| `ai-gateway/` | AI Gateway / Agent 服务，负责模型调用、Prompt 编排、课程大纲草稿生成和材料检查 |
| `file-service/` | 文件服务，统一处理文件元数据、上传、下载、预签名 URL、删除和 OSS/COS 适配；一期可独立，也可先并入主后端 |
| `mcp-server/` | MCP 工具服务，供 AI 调用受控业务能力，不直连业务数据库 |
| `workflow-service/` | 工作流服务，承载流程定义、审批任务和流程记录；一期可先并入主后端，但边界按独立服务设计 |

## 统一规则

1. 不一开始拆出大量细业务服务，避免规则重复和联调复杂。
2. 账号、租户、权限、审计、核心业务规则由平台底座统一控制。
3. 独立服务通过受控 API 协作，不绕过权限直接访问业务数据库。
4. 每个服务后续必须补充环境变量模板、启动说明和健康检查接口。
