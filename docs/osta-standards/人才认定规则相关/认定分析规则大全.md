## 二、申报条件要素说明

新规程各条款由以下要素组合而成。每类要素的判定口径如下：

### 2.1 年龄

- 仅**初级工**条款含年龄条件：年满 **16 周岁**。
- 中级工及以上不设年龄条款（由工龄/证书/职称/学历条件间接约束）。

### 2.2 累计从事本职业或相关职业工作年限（工龄）

- **本职业**：指同一职业编码下的任一工种（如铝电解工 6-17-06-02 及其全部 10 个工种互为本职业）。
- **相关职业**：以《职业分类大典》及职业标准口径为准；系统实现中结合员工所在单位、前工作岗位、实际岗位名称综合判定是否属于相关职业工作场景。
- **起算口径（2026-08 起系统执行口径）**：因工作年限证明由员工**当前工作企业**开具，工龄优先以「劳动合同签订开始时间」（或劳动合同签订时间、参加当前工作时间、入职时间）为起点、当前时间为终点计算；上述列均缺失时回退「参加工作时间（第一次工作时间）」起算，输出中标注「非由劳动合同签订开始时间计算，需人工审核」，且判定状态标注「推荐（工作年限从参加工作时间开始计算）」。
- **"满N年"的判定**：起算日 + N 年 ≤ 当前日期（或可认定年份窗口），详见引擎 `add_years` 口径。

### 2.3 职业技能等级证书

- 指**本职业或相关职业**的相应等级职业资格/职业技能等级证书（如"四级/中级工证书"）。
- 证书后的年限（如"取得初级工证书后满3年"）以**证书发证日期**为起算点。
- 系统实现中证书范围受 `CERTIFICATE_JOB_SCOPE` 约束，仅统计认定范围内工种的证书。

### 2.4 职称（专业技术人员职业资格）

- 必须为**符合专业对应关系**的职称（职称专业与申报工种相关）。
- 等级对应：初级职称 / 中级职称 / 高级职称，年限自**职称获证时间**起算。

### 2.5 学历·专业·院校

- **本专业/相关专业**：以《认定工种专业.xlsx》中该职业登记的专业清单为准（各职业清单见第三章对应小节）。
- **院校类型分层**（按条款从低到高涉及）：
  | 院校层次 | 条款中出现位置 |
  |---|---|
  | 技工院校、中等及以上职业院校、专科及以上普通高等学校（本专业/相关专业，含在读应届毕业生） | 中级（3） |
  | 技工院校**高级工班及以上**（本专业/相关专业，含在读应届毕业生） | 高级（4） |
  | 高等职业学校、专科及以上普通高等学校（本专业/相关专业，含在读应届毕业生） | 高级（5）、高级（6） |
  | 高级技工学校、技师学院毕业生 | 技师（4） |
  | 技师学院预备技师班、技师班学生（含毕业学年在校生） | 技师（5） |
- **在读应届毕业生**：条款注明"含在读应届毕业生"的，未取得毕业证书的在校应届毕业生视同满足学历条件。
- **评估论证**：高级（6）为"经评估论证"的院校毕业证书（直接申报需评估论证）；高级（5）为中级证 + 学历的晋级申报，**不需**评估论证。

### 2.6 企业新型学徒制条款定位

新规程备注明确的三条学徒制申报条款：

| 学徒制目标等级 | 选用条款 | 条款要点 |
|---|---|---|
| 中级工 | 中级（3） | 本专业/相关专业的技工院校或中职及以上院校毕业证书（含在读应届） |
| 高级工 | 高级（4） | 本专业/相关专业的技工院校高级工班及以上毕业证书（含在读应届） |
| 技师 | 技师（5） | 高级工证书满2年的技师学院预备技师班、技师班学生（毕业学年可报） |

学徒制路径的系统实现细则（认定时间口径、兜底逻辑等）见第四章。
