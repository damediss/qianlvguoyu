### 2. 后台页面要求

#### 登录页

1. 输入租户编码、账号、密码。
2. 登录成功后保存 token，加载当前用户和菜单。
3. 登录失败显示后端错误文案。

#### 后台框架

1. 左侧菜单由后端返回，不写死。
2. 顶部显示当前用户、租户、退出入口。
3. 无权限路由显示 403。
4. 刷新页面后能恢复菜单和当前用户。

#### 系统管理页

1. 列表页统一使用 ProTable。
2. 新增/编辑统一使用 Drawer 或 Modal。
3. 删除必须二次确认。
4. 启用/停用状态使用明确标签。
5. 角色授权页必须能勾选菜单和按钮权限。

#### 课程、题库、试卷

1. 课程列表支持标题、分类、工种、等级、状态筛选。
2. 课程详情支持章节维护、文件上传、提交审批。
3. 题库支持单选、多选、判断题，选项可增删。
4. 试卷支持手动选题、设置分值、总分和及格线。
5. 考试安排支持选择课程、试卷、时间和发布状态。

#### 流程与 AI 样板

1. 我的待办展示待审批任务、业务标题、提交人、提交时间。
2. 审批弹窗支持通过/驳回和意见。
3. AI 课程大纲页支持输入课程主题、工种、等级、上传资料并生成草稿。
4. AI 草稿必须显示“AI 生成，仅供人工确认”。

## 二、学员端应用

工程：`apps/student-web/`

一期定位：最小学员端 H5，不先做复杂 App。

| 路由 | 页面 | 主要接口 |
| --- | --- | --- |
| `/login` | 学员登录 | `POST /api/auth/login` |
| `/courses` | 我的课程 | `GET /api/student/courses` |
| `/courses/:id` | 课程详情 | `GET /api/student/courses/{id}` |
| `/courses/:id/chapters/:chapterId` | 章节学习 | `POST /api/student/learning-records` |
| `/exams` | 考试列表 | `GET /api/student/exam-sessions` |
| `/exams/:sessionId/start` | 开始考试 | `POST /api/student/exam-attempts` |
| `/attempts/:attemptId` | 答题页 | `GET /api/student/exam-attempts/{id}` |
| `/attempts/:attemptId/result` | 成绩页 | `GET /api/student/exam-attempts/{id}/result` |
| `/wrong-questions` | 错题本 | `GET /api/student/wrong-questions` |

### 学员端页面要求

1. 学员端只展示学员可访问的数据。
2. 考试提交后立即展示客观题分数。
3. 已提交考试不能重复提交；如允许重考，由考试安排控制。
4. 错题页展示题干、学员答案、正确答案、解析。
5. 学习记录至少支持章节完成状态。

## 三、前端权限规则

1. 前端根据后端菜单控制展示。
2. 前端不做最终权限裁决。
3. 后端返回 401 时清理登录态并跳登录页。
4. 后端返回 403 时展示无权限页面。
5. 按钮展示依赖权限码，例如 `course:create`、`question:update`。
