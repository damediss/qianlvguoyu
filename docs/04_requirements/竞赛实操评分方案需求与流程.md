# 竞赛实操评分方案需求与流程

## 目标

在实操项目导入与赛段运行规则之间增加一个明确、可复用、可版本化的“实操评分方案”环节。评分方案描述本场实操由哪些已配置评分项的实操项目组成、各项目顺序及其原始分值；赛段运行规则继续负责考试启停、时长、提前完成奖励、超时扣分和自动结束等运行行为。

简易组卷菜单中的“实操组卷”入口调整为“实操评分方案”。历史简易实操组卷计划保留在数据库中，但不出现在新评分方案工作台或赛段评分方案选择器中；既有普通试卷路径保持原行为。

## 配置流程

1. 在简易实操题库导入实操项目及其考评内容、评分项、原始分值和参考时长。
2. 进入“实操评分方案”，先选择赛事、工种和等级，再从当前范围内选择一个或多个已启用实操项目。
3. 调整项目顺序并查看每个项目的考评内容、评分方式和评分项明细。
4. 保存草稿前校验：所选项目属于当前赛事工种等级且评分配置完整；项目原始分值合计必须恰好为100分；方案参考时长等于所选项目参考时长合计。方案不缩放单项分值，也不使用随机抽题规则。
5. 保存后生成一份草稿评分快照。检查预览无误后发布；发布后的方案与快照不可编辑或删除。需要调整时复制已发布方案，形成新草稿版本，再发布新版本。
6. 进入赛段实操运行规则，选择同赛事、工种和等级下已发布的评分方案，再独立设置本赛段的考试名称、运行时长、启停方式和时间加扣分规则。

## 数据及边界

- 评分方案沿用竞赛组卷计划与 P 类试卷快照存储，但以 `plan_purpose=PRACTICAL_SCORING_SCHEME` 与普通组卷计划隔离。历史记录迁移默认用途为 `EXAM_PLAN`。
- 快照逐项目深拷贝题干、实操配置、考评内容及评分项；每个项目使用自身总分，分值比例为 1，不进行二次换算。方案总分固定为100分。
- 快照中的项目顺序由方案编辑器确定。发布方案生成不可变版本；赛段配置只能绑定已发布方案。
- 方案候选、赛段下拉及保存校验均按租户、赛事、工种和等级过滤。服务端是范围与发布状态的最终裁决点。
- 普通实操试卷绑定入口不展示也不接受评分方案快照，避免两条赛段配置路径混用。
- 题目配置中的参考时长用于方案内容汇总，不覆盖赛段运行时长；运行时长和时间计分参数仍由赛段运行规则配置，并随赛段执行计划固化。
- 普通理论组卷、普通实操组卷及细目表自动组卷流程保持原有行为。

## 验收要点

- 简易组卷菜单显示“实操评分方案”，打开独立方案工作台；理论简易组卷不受影响。
- 可按赛事、工种、等级选择实操项目、调整顺序、查看评分项明细；跨范围、停用或缺少评分配置的项目不能保存。
- 非100分、空选择、重复项目、错误参考时长、含随机组卷规则等请求均由服务端拒绝。
- 草稿可编辑、预览、发布和删除；已发布方案不可修改/删除，复制会创建独立草稿版本。
- 赛段只可选择本赛事工种等级的已发布评分方案，其他范围及普通实操组卷快照不可被误选。
- 赛段时长和运行规则与评分方案内容分离，赛段执行快照包含绑定的评分方案版本和运行参数。
