# 竞赛模块 P0 静态原型

用于业务需求沟通的原生 HTML + CSS + JavaScript 原型。所有内容均为 mock 数据，不接后端接口，不依赖构建工具；直接用浏览器打开 `index.html` 即可查看。

## 原型入口

- `h5.html`：参赛用户移动端。第二版采用五个 Tab：发现、须知、任务、积分榜、我的；包含签到、学习、学后答题、答题闯关、积分明细、排行、晋级进度、心得发布与个人中心等轻量演示。
- `super-admin.html`：超级管理员后台。包含赛事与赛段、参赛单位/用户、签到/学习/闯关规则、积分、排行、晋级，以及风采审核、须知文件管理。
- `enterprise-admin.html`：企业管理员后台。聚焦本单位数据、用户、参与记录、积分和晋级推荐。

## 说明

- P0 主线：赛事、赛段、参赛用户、签到、学习、闯关、积分、排行、晋级。
- H5 的“发现”仅用于展示竞赛风采和经验分享，不提供关注、私信、评论、推荐算法等社交功能。
- 所有提交、审核、导出、发布操作均通过 toast 模拟；不执行真实上传或状态写入。
- P1 能力以灰色占位说明，例如高级赛制编排、复杂积分公式和单位风采统计。
