# 上篇 · AI 班级助理

## 一、目标与人设

### 1.1 一句话

在「我的班级」内提供 **班务问答 + 学习辅导** 的对话式助理：懂本班课表/作业/学情，能引导刷题与布置，**不替代正式批改裁决，不替代认定考场**。

### 1.2 角色 × 痛点 × 能力

| 角色 | 痛点 | 助理能做什么（示例话术） |
|------|------|--------------------------|
| 学员 | 不知今明干啥、作业在哪、薄弱点看不懂 | 「今天课表/作业/该刷哪」「这道作业题怎么讲」 |
| 主讲 / 助教 | 选题布置慢、学情散 | 「按本章抽 10 单选 5 判断」「谁没交作业」 |
| 班主任 / 跟班教务 | 催交、答事务问 | 「本班进度汇总」「调课流程怎么走」 |
| 班长 | 代催、传话 | 「未交名单发我」 |

### 1.3 人设边界

| 做 | 不做 |
|----|------|
| 查本班课表、作业入口、练习范围说明 | 编造不存在的课次/名单/成绩 |
| 汇总完成率、未交名单（按角色授权） | 学员查看他人详细答卷（除非产品另开） |
| 引导跳转布置 / 刷题 / **精准学** / 进度页 | 静默改课表、静默发布作业（须确认） |
| 辅导讲解（官方解析 / 同步学 explain / WeKnora） | 替代认定考试、改正式判分 |
| 生成催交文案草稿 | 未经确认群发短信/推送（P3 再议） |

---

## 二、助理与现有通道关系

| 原则 | 说明 |
|------|------|
| 助理是编排层 | 不新建答题域；答卷仍落 A/B/C |
| 强制班级上下文 | 会话必带 `classId`；鉴权走本班角色 |
| 与同步学隔离 | 同步学留在「提升」；助理可跳转，不搬国标排题进班级 |
| 与精准学协同 | 「该刷哪 / 看薄弱点」→ 深链通道 E；助理只给摘要卡片 |
| 与 WeKnora | 深度讲解可调陪练；班务数字必须走 Tool |

# 下篇 · AI 精准学

## 八、精准学目标与 MVP 定义

### 8.1 来源

跟踪表「培训 AI 精准学」MVP（原文）：

> **错题记录、薄弱知识点、推荐练习、学习报告**；先做基础入口，**不做复杂个性化算法**。

### 8.2 一句话

给学员一条可见的提分闭环：**知道错在哪 → 知道弱在哪 → 下一题练什么 → 看得懂进步**。

### 8.3 与同步学 / 刷题 / 助理的边界

| 能力 | AI 精准学 | AI 同步学 | 班级刷题 A | 班级助理 D |
|------|-----------|-----------|------------|------------|
| 产品定位 | 学习中枢壳 | 考前规则排题引擎 | 班内自由练 | 班务调度 |
| 排题强度 | 轻量推荐（规则） | 三阶段 + 错题状态机 | 用户自选/组卷 | 不排题 |
| 数据主源 | appsmart 日志 + 可选同步学错题摘要 | `ai_review_*` | `exam_*` + class_id | 读 A/B 元数据 |
| 入口 | 提升「AI精准学」 | 提升「同步练习」 | 我的班级刷题 | 班级助理 |

**结论**：精准学是 **产品与入口整合**，优先复用现网；同步学继续专精考前；不在精准学内重做同步学状态机。

## 十一、精准学信息架构（MVP）

```text
我的班级
 ├─ 班级卡片「AI 精准学」 / 工作台入口
 └─ AI精准学（preciseHome?classId=）
       ├─ 错题本      → 列表 / 重练（appsmart wrongReplay）
       ├─ 我的薄弱点  → Top 知识点 +「去练习」
       ├─ 今日推荐    → 规则生成一套小题（或跳转同步学/组卷）
       └─ 学习报告    → 近 7 日指标 + 文字小结（可选 LLM）
```

班级助理侧仅出现：

- 卡片「你有 N 个薄弱点」→ `navigate: preciseHome?tab=weak&classId=`  
- 卡片「建议先练错题」→ `navigate: preciseHome?tab=wrong`

## 十二、精准学规则推荐（MVP，可单测）

**输入**：近 7～30 日答卷（优先带 `class_id` 的班级练 + 可选全局）；知识点维度对错次数。  

**输出**：

1. `weakKnowledges`：按错误率降序，Top 5（至少答过阈值阈值，如 ≥3）  
2. `recommendSet`：从薄弱知识点下抽客观题 K 道（默认 20，受 practice-scope 约束）  
3. `report`：答题数、正确率、较上周变化、薄弱 Top3  

**不做（MVP）**：深度学习排序、千人千面模型、跨工种迁移学习。

与同步学关系：若学员已开通同步学计划，推荐页增加按钮「去完成今日同步练习」，避免双轨抢时间。

## 十五、安全与口径（两产品共用）

1. 班级数据必须校验本班角色；精准学跨班不可串数据。  
2. 报告与薄弱点统计口径文档化（含/不含作业、含/不含同步学），助理引用同一口径。  
3. LLM 只做文案与讲解，不对正确率「估算造假」。  
4. 不替代认定考试；文案避免「包过」。  

---

## 十六、非目标（汇总）

**助理**：不替代批改与认定考；不与 promote 作业合并；首期无确认不群发。  

**精准学**：不重做同步学三阶段状态机；MVP 不上复杂推荐模型；不强制取代班级作业通道。
