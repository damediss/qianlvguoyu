# 竞赛简易试题管理

> 当前状态（2026-10-28）：简易试题仅保留理论试题入口；实操评分项管理入口和页面已下线。

## 目标

在“竞赛试题管理”下新增“简易试题”目录，供不需要配置竞赛细目表的赛事按统一 Excel 格式批量导入试题。

## 菜单结构

```text
竞赛试题管理
└── 简易试题
    └── 理论试题
```

原有细目表与题库页面保留。

## 简易试题 - 理论试题

- 仍按赛事、工种和等级归属试题。
- 提供批量导入与导入进度查询，不要求赛事先导入或启用细目表。
- 列表只显示未绑定细目表的理论试题。
- Excel 工作表使用“竞赛试题”，列顺序为：序号、题型、题干、参考答案、回答、选项 A 至选项 H。
- 本期支持单选题、多选题、判断题和填空题；也接受模板代码 2、7、1、3 分别表示单选、多选、判断、填空。模板中的简答、计算、论述、名词解释、制图、分析等题型待后续确认题目模型及评分规则后接入。
- 导入试题不创建细目表考评点绑定。
- 本期不调整组卷、考试和评分规则。
