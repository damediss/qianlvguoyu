## 四、后续归档规则

1. 已定稿、用于汇报或交付的文件放入 `01_正式交付文档/`。
2. 仍在讨论、内容不稳定或仅用于分析的文件放入 `02_草稿与过程文档/`。
3. 每周更新、需要持续维护的项目进度表放入 `03_项目跟踪台账/`。
4. 原始业务资料、客户资料、流程图、WBS 和表格放入 `需求资料/`，不要和加工后的方案文档混放。
5. 系统截图统一放入 `04_系统截图/`，文件名建议采用 `系统_模块_日期.png`。
6. 生成脚本放入 `05_生成脚本/`，渲染出来的 PDF 和页面截图放入 `90_渲染导出与校验/`。
7. 新版本文件建议使用 `文件名-v1.0.docx` 或 `文件名-YYYYMMDD.docx`，避免“最终版、最终最终版”命名。
